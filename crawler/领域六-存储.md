# 领域六 · 存储（已学 ✅）

## 目标
- 把爬到的数据存成文件：CSV / JSON / SQLite

## 存储三种形态
- **CSV**：表格数据，Excel 友好（本领域已学）
- **JSON**：程序间交换，保结构（复用 `r.json()` 那套）
- **SQLite**：真数据库，查询/去重（进阶再说）

## CSV 写入四步（csv 标准库，自带）
```python
import csv

with open("top250.csv", "w", newline="", encoding="utf-8-sig") as f:
    writer = csv.writer(f)
    writer.writerow(["排名", "片名", "评分", "短评"])     # 表头，循环外写一次
    writer.writerow(["1", "肖申克的救赎", "9.7", "希望让人自由。"])  # 数据行
```

## 两个必踩的坑
1. **编码用 `utf-8-sig` 不是 `utf-8`**：Excel 打开会乱码，带 BOM 头才能正常显示
2. **`newline=""` 必须写**：不写每行后面多空行（跨平台换行差异）

## writerow vs writerows
- `writerow`：数据**边解析边产生**时用（豆瓣场景，逐行写）
- `writerows`：数据**先全收集齐**再一次性写
- 边爬边写的好处：爬一半挂了，已爬数据还在文件里
