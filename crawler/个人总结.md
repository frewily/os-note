# 个人总结：crawler（爬虫）

## 我现在的理解
- 爬虫 = 模拟浏览器和服务器对话：**发请求 → 解析 → 清洗 → 存储 → 工程化**，任何爬虫都是这五环
- 信息搜集（豆瓣）重解析：HTML/JSON → BeautifulSoup / dict 索引
- 媒体下载（B站/Pixiv）重"动态取址"：地址是短时签名的，必须走 JSON API 现取现下
- 反爬是常态：伪装头 + 限速 + 状态码检查，是每一段下载代码的底线
- 工程化让爬虫"稳跑"：Session 复用连接、重试扛偶发故障、代理换身份、随机间隔像真人
- 合规是底线：**小号 + 低频 + 少量 + 限速 + 遇 403 即停**，个人学习可以，批量商用不行
