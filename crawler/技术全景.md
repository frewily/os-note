## 概念关系表
| 概念 | 所属领域 | 前置概念 | 关系说明 |

| requests | 领域二 | HTTP 请求/响应 | 发请求、拿响应对象 |
| raise_for_status | 领域二 | requests | 非2xx抛异常，防错误页被当数据 |
| BeautifulSoup | 领域三 | HTTP、HTML | 把 HTML 变文档树，select 提取 |
| 短时签名URL | 领域四 | — | CDN防盗链，deadline+签名，地址需动态获取 |

| time.sleep | 领域五 | — | 限速，礼貌爬虫防 418 |
