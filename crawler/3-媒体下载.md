# 媒体下载

## 核心

图片/视频 = 二进制下载，但地址往往带防盗链：**短时签名 URL 必须动态获取、拿到立刻用**；B 站高清要走 dash 双流 + moviepy 合成。

## 短时签名 URL（CDN 防盗链通用套路）

- 是什么：下载地址带 `deadline`（过期时间戳）+ 签名参数，过期/篡改即失效（403）
- 为什么：服务器不把"即将过期"的链接写死在 HTML，由 JS 动态请求 API 获取
- 推论：爬虫必须**动态获取地址**，不能硬编码

## B 站下载三步走（v2，已验证）

```python
# ① view API：拿 cid
info = requests.get("https://api.bilibili.com/x/web-interface/view",
                    params={"bvid": bvid}, headers=headers, timeout=(5, 10)).json()
cid = info["data"]["cid"]

# ② playurl API：拿视频流 URL（短时签名，拿到立刻用）
play = requests.get("https://api.bilibili.com/x/player/playurl",
                    params={"bvid": bvid, "cid": cid, "qn": 80},
                    headers=headers, timeout=(5, 10)).json()
video_url = play["data"]["durl"][0]["url"]

# ③ 下载（先 raise_for_status，防 403 错误页写成 .mp4）
r = requests.get(video_url, headers=headers, timeout=(10, 60))
with open(f"{bvid}.mp4", "wb") as f:
    f.write(r.content)
```

已验证：`BV1nU4y187Am` → 360P mp4（2.8MB）下载成功。

## fnval vs 登录：两个维度独立

| 维度 | 决定什么 | 值 |
| --- | --- | --- |
| `fnval=16` | 返回**格式**：单文件（durl）/ 双流（dash） | 高清只走 dash |
| 登录（Cookie） | **清晰度上限** | 未登录最高 360P，登录 720P/1080P |

反直觉点：未登录 + fnval=16 → 仍是双流，只是只给低清晰度流。想跳过合成省两步 = 永远标清。

## v3 高清版（Cookie + dash 双流）

- 思路：加 Cookie + `fnval=16` → playurl 返回 dash（视频 m4s + 音频 m4s 分离）→ 分别下载 → moviepy 合成
- **已验证 ✅**（2026-08-05 实测：quality=80 即 1080P，video 43.1MB + audio 2.7MB，合成 hd.mp4 成功；对照 v2 仅 360P/2.8MB）
- ⚠️ SESSDATA 约半年过期（重登/清浏览器/换设备也会变）——v3 跑出 360P 先怀疑 Cookie 过期；Cookie 是敏感凭证，别把含 Cookie 的代码外发
- 4K/大会员：`qn=120`（4K）+ `fnval=4048`，但 4K 多为 av1/hevc，moviepy 兼容差，需 ffmpeg 命令行合成

## moviepy 合成（高清双流场景）

```python
from moviepy.editor import VideoFileClip, AudioFileClip
video = VideoFileClip("1.mp4")
audio = AudioFileClip("1.mp3")
video.set_audio(audio).write_videofile("输出.mp4")
```

## 图片下载（静态直链 + Referer 防盗链）

- 图片 = 二进制下载的**简化版**：URL 是静态直链（无 deadline 签名），从 HTML 的 `img[src]` 直接拿
- 图片 CDN 有 **Referer 防盗链**——校验"你从哪个页面来"。实测：只带 UA → 418；带 `Referer: https://movie.douban.com` → 200
- 取海报地址：`li.select_one(".pic img").get("src")`
- 实战坑：豆瓣图片 CDN **偶发返回 JS 挑战页**（200 + HTML，非图片）——需检查 `Content-Type`（见 [[1-请求层]]）

```python
headers = {
    "User-Agent": "Mozilla/5.0 ...",
    "Referer": "https://movie.douban.com",   # ← 关键：图片来源站
}
r = requests.get(img_url, headers=headers, timeout=(5, 10))
r.raise_for_status()
with open("海报.jpg", "wb") as f:
    f.write(r.content)
```
