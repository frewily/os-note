# 基础概念

## 核心

爬虫 = 模拟浏览器和服务器对话：**发请求 → 解析 → 清洗 → 存储 → 工程化**。理解 HTTP 请求/响应是第一步。

## HTTP 请求/响应

- **请求**：方法 / URL / 头（headers）/ 体
- **响应**：状态码 / 头 / 体
- 状态码：200 = 成功；**418 = 我是茶壶（反爬拦截）**；403 = 禁止
- 关键用法：`response.status_code`、`response.ok`
- ⚠️ 易错点：`ok` 含 3xx，**不代表数据一定对**（JS 挑战页也是 200）

## HTML 与 JSON

| 形态 | 是什么 | 谁解析 |
| --- | --- | --- |
| HTML | 网页骨架文档（标签嵌套），数据嵌在标签里 | BeautifulSoup（见 [[2-解析层]]） |
| JSON | API 数据格式（键值对，字典/列表嵌套） | `response.json()` 直接转 Python 字典 |

判断依据：浏览器 DevTools → Network → 看响应类型。JS 渲染页面（B 站）数据在 JSON API，不在 HTML。

## 爬虫流水线五环

```
发请求 → 解析 → 清洗 → 存储 → 工程化
①       ②      ③      ④      ⑤
```

- 信息搜集（豆瓣）重解析：HTML/JSON → BeautifulSoup / dict 索引
- 媒体下载（B 站/Pixiv）重"动态取址"：地址是短时签名的，必须走 JSON API 现取现下
