# 领域三 · 解析层（已学 ✅）

## 概念讲解与示例

### BeautifulSoup（HTML 解析）
- 是什么：把 HTML 字符串解析成**可查询的文档树**
- 为什么：正则匹配"文本长什么样"太脆（属性顺序一变就挂）；BS4 描述"找什么"（标签/class/结构）
- 怎么做：
```python
soup = BeautifulSoup(html, "html.parser")
soup.select("ol.grid_view li")   # CSS 选择器 → 列表（25个电影条目）
li.select_one(".title").text     # 取第一个匹配 → 文本
li.get("href")                   # 取属性
```

### CSS 选择器速查
| 写法 | 含义 |
| --- | --- |
| `ol.grid_view` | `<ol>` 且 class=grid_view |
| `ol.grid_view li` | 其**后代** `<li>`（空格=后代） |
| `.title` | 任何 class=title 的元素 |
| `.quote span` | class=quote 里的 `<span>` |

### JSON 解析（解析层的另一种形态）
- `response.json()` → JSON 字符串变 Python 字典
- `d["data"]["durl"][0]["url"]` → 一路 [键]/[下标] 取到底
- 为什么需要：JS 渲染页面（如 B 站）数据不在 HTML，在背后的 JSON API（用浏览器 DevTools → Network → XHR 找）

### 怎么确定一个请求的参数（抄 + 删减验证）
1. **抄**：DevTools → Network → 找该请求 → Headers → Query String Parameters，浏览器实际发的全在这里，照抄
2. **删**：逐个删掉参数跑一遍——删了报错 = 必须；删了正常 = 可选
- 例：B 站 playurl 必须 `bvid`+`cid`；`qn` 是可选清晰度档位（80=360P，B 站没登录会降级）
- 原则：**参数清单 = 从浏览器抄 + 删减法验证**，不面向猜测

### 怎么看懂未知 JSON 的结构（探查三步）
1. **格式化全量打印**：`print(json.dumps(data, ensure_ascii=False, indent=2))`，缩进摊开层级，照抄路径
2. **DevTools Preview**：Network → 点 JSON 请求 → Preview 标签，浏览器格式化成可折叠树
3. **逐层 keys() 探查**：`data.keys()` → `data["data"].keys()`，`type(x)` 判断字典还是列表
- 核心：**字典用 `[键]`，列表用 `[下标]`；不知道就看，不猜**
