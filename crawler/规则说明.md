# 爬虫笔记 — 编写规则

> 定位：requests + BeautifulSoup 视角下的爬虫核心知识梳理。
> 只写实测验证过、反复踩过坑、能直接复用的知识点；不写查文档更快的 API 细节。

## 筛选标准

### ✅ 收录

- 实测验证过的知识点与证据（附状态码、结果）
- 反复踩坑的经验（418/403/200 假图/乱码/moov atom）
- 能直接运行的示例代码片段
- 影响"能不能爬到、会不会被封"的机制（短时签名 URL、Referer 防盗链、dash 双流）

### ❌ 不收录

- 未实测的 API 细节（查官方文档更快）
- 浏览器自动化（playwright/selenium）等尚未学习的领域
- 多线程/异步等会放大风控风险、暂未实践的进阶方向

## 命名规则

| 文件 | 用途 |
| --- | --- |
| crawler.md | 入口知识地图，双链导航到所有笔记 |
| N-主题.md | 知识点笔记，**数字前缀从 0 开始**控制排序 |
| 规则说明.md | 本文件，编写规则与命名规范 |

Obsidian 按文件名排序，数字前缀保证学习顺序与阅读顺序一致。

## 每篇结构

### 核心
一句话概括知识点本质。

### 小节
问题导向——一个知识点一个小节，先"是什么/为什么"再"怎么做"。

### 对比表格
易混概念用表格对比（Cookie vs Token、writerow vs writerows、重试 vs 不重试）。

### 练习记录
实测过的练习，记录"我的写法 vs 正确做法"的差异与验证方式。
