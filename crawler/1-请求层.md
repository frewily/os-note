# 请求层

## 核心

爬虫第一步是"把网页拿回来"——requests 是 Python 最常用的 HTTP 客户端，一个 `get` 拿回响应对象，text/content/json 三种取法。

## requests 核心 API

```python
response = requests.get(url, headers=headers, params={"start": 25}, timeout=(5, 10))
response.raise_for_status()   # 非 2xx 直接抛异常
response.text                 # HTML/JSON 文本
response.content              # 二进制字节（下载用）
response.json()               # JSON 字符串 → Python 字典
```

- `params` 自动拼查询串；`timeout=(连接, 读取)` 防挂死
- ⚠️ 不设 timeout 会挂死；裸请求被反爬（418）

## 状态码：200 不代表内容正确

- 200 成功；**418/403 反爬拦截**（豆瓣裸请求 418，B 站 CDN 403）
- `raise_for_status()` 优于 `if response.ok`：失败当场抛异常，在哪错在哪报
- **JS 挑战页也是 200**（豆瓣图片 CDN 偶发，返回 HTML 假图）——下载前检查 `Content-Type`：图片应为 `image/jpeg`，挑战页是 `text/html`。requests 不执行 JS，挑战页绕不过

## 编码（中文乱码根源）

- `response.encoding` 可能猜错 → 用内容嗅探覆盖：`response.encoding = response.apparent_encoding`

## 伪装：UA 默认必加，Referer 踩到再加

- `User-Agent`：伪装浏览器，**默认必加**
- `Referer`：声明来源页，**默认不加**；加了 UA 还是 403/418 → 补 Referer
- 判断规则：URL 域名与来源页域名**不同**（CDN 如 `img3.doubanio.com`、`upos-...bilivideo.com`）→ 大概率要加
- 参考填法：B 站视频 → `https://www.bilibili.com`；豆瓣图片 → `https://movie.douban.com`
- 浏览器能开、脚本拿不到 → DevTools → Network → 照抄关键三头：User-Agent / Referer / Cookie

## 认证方式：Cookie vs Token

| 方式 | 凭证放哪 | 典型场景 |
| --- | --- | --- |
| Cookie + Session | 浏览器自动带 | 传统服务端渲染网站 |
| Token（JWT） | `Authorization: Bearer xxx` | 前后端分离（Vue/React + 接口） |
| Basic Auth / API Key | `Authorization` 头 | 开放接口 |
| OAuth2 | access_token | 第三方登录 |

爬虫判断法：DevTools → Network → 看请求头带的是 `Cookie` 还是 `Authorization`，照抄。本质都是"带凭证冒充本人"。
