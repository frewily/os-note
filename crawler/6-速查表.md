## 请求层

| 命令/API | 用途 | 示例 | 备注 |

| requests.get | 发 GET 请求 | `requests.get(url, headers=, params=, timeout=(5,10))` | params 自动拼查询串 |
| raise_for_status | 状态检查 | `r.raise_for_status()` | 非 2xx 抛异常，推荐 |
| r.text | 取文本 | — | HTML/JSON 用 |
| r.content | 取字节 | — | 图片/视频用 |
| r.json() | JSON→字典 | `r.json()["data"]["cid"]` | — |
| r.apparent_encoding | 嗅探编码 | `r.encoding = r.apparent_encoding` | 乱码时用 |
| r.headers["Content-Type"] | 内容类型检查 | 下载前判断 | 200 不代表内容正确（JS 挑战页也是 200） |

## 工程化

| 命令/API | 用途 | 示例 | 备注 |
| --- | --- | --- | --- |
| time.sleep(1) | 限速 | 外层循环末尾 | 每页一次 |
| params={"start": 25} | 翻页 | 循环传参 | — |
| requests.Session() | 会话复用 | `s.headers.update({...})` | 省握手+存 Cookie+统一 headers |
| Retry + HTTPAdapter + s.mount | 重试机制 | total/backoff_factor/status_forcelist | 5xx 才重试，4xx 绝不重试 |
| proxies={"http":...,"https":...} | 代理 | `s.proxies.update(proxies)` | 用户环境：127.0.0.1:7897 |
| random.uniform(1, 3) | 随机间隔 | 每次下载后 | 比固定 sleep 更像真人 |

## 常见坑

| 坑 | 现象 | 原因 | 解决 |
| --- | --- | --- | --- |
| 418 | 豆瓣拒绝 | 裸请求被反爬 | 加 User-Agent |
| 418（图片） | 豆瓣图片下载被拒 | 图片 CDN **Referer 防盗链** | 加 `Referer: https://movie.douban.com` |
| 403 | B 站下载失败 | 防盗链/URL 过期 | 加 Referer；动态取址 |
| 200 假图 | 图片打开报错 | **JS 挑战页**也是 200 | 检查 Content-Type 是否 image/* |
| moov atom not found | moviepy 打不开 | 错误页/损坏文件被当视频 | 下载前 raise_for_status |
| 中文乱码 | 打印乱码 | 编码猜错 | apparent_encoding 覆盖 |
| 403/418 重试 | 越重试越被封 | 反爬是故意拒绝 | 4xx 不进 status_forcelist |

## 排查入口

- 官方文档：requests / BeautifulSoup / moviepy
- 报错搜索关键词：状态码 + 库名（如 "403 requests 视频"）
- 调试神器：浏览器 DevTools → Network → XHR，找背后的 JSON API（B 站/Pixiv 都是这么挖出来的）
- 认证方式判断：DevTools 看请求头带 `Cookie` 还是 `Authorization`
