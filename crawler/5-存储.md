# 存储

## 核心

把爬到的数据存成文件：CSV 表格友好（Excel）、JSON 保结构（程序交换）、SQLite 真数据库（查询/去重，进阶）。本领域已学 CSV。

## 三种存储形态

| 形态 | 特点 | 用途 | 状态 |
| --- | --- | --- | --- |
| CSV | 表格数据，Excel 友好 | 数据量小、给人看 | ✅ 已学 |
| JSON | 保结构（复用 `r.json()` 那套） | 程序间交换 | 进阶 |
| SQLite | 真数据库，查询/去重 | 大数据量 | 进阶 |

## CSV 写入四步（标准库自带）

```python
import csv

with open("top250.csv", "w", newline="", encoding="utf-8-sig") as f:
    writer = csv.writer(f)
    writer.writerow(["排名", "片名", "评分", "短评"])     # 表头，循环外写一次
    writer.writerow(["1", "肖申克的救赎", "9.7", "希望让人自由。"])  # 数据行
```

## 两个必踩的坑

1. **编码用 `utf-8-sig` 不是 `utf-8`**：Excel 打开会乱码，带 BOM 头才能正常显示
2. **`newline=""` 必须写**：不写每行后面多空行（跨平台换行差异）

## writerow vs writerows

| 写法 | 场景 | 好处 |
| --- | --- | --- |
| writerow | 数据**边解析边产生**（豆瓣场景，逐行写） | 爬一半挂了，已爬数据还在文件里 |
| writerows | 数据**先全收集齐**再一次性写 | 批量一次写完 |

## 结构要点

- `with open()` **包住整个翻页循环**：文件全程保持打开，写完自动关（不能每页开关）
- 对比 douban_exercise.py：`print` 换成 `writerow`，仅输出端改变
