# 领域一 · 基础概念

## 核心
- HTTP 请求/响应：客户端发请求（方法/URL/头/体）→ 服务器回响应（状态码/头/体）
- HTML：网页骨架文档（标签嵌套），解析层负责从中抠数据
- JSON：API 数据格式（键值对，字典/列表嵌套），`response.json()` 可直接转 Python 字典
- 爬虫五环节流水线：发请求 → 解析 → 清洗 → 存储 → 工程化（详见 技术全景.md 知识地图）

## 补充
- HTTP 请求头（headers）："我是谁、我要什么"——User-Agent / Referer / Cookie / Authorization 都在这层（见 领域二-请求层.md）
