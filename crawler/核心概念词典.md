## 按领域展开
### 领域一：基础概念
#### HTTP 请求/响应
- 是什么：请求行/头/体 + 状态码；200=成功，418=我是茶壶（反爬），403=禁止
- 为什么：理解状态码才能诊断反爬
- 关键用法：`response.status_code`、`response.ok`
- 易错点：`ok` 含 3xx，不代表数据一定对

### 领域二：请求层
#### requests
- 是什么：最常用的 Python HTTP 客户端
- 为什么：一个 get 拿回响应对象，text/content/json 三种取法
- 关键用法：`params` 自动拼查询串；`timeout=(连接,读取)`
- 易错点：不设 timeout 会挂死；裸请求被反爬（418）

### 领域三：解析层
#### BeautifulSoup
- 是什么：HTML 解析成文档树，select 按 CSS 选择器定位
- 为什么：比正则健壮（不依赖文本细节）
- 关键用法：`select()`→列表，`select_one()`→单个或None
- 易错点：select_one 可能返回 None，取 .text 前先判断

### 领域四：媒体下载
#### 短时签名 URL
- 是什么：deadline 时间戳 + 签名的 CDN 防盗链地址
- 为什么：防止地址被永久盗用
- 关键用法：拿到立刻下载
- 易错点：硬编码必死（403）

### 领域五：工程化
#### 限速
- 是什么：time.sleep 控制请求频率
- 为什么：礼貌爬虫，防触发反爬
- 关键用法：sleep 放外层循环（每页一次）
- 易错点：放错层级（内层=250次白等；最外层=等于没限）
