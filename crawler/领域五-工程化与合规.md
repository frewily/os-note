## Session 复用（已学 ✅）
- 每次 `requests.get()` 背后：重新 TCP 握手 + 空 Cookie 罐子 + 重复传 headers
- `requests.Session()` = 一条常驻连接 + 一个 Cookie 罐子 + 一套默认 headers
- 用法：
```python
s = requests.Session()
s.headers.update(headers)          # headers 只设一次
r1 = s.get(url1, timeout=(5, 10))  # 不用再传 headers；timeout 要保留
r2 = s.get(url2, timeout=(5, 10))
```
- 收益**分场景**：大量小请求（多步 API/翻页/批量）省握手明显；大文件下载收益小（瓶颈在带宽）；最关键是 **Cookie 状态保持**（登录一次，后续请求全认得你）
- 练习：`scrape_vodeo_hd_session.py`（v4）——与 v3 对比，差异仅 ① 建 Session ② `requests.get` → `s.get` ③ 去掉 `headers=` 参数（含 r3 下载步，仅为风格一致）

## 安全合规须知（带自己账号操作前必读）
- 风险分级：偶尔限速下载=低；高频批量+无延时+并发=高；共享Cookie/商用=极高
- 风控看**行为模式**（频率/轨迹），不是"用了脚本"本身
- 降低风险：限速、不加并发、控制量、Cookie 别泄露、见 412/验证码立刻停
- 边界：B 站协议禁止自动化下载；仅限个人学习/备份，不商用不恶意批量

## 重试机制（已学 ✅）
- 为什么：网络偶发故障（超时/连接断开/5xx）是暂时性随机问题，失败后自动重来带间隔，不用手动重跑
- 核心 API 示例：
```python
import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

# 配置重试策略
retry = Retry(
    total=3,                    # 最多重试 3 次
    backoff_factor=1,           # 指数退避：等待 1s → 2s → 4s
    status_forcelist=[500, 502, 503, 504],  # 这些状态码才值得重试
)

# 挂到 Session 上（必须在 Session 创建之后）
s = requests.Session()
adapter = HTTPAdapter(max_retries=retry)
s.mount("https://", adapter)
s.mount("http://", adapter)

r = s.get(url, timeout=(5, 10))   # 之后自动带重试
```
- 参数含义：
  - `total`：重试次数上限（+1 原始请求），有上限不无限死磕
  - `backoff_factor`：指数退避 `1×2^(n-1)`，给服务器喘息时间，防"重试风暴"
  - `status_forcelist`：命中这些状态码才重试，只列 5xx
- **重试分错误类型 ⚠️**：超时/断连/5xx = 值得重试（暂时性故障）；**403/418 反爬拦截 = 绝不重试**（故意拒绝，重试只会更触发风控）——反爬靠伪装/限速解决，不靠重试
- 练习：`scrape_vodeo_hd_session.py`（v4）已挂重试——改动仅 ① 顶部两个 import ② 建 Session 后 mount

## 代理（已学 ✅）
- 是什么：中间人服务器，请求先经代理转发，目标网站看到的是代理 IP 不是你的
- 用途：① 隐藏真实 IP 防追踪 ② 突破 IP 限频（轮换代理池）③ 绕过地区限制 ④ 访问被封锁内容
- 类型：HTTP/HTTPS 代理（爬虫常用）、SOCKS5（底层，梯子常用）
- 用法（两种写法）：
```python
proxies = {
    "http": "http://127.0.0.1:7897",     # 用户环境：Clash 本地代理端口
    "https": "http://127.0.0.1:7897",
}
# 写法一：单次请求
r = requests.get(url, proxies=proxies, timeout=(5, 10))
# 写法二：挂 Session（和重试一样是会话级，设一次全生效）
s = requests.Session()
s.proxies.update(proxies)
```
- 代理来源：① 自己的梯子（Clash/Surge 本地端口，免费）② 付费代理池（批量/大规模，按量计费）
- 验证方法：通过代理访问 `http://ip-api.com/json`，看 `query` 字段的出口 IP 是否变化
- ⚠️ 免费代理不可靠（慢/失效/盗流量）；代理放大能力不改变合规边界（批量/商用仍违规）
