# 基础操作

---

## 核心

Git 是版本控制工具，核心流程：**工作区修改 → 暂存区 → 本地仓库 → 远程仓库**。

---

## 配置

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"

# 查看配置
git config --list
```

---

## 初始化与克隆

```bash
# 方式一：从零开始，本地初始化
cd 项目目录
git init                     # 当前目录变成 Git 仓库

# 方式二：从远程仓库拉下来（最常用）
git clone <仓库地址>
git clone https://github.com/xxx/project.git
```

---

## 四个状态

```
工作区（修改文件） → git add → 暂存区 → git commit → 本地仓库 → git push → 远程仓库
     ↑
  git checkout 或 git restore
```

| 区域 | 说明 |
|------|------|
| **工作区** | 你正在编辑的文件 |
| **暂存区** | 用 `git add` 标记要提交的文件 |
| **本地仓库** | 用 `git commit` 提交后的记录 |
| **远程仓库** | 用 `git push` 推送到 GitHub/GitLab |

---

## 核心三连

```bash
# ① 暂存修改
git add <文件名>          # 添加指定文件
git add .                 # 添加所有修改（包括新增）
git add -A                # 添加所有修改（包括删除）

# ② 提交到本地仓库
git commit -m "feat: 添加用户注册功能"

# ③ 推送到远程仓库
git push                  # 推送到默认远程分支
git push origin main      # 推送到指定远程的指定分支
```

**commit message 习惯**：简明扼要说清楚"做了什么"，不要用 "update"、"fix" 这种没信息量的描述。

---

## 拉取与合并

```bash
git pull                  # 拉取远程最新代码并合并到当前分支
git pull origin main      # 从远程 main 拉取
```

`git pull` = `git fetch` + `git merge`。如果你不想自动合并：

```bash
git fetch                 # 只拉取远程更新，不自动合并
git diff origin/main      # 看看远程改了啥
git merge origin/main     # 确认没问题后再合并
```

---

## 查看状态

```bash
git status                # 看当前哪些文件修改了
git log                   # 看提交历史
git log --oneline         # 一行显示提交历史
git log --oneline -5      # 只看最近 5 条
git diff                  # 看工作区 vs 暂存区的差异
git diff --staged         # 看暂存区 vs 已提交的差异
```

---

## 撤销修改

```bash
# 文件还没 add，想撤销工作区的修改
git checkout -- <文件名>         # 老写法
git restore <文件名>             # 新写法（推荐）

# 文件已经 add 了，想取消暂存
git reset HEAD <文件名>          # 老写法
git restore --staged <文件名>    # 新写法（推荐）

# 文件已经 commit 了，想撤回这次提交
git reset --soft HEAD~1          # 撤回 commit，保留修改
git reset --hard HEAD~1          # 撤回 commit，丢弃修改（⚠️ 谨慎）

# 想回到某个历史版本
git log --oneline                # 先看历史，找到 commit hash
git checkout <commit-hash>       # 临时查看该版本
git reset --hard <commit-hash>   # 永久回到该版本（⚠️ 谨慎）
```

## 命令速查

```bash
git init                     # 初始化仓库
git clone <url>              # 克隆远程仓库
git add <file>               # 暂存
git commit -m "msg"          # 提交
git push                     # 推送
git pull                     # 拉取
git status                   # 查看状态
git log --oneline            # 查看历史
git diff                     # 查看差异
git restore <file>           # 撤销修改
git checkout -- <file>       # 撤销修改（老版）
git reset HEAD <file>        # 取消暂存
```
