## 一、就业方向对比

| 方向 | 门槛 | 待遇 | AI替代风险 | 推荐度 |
|------|------|------|-----------|--------|
| 算法 | 极高（985/211硕博） | 最好 | 低 | ⚠️ 学历要求苛刻 |
| **后端/Agent开发** | 相对高 | 不错 | 低 | ⭐ **最推荐** |
| 前端 | 一般 | 一般 | ⚠️ 存在 | 不推荐纯前端 |
| 客户端/测试开发 | 校招低 | 一般 | - | 社招难跳槽 |
| 运维 | 低 | 低 | - | HC极少 |

**结论**：后端/Agent 开发是目前综合最优选择。

---

## 二、语言选择：Java vs Golang

- 国内主流仍是 **Java**（阿里/京东/美团等）
- 大厂趋势：**Golang** 增长快（腾讯/字节/百度等）
- **推荐 Java** 入门：
  - 学习资料最完善
  - 面 Java 岗进大厂后，可转 Golang

## 三、传统 Java 后端学习路线

### 阶段一：Java 基础

| 模块 | 说明 | 资源 |

| 中间件 | 重要性 | 说明 | 资源 |

### 阶段三：开发必备工具

| 工具 | 说明 |
|------|------|
| **Maven** | ⭐ 依赖管理，重点学 |

### 阶段四：入门项目实践

> 学习方法：初期视频学习积累知识；中后期直接看文档效率更高。

## 四、AI 相关内容（竞争力关键）

> 传统 Java 路线在 AI 时代太单薄，必须补充 AI 知识以投递 **Agent 开发岗**等更多方向。

### 4.1 必须掌握的 AI 概念

根据阿里等大厂 AI 岗位 JD，核心技能树：

| 概念 | 说明 |
|------|------|
| **RAG** | 检索增强生成，AI 应用核心模式 |
| **Context Engineering** | 上下文工程 |
| **Prompt Engineering** | 提示词工程 |
| **Tool Calling** | 工具调用 |
| **MCP** | Model Context Protocol |
| **Skills** | 由 Anthropic 提出的概念 |

### 4.2 学习途径

1. **一手资料**：Anthropic、OpenAI 等官网原文文档（最精准）
2. **中文入门**：B站、CSDN、知识星球等平台找优质 AI 博主

### 4.3 AI 项目实践

| 阶段 | 做法 |
|------|------|
| **入门 demo** | 学 SpringAI / Langchain4j 框架用法（黑马视频），但规模不足以写进简历 |
| **亮点融合** | 把 AI 功能**嵌入已有项目**，如：在苍穹外卖中加入 AI 智能客服，作为技术亮点 |
| **成型项目** | 目前缺少成熟的 AI 项目模板，需要自己迭代 demo 成大型项目 |

## 六、关键建议汇总

1. **不要看几年前的学习路线** — AI 已重构行业规则
2. **初期视频学习，中后期直接看文档**
3. **传统后端是打底，AI 是加分项**，两者结合才具竞争力
4. **不要只做独立的 AI demo**，要把 AI 融入已有项目作为亮点
5. 岗位目标可以放宽到 **Agent 开发岗**，不局限于传统后端
