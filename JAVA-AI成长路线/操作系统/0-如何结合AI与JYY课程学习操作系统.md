# 如何结合 AI 与 JYY 课程学好操作系统

> 主线课程：JYY《操作系统》(2026)  
> 适用情况：硬件基础较少，希望真正理解操作系统，而不只是看完视频或生成笔记。  
> 核心原则：**JYY 负责知识结构和实验方向，AI 负责个性化解释与反馈，自己负责回忆、判断和验证。**

## 1. 学习目标

学习操作系统不是为了背完所有寄存器、系统调用和内核代码，而是逐步获得三种能力：

1. **建立模型**：能用状态机、抽象、资源管理等概念解释程序怎样运行。
2. **追踪因果**：面对一个现象，能沿着“应用 → syscall → OS → 硬件”寻找原因。
3. **用证据验证**：会通过代码、调试工具和实验确认理解，而不是只相信流畅的文字解释。

```text
听懂概念
   ↓
能脱稿复述
   ↓
能用代码或工具观察
   ↓
能解释新现象、定位问题
```

前三讲暂时只要求达到“听懂并能复述”；随着课程和实验推进，再逐渐达到后两层。

## 2. 三方分工

### JYY 课程负责什么

- 提供课程的主线、概念顺序和取舍；
- 通过课堂演示说明抽象如何对应真实系统；
- 提供代码、实验和进一步阅读材料；
- 告诉我们哪些细节现在只需了解，哪些值得深入。

### AI 负责什么

- 根据当前基础重新解释陌生概念；
- 提炼每讲主线，校正 AI 字幕中的识别错误；
- 把复杂问题分解成更小的问题；
- 一题一题进行脱稿检查和针对性纠错；
- 帮助阅读代码、准备实验、解释报错和设计验证方法；
- 记录薄弱点，安排之后的复习。

### 自己必须负责什么

- 先尝试思考和回答，允许说“不知道”；
- 判断自己是“看着觉得懂”，还是能独立复述；
- 亲自运行关键代码和实验；
- 对 AI 的回答保持怀疑，要求来源或运行证据；
- 最终对自己的代码、结论和学习状态负责。

> AI 可以降低理解成本，但不能替代大脑完成记忆、建模和能力迁移。

## 3. 每一讲的标准学习流程

### 第一步：课前建立地图（5～10 分钟）

先快速浏览讲义标题，不追求理解所有术语，只回答：

1. 这一讲试图解决什么问题？
2. 它和上一讲有什么联系？
3. 出现了哪些完全陌生的词？

可以让 AI 先给出一份“零基础预览”，但此时不要让它展开全部细节。

推荐提问：

```text
这是 JYY 操作系统第 X 讲的讲义。我的硬件基础较少。
请先只告诉我：这一讲要解决什么问题、为什么要学、需要哪些前置概念。
不要逐段总结，也不要提前灌输太多术语。
```

### 第二步：选择性听课，而不是机械看完

视频中优先关注：

- 老师反复强调的主线和因果关系；
- 代码、调试器、终端等现场演示；
- 自己从讲义文字中无法理解的部分；
- 老师解释“为什么这样设计”的部分。

可以加速或跳过：

- 与主线关系不大的闲聊；
- 已经理解的重复铺垫；
- 补充选讲中自己暂时不需要的故事和历史细节。

遇到术语时先记下，不要每次都中断视频深入搜索。听完一个完整小节后，再集中补缺口。

### 第三步：整理重点笔记

每讲笔记至少应包含：

- 一句话主线；
- 关键概念及其解决的问题；
- 概念之间的因果关系；
- 一个简短的课后复述版本；
- 自测题及参考答案；
- 暂时不懂、等待后续课程验证的问题。

笔记以讲义为准，字幕只用于补充课堂解释。字幕是 AI 识别结果，不能直接当作可靠原文。

笔记不追求覆盖所有课堂内容。衡量标准是：**一周后还能靠它恢复这讲的知识结构。**

### 第四步：先盲答，再看答案

看完笔记后合上答案，一题一题回答自测题：

```text
盲答 → 指出具体缺口 → 重新解释 → 再复述
```

不要让 AI 一次抛出十几道题。一次只处理一道，并允许回答：

- 我知道；
- 我只能说出一部分；
- 我不清楚。

AI 纠错时，应先指出哪一句正确、哪一步因果缺失，再补充知识，而不是直接给出一篇全新标准答案。

### 第五步：把概念变成可观察的证据

对课程中的关键结论，尽量完成一次最小验证：

| 概念 | 可以观察什么 |
| --- | --- |
| 应用通过 syscall 使用 OS | 用 `strace` 观察 `read`、`write`、`execve` 等调用 |
| 程序是状态机 | 单步执行，观察变量、栈和 PC 的变化 |
| 固件加载启动代码 | 在模拟器中观察寄存器和约定内存地址 |
| 中断让 OS 重新获得控制权 | 后续实验中观察时钟中断与调度 |
| 多进程/多线程并发 | 反复运行并观察不同交错结果 |

AI 可以帮忙生成命令和解释输出，但必须由真实运行结果决定结论。

### 第六步：40 秒脱稿收尾

每讲结束时，不看笔记回答：

1. 这一讲的核心问题是什么？
2. 最重要的三个概念是什么？
3. 它们之间是什么因果关系？
4. 我还有哪里不确定？

能顺畅说清主线，才算完成本讲的第一轮学习。说不清时只补对应缺口，不必重看整节视频。

## 4. 如何判断一堂视频值不值得完整观看

### 建议完整或重点观看

- 属于 OS 主线课程；
- 有大量动态演示，文字笔记不容易还原；
- 自己读完讲义仍无法建立因果关系；
- 内容会直接影响实验。

### 可以加速、选看或只读笔记

- Hacking Day 等补充选讲；
- 主要是行业观点、故事或历史背景；
- 自己已经能回答自测题；
- 当前目标只是掌握后续课程的必要前置知识。

不要用“视频是否播放完毕”衡量进度。应使用“是否能复述、能否验证、是否会应用”衡量。

## 5. AI 回答的可信度规则

遇到冲突时，按以下优先级判断：

```text
课程讲义和课程代码
        ↓
亲自运行的实验结果
        ↓
官方手册、教材和权威文档
        ↓
老师课堂上的口头补充
        ↓
AI 字幕
        ↓
AI 未提供证据的解释
```

需要特别警惕的信号：

- AI 给出非常具体的寄存器、地址或命令，却没有说明体系结构和环境；
- 把简化教学模型说成任何机器都严格成立的事实；
- 只证明代码能够编译，就声称功能正确；
- 用流畅术语掩盖没有回答“为什么”；
- 把尚未亲自完成的实验记录成已经掌握。

推荐追问：

```text
请把回答分成：讲义明确说明的事实、你根据上下文做的推断、目前无法确认的部分。
如果能验证，请给我一个最小验证方法，但先不要替我宣称验证成功。
```

## 6. 使用 AI 阅读代码的正确方式

不要直接问“完整解释这份代码”，那通常会得到一篇看似全面、实际上记不住的说明。按以下顺序阅读：

1. 先问程序的输入、输出和总体目标；
2. 找到入口和最主要的状态；
3. 追踪一条最短执行路径；
4. 只在路径上遇到障碍时补相应语法或硬件知识；
5. 修改一个小地方，预测结果，再运行验证；
6. 最后脱离 AI 重新解释代码的主线。

推荐提问：

```text
不要逐行翻译。请先指出这段代码的入口、核心状态和一条最短执行路径。
我会逐步追问；每次只引入理解当前步骤必需的概念。
```

## 7. 使用 AI 做实验的边界

AI 可以：

- 帮助搭建环境、解释命令和读取错误信息；
- 把任务拆成小步骤；
- 建议断点、日志、断言和测试用例；
- 审查代码并提出可能的问题。

AI 不应该替代：

- 自己理解实验目标和关键机制；
- 自己预测代码执行结果；
- 自己确认测试真的覆盖了要求；
- 课程关于代码来源和学术诚信的规定。

每次接受 AI 修改后，至少能回答：

1. 改了什么？
2. 为什么可能有效？
3. 用什么证据确认有效？
4. 如果出问题，应该先检查哪里？

回答不了，就说明代码虽然存在，但还没有被自己接管。

## 8. 推荐的复习节奏

### 当天

- 完成重点笔记；
- 做自测题；
- 完成 40 秒复述；
- 标记仍不确定的问题。

### 2～3 天后

- 不看笔记复述主线；
- 随机回答 2～3 道旧题；
- 只复习答错部分。

### 一周后

- 把连续几讲串成一条因果链；
- 解释新一讲如何建立在旧知识上；
- 若课程已有实验，用实验现象反证或补强笔记。

例如前三讲可以串成：

```text
OS 为什么存在
  → 应用通过 syscall 请求 OS
  → OS 利用特权、中断和 I/O 管理硬件
  → firmware 在开机时把 OS 加载起来
```

## 9. 一讲是否“学完”的检查表

- [ ] 我能用一句话说出本讲主线。
- [ ] 我知道每个新名词解决什么问题。
- [ ] 我能解释至少一条完整因果链。
- [ ] 我已经盲答自测题，而不是直接阅读答案。
- [ ] 我能进行 40 秒脱稿复述。
- [ ] 涉及代码时，我观察过至少一个真实运行结果。
- [ ] 我区分了已经掌握、暂时理解和待验证内容。
- [ ] 我没有因为 AI 生成了笔记或代码，就把它算作自己已经掌握。

## 10. 默认协作约定

以后每完成一讲，可以按以下方式协作：

1. 提供讲义链接和字幕文件；
2. 以讲义为准，结合字幕提炼重点笔记；
3. 对字幕中的术语和识别错误进行校正；
4. 笔记直接放在当前操作系统目录，不再建立子目录；
5. 添加一句话主线、最低理解要求、40 秒复述、自测题与答案；
6. 整合并核对完成后删除原字幕；
7. 需要复习时，采用“一次一题的盲答 → 纠错 → 再复述”，不把生成笔记等同于已经掌握。

## 最终原则

**课程不是必须逐分钟观看的仪式，AI 也不是自动学习机。**

最有效的组合是：

```text
JYY 给主线和高质量材料
AI 提供个性化解释与反馈
实验提供真实证据
自己通过回忆和复述形成能力
```

只要这四部分都在，视频可以选择性观看，解释可以反复定制，学习进度也能真正由自己掌控。
