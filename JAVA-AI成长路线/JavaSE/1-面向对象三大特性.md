# 面向对象三大特性

---

## 核心

封装、继承、多态——Java 组织代码的三条基本原则。

---

## 封装（Encapsulation）

**定义**：将数据（字段）和操作数据的方法绑定在一起，对外隐藏内部实现细节。

```java
public class User {
    private String name;  // 私有字段，外部不可直接访问
    
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    // 对外只暴露 getter/setter，内部怎么存、怎么校验，外部不用管
}
```

**价值**：降低耦合、控制访问权限、内部实现可自由修改而不影响调用方。

**vibe coding 视角**：AI 生成的代码默认会用 private + getter/setter，你需要判断的是"这个字段该不该暴露出去"。

---

## 继承（Inheritance）

**定义**：子类复用父类的属性和方法，建立 is-a 关系。

```java
public class BaseEntity {
    private Long id;
    private Date createTime;
    public Long getId() { return id; }
}

public class Order extends BaseEntity {  // Order 自动拥有 id、createTime
    private BigDecimal amount;
}
```

**价值**：代码复用、统一公共行为。

**注意**：现代 Java 开发更推荐"组合优于继承"。继承层次超过三层通常意味着设计需要简化。

---

## 多态（Polymorphism）

**定义**：同一接口类型，运行时指向不同的实现，表现出不同的行为。

```java
// 声明时针对接口编程
List<String> list = new ArrayList<>();   // ArrayList 实现
List<String> list = new LinkedList<>();  // 换 LinkedList，代码不用改
```

```java
// 框架中更极致的体现：面向接口编程
public interface Payment {
    void pay(BigDecimal amount);
}

public class Alipay implements Payment { ... }
public class WechatPay implements Payment { ... }
// 运行时用哪个实现，由配置决定
```

**价值**：可扩展、可替换、松耦合。Spring 框架的 IoC 容器正是基于多态实现依赖注入。

**实际定位**：三个特性中在框架使用和 AI 辅助开发中最常接触的一个。框架的核心机制（如依赖注入、AOP 代理）都依赖多态实现。

---

## 项目关联

| 特性 | 关联位置 |
|------|---------|
| **封装** | entity / vo / dto 类的 private 字段 + getter 方法 |
| **继承** | 拦截器实现 `HandlerInterceptor` 接口；entity 类继承公共基类 |
| **多态** | `JwtAuthInterceptor` / `RateLimitInterceptor` / `ProcessTimeInterceptor` 实现同一接口，Spring 按需加载生效 |
