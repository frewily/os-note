# 面向对象三大特性

---

## 一句话核心

封装、继承、多态，就是 Java 组织代码的三条基本原则——让代码好读、好改、好用。

---

## 为什么用

你在 vibe coding 中干的事，本质上就是**跟 AI 描述需求，让它生成代码**。如果连这三个东西都说不清楚，你跟 AI 的沟通会非常低效。

例子：

> 写一段代码，支持多种支付方式

AI 可能给你写一堆 if-else。但如果你说：

> 用策略模式实现多种支付方式，每个支付方式是一个独立的类

这就是在利用**多态**来让 AI 生成更高质量的代码。**你不知道多态，你就不知道有这种更好的写法。**

你的工作流是：

```
我描述需求 → AI 生成代码 → 我看懂并决定"行不行"
```

这三个特性就是你判断"AI 写得行不行"的基础标准。

---

## 关键理解

### 封装 — 把东西藏好

**本质**：一个类的内部数据不让外面直接改，只能通过它提供的方法来操作。

```
类 A（提供 get/set 方法） ← 外部代码通过方法访问，不能直接碰内部数据
```

在 vibe coding 中，AI 生成的代码基本都会帮你写好 private + getter/setter，你能看懂这层结构就行。真正需要你判断的是："这个字段该不该暴露出去？"

### 继承 — 复用代码

**本质**：子类拿父类的东西直接用。

```
父类（通用逻辑） → 子类（复用父类 + 扩展自己的）
```

**但要注意**：现代 Java 开发更推荐"组合优于继承"，也就是"持有"而不是"继承"。AI 生成的代码如果继承层次太深（三层以上），你该意识到这可能是坏设计。

### 多态 — 同一套接口，不同行为

**本质**：你写代码时针对"接口"编程，具体干活的是哪个实现类，运行时才决定。

这是三个里面**在 vibe coding 中最需要理解的一个**——因为框架（Spring）到处都在用多态。

```java
// 你只依赖 List 这个"接口"
List<String> list = new ArrayList<>();
// 如果想换实现，改右边就行：
List<String> list = new LinkedList<>();
```

Spring 里更夸张——你甚至不用改代码，改个配置就换了实现。这就是多态的终极形态。

## 代码看一眼

```java
// 封装：外部不知道你内部怎么存的
public class User {
    private String name;
    
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}

// 继承：子类复用父类的公共能力
public class BaseEntity {
    private Long id;
    public Long getId() { return id; }
}

public class Order extends BaseEntity {  // Order 自动有了 id
    private BigDecimal amount;
}

// 多态：同一方法在不同类里有不同行为
public interface Payment {
    void pay(BigDecimal amount);
}

public class Alipay implements Payment {
    public void pay(BigDecimal amount) {
        // 支付宝逻辑
    }
}

public class WechatPay implements Payment {
    public void pay(BigDecimal amount) {
        // 微信逻辑
    }
}
```

## 你的项目里

| 特性 | 在项目中哪里 |
|------|------------|
| **封装** | 几乎每个 entity/vo/dto 类都用 private 字段 + getter |
| **继承** | 你的拦截器实现 `HandlerInterceptor` 接口就是继承思想；entity 类继承公共字段（如果有 BaseEntity） |
| **多态** | `JwtAuthInterceptor` / `RateLimitInterceptor` / `ProcessTimeInterceptor` 都实现同一个 `HandlerInterceptor` 接口，Spring 根据配置决定哪个拦截器生效——这就是多态 |
