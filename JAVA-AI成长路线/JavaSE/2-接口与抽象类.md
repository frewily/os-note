# 接口与抽象类

---

## 一句话核心

抽象类定义"你是什么"，接口定义"你能干什么"——在 AI 辅助开发中，你大多数时候只需要接口。

---

## 为什么用

你在 vibe coding 中经常需要跟 AI 说：

> 写一个支付接口，支持支付宝和微信两种实现

"接口"这个词你必须说清楚，不然 AI 不知道怎么组织代码。如果你分不清接口和抽象类，你可能会让 AI 写出不合适的设计。

**另一个场景**：AI 生成的代码里有 `implements` 和 `extends`，你要能看懂它为什么用这个而不是那个。

---

## 关键理解

### 接口（Interface）— can-do

定义一组能力/规范，不提供具体实现。Java 8 之后接口里可以有 default 方法（带默认实现），但核心定位没变。

```java
public interface Payable {
    void pay(BigDecimal amount);  // 只定义"能付钱"，不 care 怎么付
}
```

**在 vibe coding 中**：跟 AI 说"定义一个 XX 接口"，AI 就会生成一个 interface。Spring 里你天天见到——`UserService` 是接口，`UserServiceImpl` 是实现。

### 抽象类（Abstract Class）— is-a

定义"这是一类什么东西"，并提供一些通用的骨架代码，子类填空。

```java
public abstract class Animal {
    public void eat() { System.out.println("吃东西"); }  // 通用
    public abstract void makeSound();                    // 子类自己决定
}
```

**在 vibe coding 中**：抽象类你用到的场景很少。大多数时候接口就够了。

### 怎么选（给 AI 写 prompt 时）

```
情况                          → 用什么
定义能力/规范，不关心实现      → 接口
多个类共享代码，有通用逻辑     → 抽象类
能做多个不同的事情             → 接口（一个类可以实现多个接口）
```

**一张图记住**：

```
接口：你实现了它，就能干某件事（可插拔）
抽象类：你继承了它，就是某一类东西（血缘关系）
```

## 代码看一眼

```java
// 接口：定义"能登录"的能力
public interface Loginable {
    String login(String username, String password);
}

// 抽象类：定义"基础认证"的骨架
public abstract class BaseAuth {
    public void logAttempt(String username) {
        System.out.println(username + " 尝试登录");
    }
    public abstract boolean validate(String token);
}

// 具体实现
public class JwtAuth extends BaseAuth implements Loginable {
    public String login(String username, String password) {
        logAttempt(username);
        // 登录逻辑
        return "jwt_token...";
    }
    
    public boolean validate(String token) {
        // 验证逻辑
        return true;
    }
}
```

你看，`JwtAuth` 继承了 `BaseAuth`（拿到 logAttempt 方法），实现了 `Loginable`（承诺自己能登录）。一个类同时做了两件事。

## 你的项目里

| 概念 | 在项目中哪里 |
|------|------------|
| **接口** | `HandlerInterceptor` 就是接口——定义了 `preHandle`、`postHandle`、`afterCompletion` 三个方法，你的拦截器去实现它 |
| **接口** | 你的 Service 层大概率也是 `XxxService` 接口 + `XxxServiceImpl` 实现——Spring 的常规写法 |
| **抽象类** | 如果你的项目里有多个拦截器共用逻辑（比如都要记录请求时间），可以用抽象类抽取公共代码，子类各自实现具体拦截逻辑 |
