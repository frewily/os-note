# 反射

---

## 核心

反射是在运行时获取类的信息并操作它的能力——不知道具体类名也能创建对象、调用方法、访问字段。

---

## 为什么需要反射

正常情况下，写代码时就知道要操作哪个类：

```java
User user = new User();          // 编译时就知道是 User
user.getName();                  // 编译时就知道有这个字段
```

但框架需要在**编译时完全不知道类名的情况下**操作对象：

```java
// Spring 需要做的事：
// 从配置中读到 "com.example.UserService"
// 动态创建这个类的对象
// 注入它的依赖
// 把它放到容器中

// 这些在写 Spring 源码的时候都不知道 "UserService" 是什么
// 必须靠反射在运行时搞定
```

**所以**：框架（Spring、MyBatis）是所有能力的基础，不理解反射就理解不了框架。

---

## 核心 API

```java
// 1. 获取 Class 对象（反射的入口）
Class<?> clazz = Class.forName("com.example.User");
Class<?> clazz = User.class;
Class<?> clazz = user.getClass();

// 2. 创建实例
Object obj = clazz.getDeclaredConstructor().newInstance();

// 3. 获取方法并调用
Method method = clazz.getMethod("getName");
String name = (String) method.invoke(obj);

// 4. 获取字段并赋值
Field field = clazz.getDeclaredField("name");
field.setAccessible(true);    // 即使是 private 也能访问
field.set(obj, "张三");

// 5. 获取注解
Service anno = clazz.getAnnotation(Service.class);
```

---

## 反射的典型应用链

```java
// 这就是 Spring 处理 @Service 的简化版逻辑
// 1. 扫描包，找到所有带 @Service 的类
Class<?> clazz = ...;  // "com.example.UserService"

// 2. 检查是否有 @Service 注解
if (clazz.isAnnotationPresent(Service.class)) {
    // 3. 通过反射创建实例
    Object instance = clazz.getDeclaredConstructor().newInstance();
    
    // 4. 查找带有 @Autowired 的字段，注入依赖
    for (Field field : clazz.getDeclaredFields()) {
        if (field.isAnnotationPresent(Autowired.class)) {
            Object dependency = getBean(field.getType());
            field.setAccessible(true);
            field.set(instance, dependency);
        }
    }
    
    // 5. 存入容器
    beanContainer.put(clazz.getName(), instance);
}
```

## 反射的代价

- **性能较差**：比直接调用慢（有额外的类型检查和安全检查）
- **有安全风险**：可以访问 private 字段和方法，破坏了封装

**实际使用**：框架在启动时使用反射完成初始化，运行时性能影响通过缓存优化（方法对象、字段对象会被缓存复用），对业务代码几乎没有影响。

---

## vibe coding 视角

- 反射是理解 Spring Boot **自动配置、依赖注入、AOP** 原理的关键
- 日常业务代码中几乎不会主动写反射代码，也不需要写
- AI 生成的工具类（如 JSON 解析器、通用 Mapper）中可能出现反射，能够看懂即可
- 重点在于理解"为什么需要反射"以及"它在 Spring 中起什么作用"

## 项目关联

| 场景 | 说明 |
|------|------|
| **Spring IoC** | 扫描包 → 反射创建 Bean → 反射注入依赖 |
| **Spring AOP** | 运行时通过反射 / 代理生成目标类的代理对象 |
| **@Transactional** | 通过反射获取方法上的注解信息，决定是否开启事务 |
| **JSON 序列化** | Jackson / Gson 通过反射读取对象的字段名和值 |
