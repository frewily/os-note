# Redis 知识点 — 编写规则

> 定位：AI 辅助开发（vibe coding）视角下的 Redis 核心知识梳理。
> 不是面试八股，是后端开发中必须理解的内存数据库原理与用法。

---

## 面向读者

已具备 Redis 基础使用经验，需要深入理解数据结构特性、缓存策略、以及项目中的落地场景。

---

## 筛选标准

### ✅ 收录

- 知道 Redis 的 5 种数据类型及适用场景
- 理解缓存的三种常见问题（穿透/击穿/雪崩）
- 知道 Redis 为什么快（内存 + IO 多路复用，概念级）
- 项目中 Redis 的实际用法

### ❌ 不收录

- Redis 安装配置、主从哨兵集群搭建
- 面试级源码细节（如 SDS 扩容策略、跳表实现细节）
- 特定版本的行为差异
