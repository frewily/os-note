# 五种数据类型

---

## 核心

Redis 有 5 种核心数据类型，选对类型比写好代码更重要——不同类型对应不同的操作特性和使用场景。

---

## String——字符串

```bash
SET key value           # 存
GET key                 # 取
INCR key                # 原子加一
INCRBY key 10           # 原子加 N
EXPIRE key 60           # 设置过期时间（秒）
SETEX key 60 value      # 存 + 设过期时间（一条命令）
```

**底层**：SDS（动态字符串），自动扩缩容。

**场景**：缓存、计数器、分布式锁、Token 存储。

---

## Hash——哈希

```bash
HSET user:1001 name "张三"        # 存单个字段
HSET user:1001 age "18"           # 追加字段
HGET user:1001 name               # 取单个字段
HGETALL user:1001                 # 取所有字段
HDEL user:1001 age                # 删字段
```

**场景**：对象/实体存储（用户信息、会话信息）。

Hash 适合存对象——改一个字段不用像 String 那样整个序列化/反序列化。

---

## List——列表

```bash
LPUSH messages "msg1"             # 左插
RPUSH messages "msg1"             # 右插
LPOP messages                     # 左弹
RPOP messages                     # 右弹
LRANGE messages 0 -1              # 取全部
LLEN messages                     # 长度
LTRIM messages 0 99               # 截断（保留前 100 条）
```

**场景**：消息队列、最新列表（如聊天记录）、时间线数据。

**vibe coding 视角**：`LTRIM` 是 List 做固定长度队列的关键，AI 生成的代码中如果忘了加 LTRIM，List 会无限增长。

---

## Set——集合

```bash
SADD tags "java" "redis"          # 添加
SMEMBERS tags                     # 取全部
SISMEMBER tags "java"             # 判断是否存在
SINTER set1 set2                  # 交集
SUNION set1 set2                  # 并集
SDIFF set1 set2                   # 差集
```

**场景**：去重、标签系统、共同好友/共同关注。

---

## ZSet（Sorted Set）——有序集合

```bash
ZADD leaderboard 100 "user:1"     # 添加（分数 + 成员）
ZADD leaderboard 200 "user:2"
ZINCRBY leaderboard 50 "user:1"   # 加分
ZREVRANGE leaderboard 0 9         # 取前 10 名（按分数降序）
ZRANK leaderboard "user:1"        # 查排名
ZSCORE leaderboard "user:1"       # 查分数
```

**场景**：排行榜、延时队列（分数用时间戳）、限流计数。

---

## 速查表

| 类型 | 底层结构 | 特点 | 典型场景 |
|------|---------|------|---------|
| **String** | SDS | 最基础，能存任何东西 | 缓存、计数器、Token |
| **Hash** | dict / ziplist | 适合存对象，字段级操作 | 用户信息、会话 |
| **List** | quicklist | 有序可重复，头尾操作快 | 消息队列、聊天记录 |
| **Set** | dict / intset | 无序不重复，集合运算 | 去重、标签、共同好友 |
| **ZSet** | skiplist + dict | 按分数排序，可做排行榜 | 排行榜、延时队列 |

## 项目关联

| 类型 | 在项目中的用途 |
|------|---------------|
| **String** | Token 存储 `JWT:{userId}`、短信验证码、缓存 JSON 字符串 |
| **Hash** | 用户会话信息 `session:{userId}`、模型配置参数 |
| **List** | 对话历史消息 `chat:{sessionId}:messages`、消息队列 |
| **Set** | 用户权限标签、黑名单 |
| **ZSet** | 用户积分/活跃度排行、限流窗口记录 |
