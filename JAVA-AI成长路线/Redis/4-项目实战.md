# 项目实战

---

## 核心

Redis 在你的 AI 客服项目中承担多个角色——缓存、限流、历史对话、Token 管理，每种角色用的数据结构和策略不同。

---

## 角色一：缓存（Cache-Aside）

**模式**：读请求先查 Redis，没有再查 MySQL，查完后写回 Redis。

```java
public AiConfig getConfig(String key) {
    // ① 先读 Redis
    String cached = redisTemplate.opsForValue().get("config:" + key);
    if (cached != null) {
        return JSON.parseObject(cached, AiConfig.class);
    }
    
    // ② Redis 没有，查数据库
    AiConfig config = configMapper.selectByKey(key);
    
    // ③ 写回 Redis，设置过期时间
    if (config != null) {
        redisTemplate.opsForValue().set(
            "config:" + key, 
            JSON.toJSONString(config), 
            1, TimeUnit.HOURS
        );
    }
    return config;
}
```

**注意点**：
- 过期时间加随机值，防止缓存雪崩
- 更新数据时**先更新数据库，再删除缓存**（不是先删缓存再更新数据库，避免并发问题）

## 角色二：限流（滑动窗口）

**原理**：用 ZSet 记录每个用户的时间戳，统计窗口内的请求数。

```java
public boolean isRateLimited(Long userId, int maxRequests, int windowSeconds) {
    String key = "rate:user:" + userId;
    long now = System.currentTimeMillis();
    long windowStart = now - windowSeconds * 1000L;
    
    // ① 删除窗口外的旧记录（保持 ZSet 大小可控）
    redisTemplate.opsForZSet().removeRangeByScore(key, 0, windowStart);
    
    // ② 统计当前窗口内的请求数
    Long count = redisTemplate.opsForZSet().count(key, windowStart, now);
    
    if (count >= maxRequests) {
        return true;  // 超过限制
    }
    
    // ③ 记录当前请求
    redisTemplate.opsForZSet().add(key, String.valueOf(now), now);
    
    // ④ 设置过期时间，防止 key 永远不清理
    redisTemplate.expire(key, windowSeconds, TimeUnit.SECONDS);
    
    return false;
}
```

用 INCR + EXPIRE 的简化版本也可以（精度稍低但实现简单）：

```java
public boolean isRateLimitedSimple(Long userId, int maxRequests, int windowSeconds) {
    String key = "rate:user:" + userId;
    
    // INCR 原子递增
    Long count = redisTemplate.opsForValue().increment(key);
    
    // 第一次设置时设过期时间
    if (count == 1) {
        redisTemplate.expire(key, windowSeconds, TimeUnit.SECONDS);
    }
    
    return count > maxRequests;
}
```

## 角色三：历史对话管理

**结构**：用 List 存储对话消息，每条消息是一个 JSON 字符串。

```java
public class ChatMessage {
    private String role;       // "user" 或 "assistant"
    private String content;    // 消息内容
    private Long timestamp;    // 时间戳
}

// 存储消息
public void saveMessage(String sessionId, ChatMessage message) {
    String key = "chat:" + sessionId + ":messages";
    
    // 追加到 List 末尾
    redisTemplate.opsForList().rightPush(key, JSON.toJSONString(message));
    
    // 只保留最近 N 条（控制上下文窗口大小，避免无限增长）
    int maxMessages = 50;  // 根据模型上下文窗口调整
    redisTemplate.opsForList().trim(key, -maxMessages, -1);
    
    // 更新过期时间（对话 24 小时无人访问自动清理）
    redisTemplate.expire(key, 24, TimeUnit.HOURS);
}

// 获取最近 N 条对话历史
public List<ChatMessage> getRecentMessages(String sessionId, int count) {
    String key = "chat:" + sessionId + ":messages";
    List<String> jsonList = redisTemplate.opsForList().rightPop(key, count);
    // 注意：rightPop 会移除元素，如果要只读应该用 range
    // List<String> jsonList = redisTemplate.opsForList().range(key, -count, -1);
    return jsonList.stream()
        .map(json -> JSON.parseObject(json, ChatMessage.class))
        .collect(Collectors.toList());
}
```

**注意**：
- `LTRIM`（Java 中对应 `trim`）控制 List 长度，防止无限增长
- 给每个对话设置过期时间，长时间不活跃的对话自动清理
- 读取历史时用 `range`（不移除），不要用 `pop`（会移除）

## 角色四：Token 用量追踪

```java
// 记录每次 Token 消耗
public void recordTokenUsage(Long userId, int tokens) {
    String dailyKey = "token:daily:" + userId + ":" + LocalDate.now();
    
    // 累计当日消耗
    redisTemplate.opsForValue().increment(dailyKey, tokens);
    
    // 设置过期（第二天自动失效）
    redisTemplate.expire(dailyKey, 2, TimeUnit.DAYS);
    
    // 同时更新总消耗排行
    redisTemplate.opsForZSet().incrementScore("token:ranking", userId.toString(), tokens);
}

// 检查是否超限
public boolean checkTokenLimit(Long userId, int dailyLimit) {
    String key = "token:daily:" + userId + ":" + LocalDate.now();
    String used = redisTemplate.opsForValue().get(key);
    if (used == null) return true;
    return Integer.parseInt(used) < dailyLimit;
}
```

## 角色五：会话状态管理

```java
// 用户登录后，存储会话信息
public void createSession(Long userId, String token) {
    String sessionKey = "session:" + userId;
    
    // 用 Hash 存储会话信息
    Map<String, Object> session = new HashMap<>();
    session.put("token", token);
    session.put("loginTime", System.currentTimeMillis());
    session.put("status", "online");
    
    redisTemplate.opsForHash().putAll(sessionKey, session);
    redisTemplate.expire(sessionKey, 7, TimeUnit.DAYS);
}

// 每次请求刷新过期时间
public void refreshSession(Long userId) {
    String key = "session:" + userId;
    redisTemplate.expire(key, 7, TimeUnit.DAYS);
}
```

## Redis 在你项目中的完整角色

| 角色 | 数据类型 | 说明 |
|------|---------|------|
| **缓存** | String | 缓存模型配置、热点数据 |
| **限流** | String / ZSet | INCR + EXPIRE 或 ZSet 滑动窗口 |
| **历史对话** | List | 按时间顺序存储聊天消息，LTRIM 控制长度 |
| **Token 追踪** | String + ZSet | 日用量统计 + 用户排行 |
| **会话管理** | Hash | 存储用户登录状态、会话信息 |
