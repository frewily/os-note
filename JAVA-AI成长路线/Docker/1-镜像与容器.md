# 镜像与容器

---

## 核心

**镜像**是打包好的环境（类），**容器**是镜像跑起来的实例（对象）。一个镜像可以启动多个容器。

---

## 镜像操作

```bash
# 拉取镜像
docker pull mysql:8.0
docker pull openjdk:17-jdk

# 查看本地镜像
docker images

# 删除镜像
docker rmi mysql:8.0
```

**镜像仓库**：Docker Hub（hub.docker.com），找镜像的首选。

---

## 容器操作

```bash
# 运行容器
docker run -d --name my-mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=123456 mysql:8.0
#   -d           后台运行
#   --name       容器名称
#   -p 3306:3306 主机端口:容器端口
#   -e           环境变量

# 查看运行中的容器
docker ps
# 查看所有容器（含已停止的）
docker ps -a

# 停止容器
docker stop my-mysql

# 启动已停止的容器
docker start my-mysql

# 进入容器内部
docker exec -it my-mysql bash
docker exec -it my-mysql mysql -uroot -p

# 查看容器日志
docker logs my-mysql
docker logs -f my-mysql    # 实时跟踪日志

# 删除容器
docker rm my-mysql
docker rm -f my-mysql      # 强制删除运行中的容器
```

---

## 端口映射

```bash
# -p 主机端口:容器端口
# 主机端口不能重复，容器端口是应用本身的端口
docker run -d --name my-redis -p 6379:6379 redis:7
docker run -d --name my-app -p 8080:8080 my-app:latest
```

**注意**：主机上的每个端口只能映射一个容器。如果你同时跑两个 MySQL，必须用不同主机端口（如 3306 和 3307）。

---

## 数据持久化

```bash
# 不挂载卷 → 容器删了数据就没了
docker run -d --name my-mysql mysql:8.0

# 挂载卷 → 数据保存在主机上，容器删了数据还在
docker run -d --name my-mysql \
  -v /data/mysql:/var/lib/mysql \
  mysql:8.0
```

**需要持久化的数据**：数据库文件、日志文件、上传的文件。

---

## 查看资源占用

```bash
docker stats           # 实时查看所有容器的 CPU/内存/网络
docker stats my-app    # 查看指定容器
```
