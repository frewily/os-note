# 文本处理

---

## 核心

服务端排查问题、看日志时最常用的就是 grep —— 在一堆文本中搜你要的东西。

---

## grep——搜索

```bash
# 基本用法
grep "关键字" file.log                    # 在文件中搜索关键字
grep "ERROR" app.log                      # 搜日志中的错误
grep -i "error" app.log                   # 忽略大小写
grep -n "error" app.log                   # 显示行号
grep -c "error" app.log                   # 统计匹配行数

# 搜多个文件
grep "error" *.log                        # 当前目录下所有 log 文件
grep -r "error" /var/log/                 # 递归目录搜索

# 只看包含关键字的文件
grep -l "error" *.log                     # 只输出文件名

# 多看几行上下文
grep -A5 "NullPointerException" app.log   # 匹配行 + 后 5 行
grep -B5 "NullPointerException" app.log   # 匹配行 + 前 5 行
grep -C5 "NullPointerException" app.log   # 匹配行 + 前后各 5 行
```

## vim——文件编辑

```bash
# 打开文件
vim app.log

# 三种模式
普通模式 → i → 插入模式（编辑文本）
普通模式 → : → 命令模式（输入命令）
按 ESC 回到普通模式

# 常用操作
:w            # 保存
:q            # 退出
:wq           # 保存并退出
:q!           # 不保存强制退出
/关键字       # 搜索
n             # 下一个匹配
N             # 上一个匹配
dd            # 删除当前行
yy            # 复制当前行
p             # 粘贴
```

**够用就行**：`vim 文件 → i 编辑 → ESC → :wq 保存退出`。

---

## sed——替换

```bash
# 把文件中的 old 替换为 new
sed -i 's/old/new/g' file.txt

# 只替换第 3 行
sed -i '3s/old/new/g' file.txt
```

---

## awk——按列处理

```bash
# 取出第 2 列
cat file.log | awk '{print $2}'

# 按逗号分割
cat data.csv | awk -F',' '{print $1, $3}'
```
