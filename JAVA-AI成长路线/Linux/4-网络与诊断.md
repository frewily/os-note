# 网络与诊断

---

## 核心

服务器上排查问题最常用的就是 curl 和 ping——看服务通不通、接口能不能调。

---

## curl——发起 HTTP 请求

```bash
# GET 请求
curl http://localhost:8080/api/users
curl -X GET http://localhost:8080/api/users

# POST 请求（带 JSON 体）
curl -X POST http://localhost:8080/api/users \
  -H "Content-Type: application/json" \
  -d '{"name":"张三","email":"test@test.com"}'

# 带 Token
curl http://localhost:8080/api/users \
  -H "Authorization: Bearer xxx"

# 只看响应头
curl -I http://localhost:8080

# 显示完整请求响应（调试用）
curl -v http://localhost:8080
```

**典型场景**：部署后验证接口是否正常。

---

## ping——检查网络连通

```bash
ping baidu.com              # 看能不能上网
ping 192.168.1.1            # 看网关能不能通
ping -c 4 10.0.0.1          # 只发 4 个包（按 Ctrl+C 停止）
```

**注意**：ping 只能检查 IP 通不通，不能检查端口。服务器上可能禁 ping。

---

## telnet——检查端口

```bash
telnet 192.168.1.100 3306   # 检查 MySQL 端口能不能连
telnet localhost 8080       # 检查本地服务端口

# 连不上 = 端口没开、防火墙拦住、或服务没启动
# 连上了 = 端口通了（按 Ctrl+] 然后 quit 退出）
```

---

## netstat——查看网络连接

```bash
netstat -tlnp               # 查看所有监听中的端口（最常用）
# -t  TCP
# -l  监听中的
# -n  显示数字地址
# -p  显示进程信息

# 输出示例
# Proto Recv-Q Send-Q Local Address  Foreign Address  State  PID/Program
# tcp   0      0      0.0.0.0:8080   0.0.0.0:*        LISTEN 12345/java
```

---

## 其他诊断命令

```bash
# DNS 解析
nslookup baidu.com          # 看域名解析到哪个 IP
dig baidu.com               # 更详细的 DNS 信息

# 路由追踪
traceroute baidu.com        # 看请求经过哪些节点

# 下载文件
wget http://example.com/file.zip

# 查看网络接口
ip addr                     # 看本机 IP 地址
ifconfig                    # 老命令
```
