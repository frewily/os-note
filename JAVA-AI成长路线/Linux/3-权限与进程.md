# 权限与进程

---

## 文件权限

```bash
# 查看权限
ls -l app.jar
# -rwxr-xr-x 1 root root 12345 Jul 19 10:00 app.jar
# ↑↑↑↑↑↑↑↑↑
# 类型 + 三组权限（所有者/组/其他）

# 每组权限含义
r = 4（读）
w = 2（写）
x = 1（执行）

# 644 = rw-r--r--  （文件默认）
# 755 = rwxr-xr-x（可执行文件/目录默认）
# 600 = rw-------  （配置文件，只让所有者看）

chmod 755 app.jar          # 设为可执行
chmod +x app.jar           # 加执行权限（常用）
chmod -R 755 /app/dir      # 递归改目录权限

chown user:group file      # 改文件所有者
chown -R user:group dir    # 递归改目录所有者
```

## 进程查看

```bash
# 查看所有进程
ps aux
ps aux | grep java          # 只看 Java 进程

# 查看进程树
ps -ef

# 动态监控（最常用）
top                         # 按 q 退出
top -p 1234                 # 只看指定 PID

# 更友好的监控
htop                        # 需要安装，比 top 直观
```

**top 输出怎么看**：

```
top - 10:00:00 up 3 days    — 运行时间
%Cpu: 15.0 us, 5.0 sy      — CPU 使用率（user/system）
KiB Mem: 8000000 total      — 内存总量
```

## 进程管理

```bash
# 杀进程
kill 1234                   # 正常退出
kill -9 1234                # 强制杀掉（收不到 SIGTERM，慎用）

# 找进程
ps aux | grep java          # 找到 PID
lsof -i :8080               # 谁占用了 8080 端口
lsof -i :8080 | grep LISTEN # 只看监听状态的

# 后台运行
nohup java -jar app.jar &   # 后台运行，退出终端不停止
nohup java -jar app.jar > app.log 2>&1 &   # 并输出日志到文件
```

## 常用技巧

```bash
# 端口占用了怎么办
lsof -i :8080               # 查谁占了 8080
kill -9 <PID>               # 杀掉

# 进程卡住了怎么办
top                         # 看哪个进程 CPU/内存高
kill -9 <PID>               # 杀掉

# 日志太大了怎么办
tail -100 app.log           # 只看最后 100 行
grep "ERROR" app.log        # 只搜错误
```
