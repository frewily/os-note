# 文件与目录

---

## 核心

Linux 一切皆文件。常用操作就是浏览、创建、复制、移动、删除。

---

## 目录操作

```bash
pwd                     # 当前路径
ls                      # 列出文件
ls -l                   # 详细列表（权限、大小、时间）
ls -a                   # 包含隐藏文件（.开头的）
ls -lh                  # 文件大小显示为人类可读（K/M/G）

cd /home                # 进入目录
cd ~                    # 回用户主目录
cd -                    # 回上一个目录
cd ..                   # 上一级

mkdir dir               # 创建目录
mkdir -p a/b/c          # 创建多级目录

rmdir dir               # 删除空目录
rm -rf dir              # 删除目录及其内容（⚠️ 危险）
```

---

## 文件操作

```bash
touch file.txt          # 创建空文件
cp file1.txt file2.txt  # 复制
cp -r dir1 dir2         # 复制目录
mv file.txt /tmp/       # 移动
mv old.txt new.txt      # 重命名
rm file.txt             # 删除
rm -f file.txt          # 强制删除（不提示）

# 查看文件
cat file.txt            # 全部内容（适合短文件）
less file.txt           # 分页查看（按 q 退出）
head -20 file.txt       # 前 20 行
tail -50 file.txt       # 后 50 行
tail -f app.log         # 实时跟踪日志（最常用）
```

---

## 查找文件

```bash
find / -name "app.log"          # 按文件名查找
find . -name "*.java"           # 找当前目录下所有 Java 文件
find . -size +10M               # 找大于 10M 的文件
find . -mtime -7                # 最近 7 天修改过的文件

locate app.log                  # 更快（基于索引，需要定期更新）
```

---

## 磁盘

```bash
df -h                   # 查看磁盘使用情况
du -sh *                # 查看当前目录下每个文件/文件夹的大小
du -sh /var/log         # 查看指定目录总大小
```
