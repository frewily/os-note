### 今天学习到的知识

- HTTP 是应用层协议，负责规定请求和响应的内容格式。
- TCP 负责可靠、有序地传输字节流，并使用端口号区分具体应用。
- IP 负责标识主机，并让数据包跨网络找到目标主机。
- 以太网负责局部网络中的数据帧传输，使用 MAC 地址识别网卡。
- 访问外网时，IP 头中的目标地址仍是远程服务器 IP，但当前以太网帧的目标 MAC 通常是默认网关的 MAC。
- TCP 首部会携带源端口、目标端口、序列号、确认号和控制标志等信息；IP 层再添加源 IP 和目标 IP；链路层再添加 MAC 地址。
- 数据封装关系：HTTP 数据 → TCP 段 → IP 包 → 以太网帧。
- `200` 表示请求成功，`301` 表示永久重定向，`404` 表示资源不存在，`500` 表示服务器内部处理错误。
- 收到 `404` 说明某个 HTTP 服务已经返回了响应，通常表示 TCP 连接已经建立；TCP 失败时一般收不到 HTTP 状态码。
