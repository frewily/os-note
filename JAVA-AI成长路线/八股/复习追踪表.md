## 2026-09-22 D13 首学效果总结

### 总体评价

能够脱稿说明 RDB/AOF、内存淘汰策略和缓存三大问题，整体理解较好；过期删除策略经过纠正后能够复述，但术语和机制细节仍需在第 2 天复习时巩固，因此 D13 暂记为 🟡。

### 已基本掌握

- RDB 快照与 AOF 写命令日志的核心区别；
- `maxmemory-policy`、`noeviction`、LRU/LFU/TTL/Random；
- `allkeys` 与 `volatile` 的淘汰范围；
- 缓存穿透、击穿、雪崩的区别和主要解决方案。

### 需要重点复习

- Redis 使用“惰性删除 + 定期删除”，定期删除是周期性抽查，不是扫描全部 key；
- LRU 是最近最少使用，LFU 是访问频率最低；
- 缓存雪崩除随机 TTL 外，还应想到高可用、多级缓存、限流和降级。
