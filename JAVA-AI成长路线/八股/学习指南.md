# 八股学习指南

> 目标：用最高效率掌握中厂实习面试所需的八股知识
> 方法："先答再补，出声才算数"
> 定位：这不是教科书，这是"面试话术训练手册"

---

## 一、核心认知：八股的本质

八股不是"知识"。面试官问八股，不是为了考你背得多熟，而是为了：

1. **快速判断基础扎不扎实** —— 一个人连 HashMap 原理都说不清楚，大概率代码也写不好
2. **找一个聊得来的队友** —— 问八股的同时看你沟通表达是否清晰
3. **筛掉完全没准备的人** —— 八股是"只要你准备了就不会丢分"的送分题

所以八股的正确心态是：**这是面试里最不需要焦虑的部分——因为它是可以靠方法攻下来的。**

## 二、学习方法：四步循环

这是你每天学八股的标准流程，**一步都不能少**。

### 第一步：选题（每天 1 道）

从「八股题集」里按顺序每天选 1 道题。不多选，就 1 道。

### 第二步：盲答（30 秒）

**先不要看任何资料。** 强迫自己回忆：

- 我知道哪些点？
- 哪些点我不确定？

想不起来是正常的——这个"卡壳感"会让你的大脑记住：**哦，这个我还不会，等会儿要认真看。**

### 第三步：看答案，提炼"3-4 个关键点"

看答案时不要逐字背，**只记骨架**。

例如 HashMap put 流程，你只需要记住：

```
1. 计算 hash → 定位 bucket → 空就直接放
2. 不空 → 比较 key → 相同就覆盖
3. 不同就拉链表 → >8 转红黑树
4. 检查 size > threshold → 扩容翻倍
```

其他细节（红黑树怎么旋转、扩容时怎么 rehash）都是**第二遍才需要**的。

### 第四步：说出来（最重要！）

**对着空气、镜子、或者你养的花，把这道题讲一遍。**

你会发现：
- 第一次说：磕巴，忘点
- 第二次说：顺了，但缺细节
- 第三次说：流畅了

**能说出来的东西才是你的，脑子里想的不算。**

## 三、复习节奏：防止遗忘

绝大多数人背八股的最大问题是**只背不复习**。你需要遵循这个节奏：

| 背完后的时间 | 需要做什么 |
|------------|-----------|
| **当天晚上** | 睡前在心里默一遍今天背的题 |
| **第二天** | 早上刷牙时再默一遍 |
| **第四天** | 快速过一遍关键词 |
| **第七天** | 对着题集再出声说一遍 |

> **简单操作**：手机备忘录里按日期记"今天背了啥"，
> 或者用 Anki / 任何卡片工具，每天抽 10 张过一遍。

## 五、常见误区

### ❌ 误区 1：追求一次背完再也不忘

不存在。八股就是要反复过。**每道题至少在不同时间点说 3 遍。**

### ❌ 误区 2：看大段博客文章代替背题

一篇博客几千字，看了两小时，关上问你"讲了啥"——说不出来。**直接看面试题 + 精简答案，不要看背景知识长文。**

### ❌ 误区 3：用"看"代替"说"

看答案觉得自己懂了 → 面试时大脑一片空白。**出声说一遍，比看十遍都管用。**

### ❌ 误区 4：追求一次背完所有细节

第一遍只记**骨架（3-4 个关键点）**，第二遍再填**血肉（细节+原理）**，第三遍再补**源码级（如果面试官追问）**。

**不要试图一步到位。**

## 六、你的学习节奏

### 学期中（每天 ~30 分钟）

```
每天选 1 道题 → 盲答 30 秒 → 看答案提炼要点 → 出声说 3 遍
                                                     ↓
                                             手机备忘录记"今天背了啥"
                                                     ↓
                                             第二天早上复习前一题
```

### 暑假强化（每天 ~1 小时）

```
先复习昨天的题（5 分钟）
→ 今天的 1 道新题（20 分钟）
→ 随机抽之前的 2 道题再出声说一遍（20 分钟）
→ 对着面经查漏补缺（15 分钟）
```

## 七、和 AI 配合的学习流程

这套题集配合以下流程使用：

```
1. 你在题集里选一道题
2. 先盲答（不看任何资料）
3. 我来评判你的回答：
   - 对的地方：肯定
   - 漏的地方：补充
   - 错的地方：纠正
   - 面试官会追问的地方：提示
4. 你根据反馈调整，再说一遍
5. 我会帮你提炼成"面试标准回答"的关键词，方便复习
```

**现在就开始：从题集里选一道题，告诉我你准备好了，然后说出你的回答。**
