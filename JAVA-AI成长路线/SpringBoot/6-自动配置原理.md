# 自动配置原理

---

## 核心

Spring Boot 的自动配置就是根据 Classpath 中的依赖，自动创建所需的 Bean——引入 `spring-boot-starter-web` 就自动配好 Tomcat 和 DispatcherServlet，什么都不用配置。

---

## 入口：@SpringBootApplication

```java
@SpringBootApplication  // 等于下面三个注解
public class Application {
    public static void main(String[] args) {
        SpringApplication.run(Application.class, args);
    }
}
```

`@SpringBootApplication` = 三个注解的合体：

| 注解 | 作用 |
|------|------|
| `@Configuration` | 标记为配置类 |
| `@EnableAutoConfiguration` | **开启自动配置（核心）** |
| `@ComponentScan` | 扫描当前包及其子包的 @Component |

---

## 自动配置的工作流程

```
① Spring Boot 启动 → 解析 @EnableAutoConfiguration
② 加载 META-INF/spring.factories 文件
   ↓
   这个文件里列出了所有可能的自动配置类
   （如 DataSourceAutoConfiguration、RedisAutoConfiguration...）
③ 逐个检查自动配置类上的 @Conditional 条件
   ↓
   条件满足才生效，不满足就跳过
④ 生效的自动配置类创建对应的 Bean 放入容器
```

---

## @Conditional——条件注解

自动配置类上有一堆条件注解，决定这个配置**是否生效**：

```java
// 举例：DataSourceAutoConfiguration 的简化版
@Configuration
@ConditionalOnClass(DataSource.class)          // Classpath 中有 DataSource 才生效
@ConditionalOnMissingBean(DataSource.class)    // 容器中没有 DataSource Bean 才生效
@EnableConfigurationProperties(DataSourceProperties.class)  // 绑定配置项
public class DataSourceAutoConfiguration {
    
    @Bean
    @ConditionalOnMissingBean
    public DataSource dataSource() {
        // 根据 spring.datasource.* 配置创建数据源
        return DataSourceBuilder.create().build();
    }
}
```

**常用条件注解**：

| 注解 | 生效条件 |
|------|---------|
| `@ConditionalOnClass` | Classpath 中存在指定类 |
| `@ConditionalOnMissingClass` | Classpath 中不存在指定类 |
| `@ConditionalOnBean` | 容器中存在指定 Bean |
| `@ConditionalOnMissingBean` | 容器中不存在指定 Bean（用户自定义优先） |
| `@ConditionalOnProperty` | 配置文件中存在指定属性 |
| `@ConditionalOnExpression` | SpEL 表达式为 true |

## 自动配置的完整链路

以引入 `spring-boot-starter-web` 为例：

```
① pom.xml 引入 spring-boot-starter-web
    ↓
② Classpath 中多了 Tomcat、Spring MVC 等依赖
    ↓
③ 加载 spring.factories，找到 WebMvcAutoConfiguration
    ↓
④ @ConditionalOnClass 检查：有 Servlet、DispatcherServlet 等类 → 条件满足
    ↓
⑤ @ConditionalOnMissingBean 检查：用户没有自定义 WebMvcConfigurer → 条件满足
    ↓
⑥ WebMvcAutoConfiguration 生效
    ↓
⑦ 自动创建 DispatcherServlet、ViewResolver、静态资源映射等 Bean
    ↓
⑧ 读取 server.port=8081 等配置项赋值
```

## 如何覆盖自动配置

```java
// 方式一：提供自己的 Bean（@ConditionalOnMissingBean 会跳过自动配置）
@Configuration
public class MyDataSourceConfig {
    @Bean
    public DataSource dataSource() {
        return new HikariDataSource();  // 用自己的数据源覆盖自动配置的
    }
}

// 方式二：在 application.yml 中修改配置
spring.datasource.url=jdbc:mysql://localhost:3306/db
spring.datasource.username=root

// 方式三：排除不需要的自动配置
@SpringBootApplication(exclude = DataSourceAutoConfiguration.class)
```

## 项目关联

| 场景 | 说明 |
|------|------|
| **引入 starter 就能用** | `spring-boot-starter-web` 自动配好 Tomcat + Spring MVC |
| **配置数据源** | `spring.datasource.*` 配置 → 自动配置创建 DataSource |
| **排除自动配置** | 不需要自动配置的数据源时用 `@SpringBootApplication(exclude=...)` |
