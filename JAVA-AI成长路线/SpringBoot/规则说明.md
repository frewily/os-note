# Spring Boot 知识点 — 编写规则

> 定位：AI 辅助开发（vibe coding）视角下的 Spring Boot 核心知识梳理。
> 不写配置文件的拼写，不写繁琐的 XML，只写真正需要理解的概念。

---

## 面向读者

已能用 Spring Boot + MyBatis 完成业务开发，需要深入理解底层机制。

---

## 筛选标准

### ✅ 收录

- 理解框架行为需要知道的概念
- 出现问题时能定位原因的知识
- 项目中直接用到、面试常问的机制

### ❌ 不收录

- 配置文件的键值对（查文档更快）
- 各种 starter 的用法细节
- 过时的 XML 配置方式
