# 拦截器与过滤器

---

## 核心

Filter 是 Servlet 规范的组件，作用范围广；Interceptor 是 Spring 的组件，能操作 Spring Bean，控制粒度更细。**你的项目里两种都用到了。**

---

## 执行顺序

```
请求 → Tomcat → Filter.doFilter()
                    ↓
              DispatcherServlet
                    ↓
              Interceptor.preHandle()
                    ↓
              Controller 方法
                    ↓
              Interceptor.postHandle()
                    ↓
              Interceptor.afterCompletion()
                    ↓
              Filter.doFilter() 后续逻辑
                    ↓
              返回响应
```

---

## Filter（过滤器）

```java
@Component
public class CorsFilter implements Filter {
    
    @Override
    public void doFilter(ServletRequest request, ServletResponse response, 
                         FilterChain chain) {
        // 请求进入时执行
        HttpServletResponse resp = (HttpServletResponse) response;
        resp.setHeader("Access-Control-Allow-Origin", "*");
        
        chain.doFilter(request, response);  // 放行
        
        // 响应返回时执行
    }
}
```

**特点**：
- 基于 Servlet 规范，**不依赖 Spring**（Tomcat 就能运行）
- 拦截范围最广——静态资源、Servlet、Controller 都经过 Filter
- 不能获取 Controller 的方法名、参数等细节

**典型用途**：字符编码、CORS 跨域、请求日志（最基础的过滤）。

## Interceptor（拦截器）

```java
@Component
public class AuthInterceptor implements HandlerInterceptor {
    
    @Autowired
    private JwtUtil jwtUtil;  // 可以注入 Spring Bean
    
    @Override
    public boolean preHandle(HttpServletRequest request, 
                             HttpServletResponse response, 
                             Object handler) {
        // Controller 执行前
        String token = request.getHeader("Authorization");
        if (token == null) {
            response.setStatus(401);
            return false;  // 拦截
        }
        Long userId = jwtUtil.parseToken(token);
        UserContext.set(userId);  // 存入 ThreadLocal
        return true;  // 放行
    }
    
    @Override
    public void postHandle(HttpServletRequest request, 
                          HttpServletResponse response, 
                          Object handler, ModelAndView modelAndView) {
        // Controller 执行后，视图渲染前
    }
    
    @Override
    public void afterCompletion(HttpServletRequest request, 
                               HttpServletResponse response, 
                               Object handler, Exception ex) {
        // 请求完全结束后（清理资源）
        UserContext.remove();  // 清理 ThreadLocal
    }
}
```

注册拦截器：

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {
    
    @Autowired
    private AuthInterceptor authInterceptor;
    
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(authInterceptor)
                .addPathPatterns("/api/**")          // 拦截哪些路径
                .excludePathPatterns("/api/login");  // 放行哪些路径
    }
}
```

**特点**：
- 依赖 Spring，**可以注入 Bean**
- 只拦截 Controller 请求，不拦截静态资源
- 能获取请求的 HTTP 方法和处理类（handler）
- 三个方法分别在请求前、渲染前、完成后执行

---

## Filter vs Interceptor

| | Filter | Interceptor |
|--|--------|-------------|
| 规范 | Servlet 规范 | Spring 框架 |
| 是否可注入 Spring Bean | 不能（普通 Filter 不能） | **可以** |
| 拦截范围 | 所有请求（含静态资源） | 只拦截 Controller 请求 |
| 控制粒度 | 粗粒度（request/response 级别） | 细粒度（方法和参数级别） |
| 执行次数 | 一次 | 三次（pre/post/after） |
| 请求中断 | 不调用 chain.doFilter() | preHandle 返回 false |

## 项目关联

```java
// 你的项目中三种拦截器各司其职
@Configuration
public class InterceptorConfig implements WebMvcConfigurer {
    
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(new JwtAuthInterceptor())     // JWT 校验
                .addPathPatterns("/api/**")
                .excludePathPatterns("/api/auth/**");
        
        registry.addInterceptor(new RateLimitInterceptor())   // 限流
                .addPathPatterns("/api/**");
        
        registry.addInterceptor(new ProcessTimeInterceptor()) // 耗时统计
                .addPathPatterns("/api/**");
    }
}
```

| 组件 | 类型 | 作用 |
|------|------|------|
| **JwtAuthInterceptor** | Interceptor | 解析 JWT，校验身份，存入 ThreadLocal |
| **RateLimitInterceptor** | Interceptor | 滑动窗口限流，返回 429 |
| **ProcessTimeInterceptor** | Interceptor | 统计请求耗时，记录日志 |
| **CorsFilter**（如果有） | Filter | 处理跨域请求（设置 CORS 头） |
