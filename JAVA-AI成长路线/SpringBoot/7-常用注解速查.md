# 常用注解速查

---

## 核心

一个速查索引——看到不认识的注解来这里看一眼，不需要记忆。

---

## Bean 注册

| 注解 | 用途 | 位置 |
|------|------|------|
| `@Component` | 通用组件，注册为 Bean | 类上 |
| `@Service` | 业务层（语义化 @Component） | 类上 |
| `@Repository` | 数据层（语义化 @Component） | 类上 |
| `@Controller` | 控制器（返回视图） | 类上 |
| `@RestController` | 控制器（返回 JSON） = `@Controller` + `@ResponseBody` | 类上 |
| `@Configuration` | 配置类，里面可以声明 `@Bean` | 类上 |
| `@Bean` | 声明一个 Bean（通常放在 `@Configuration` 类中） | 方法上 |

**原理**：`@Service`、`@Repository`、`@Controller` 底层都是 `@Component`，功能一样，语义不同。

---

## 依赖注入

| 注解 | 用途 |
|------|------|
| `@Autowired` | Spring 按类型注入 |
| `@Qualifier("name")` | 指定 Bean 名称（配合 @Autowired） |
| `@Resource(name="")` | Java 按名称注入 |
| `@Value("${property}")` | 注入配置文件的属性值 |

---

## Web 映射

| 注解 | 用途 |
|------|------|
| `@RequestMapping` | 通用请求映射（可以指定方法类型） |
| `@GetMapping` | GET 请求（= `@RequestMapping(method=GET)`） |
| `@PostMapping` | POST 请求 |
| `@PutMapping` | PUT 请求 |
| `@DeleteMapping` | DELETE 请求 |
| `@PathVariable` | 取 URL 路径参数：`/users/{id}` |
| `@RequestParam` | 取查询参数：`?page=1` |
| `@RequestBody` | 取请求体 JSON，绑定到对象 |
| `@RequestHeader` | 取请求头 |
| `@ResponseBody` | 把返回值直接写回响应体（转为 JSON） |

---

## 配置

| 注解 | 用途 |
|------|------|
| `@ConfigurationProperties(prefix="...")` | 绑定配置文件中的一组配置到类 |
| `@EnableConfigurationProperties` | 启用 @ConfigurationProperties |
| `@PropertySource("classpath:xxx.properties")` | 指定加载的配置文件 |
| `@ConditionalOnProperty` | 配置属性满足条件才生效 |

---

## 事务

| 注解 | 用途 |
|------|------|
| `@Transactional` | 声明式事务管理 |
| `@Transactional(rollbackFor = Exception.class)` | 指定异常回滚策略 |
| `@Transactional(timeout = 5)` | 超时设置 |
| `@EnableTransactionManagement` | 启用事务管理（Spring Boot 默认开启） |

---

## 条件注解

| 注解 | 生效条件 |
|------|---------|
| `@ConditionalOnClass` | Classpath 中有指定类 |
| `@ConditionalOnMissingClass` | Classpath 中没有指定类 |
| `@ConditionalOnBean` | 容器中有指定 Bean |
| `@ConditionalOnMissingBean` | 容器中没有指定 Bean |
| `@ConditionalOnProperty` | 配置项匹配指定值 |

---

## AOP

| 注解 | 用途 |
|------|------|
| `@Aspect` | 声明一个切面类 |
| `@Before` | 方法执行前执行 |
| `@After` | 方法执行后执行（不管是否异常） |
| `@AfterReturning` | 方法正常返回后执行 |
| `@AfterThrowing` | 方法抛出异常后执行 |
| `@Around` | 包裹整个方法（最灵活） |
| `@Pointcut` | 定义切点表达式 |

---

## 启动与配置

| 注解 | 用途 |
|------|------|
| `@SpringBootApplication` | 启动类 = @Configuration + @EnableAutoConfiguration + @ComponentScan |
| `@EnableAutoConfiguration` | 开启自动配置 |
| `@ComponentScan` | 扫描指定包下的 @Component 及其派生注解 |
| `@EnableScheduling` | 开启定时任务 |
| `@EnableAsync` | 开启异步方法执行 |

---

## 项目关联

不同的注解分布在项目中的不同位置：

| 注解群 | 在项目中的位置 |
|--------|---------------|
| **@RestController / @GetMapping** | Controller 类上 |
| **@Service / @Autowired** | Service 层 |
| **@Repository / @Autowired** | Mapper 层 |
| **@Configuration / @Bean** | 配置类 |
| **@Transactional** | 写入操作的方法上 |
| **@SpringBootApplication** | 启动类 |
