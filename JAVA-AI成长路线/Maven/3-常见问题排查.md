# 常见问题排查

---

## 问题一：依赖冲突

**现象**：编译失败、运行时报 `NoSuchMethodError` / `ClassNotFoundException`。

**排查**：

```bash
# 查看依赖树
mvn dependency:tree

# 搜索具体冲突的包
mvn dependency:tree -Dincludes=com.fasterxml.jackson
```

**解决**：

```xml
<!-- 在引入依赖时排除冲突的版本 -->
<dependency>
    <groupId>xxx</groupId>
    <artifactId>xxx</artifactId>
    <exclusions>
        <exclusion>
            <groupId>com.fasterxml.jackson.core</groupId>
            <artifactId>jackson-databind</artifactId>
        </exclusion>
    </exclusions>
</dependency>

<!-- 或直接声明你需要的版本（路径更短，优先级更高） -->
<dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.16.0</version>
</dependency>
```

## 问题二：jar 包下载失败

**现象**：`Could not resolve dependency`、`ArtifactNotFoundException`。

**原因和解决**：

| 原因 | 解决 |
|------|------|
| 网络问题没下载完 | 删掉 `~/.m2/repository` 下对应的目录，重新 `mvn clean install` |
| 私服上没有这个包 | 检查 settings.xml 中的镜像配置 |
| GAV 坐标写错了 | 去 mvnrepository 确认 |
| 版本不存在 | 确认版本号是否正确 |

```bash
# 强制更新快照
mvn clean install -U

# 重新下载所有依赖（删掉本地仓库重来）
rm -rf ~/.m2/repository/org/example
mvn clean install
```

## 问题三：打包后无法运行

```bash
# ❌ 直接 java -jar 报 "no main manifest attribute"
# 原因：没有用 spring-boot-maven-plugin 打包
```

```xml
<!-- 解决：加上这个插件 -->
<build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
        </plugin>
    </plugins>
</build>
```

```bash
# 打出来的 jar 比预期小很多
# 原因：只打了自己的代码，没打依赖包（用 spring-boot-maven-plugin 会打 fat jar）
```

---

## 问题四：IDEA 中依赖对了但编译报错

**常见原因**：
- IDE 缓存没刷新 → 右键项目 → Maven → Reload project
- Lombok 没装插件 → IDEA 安装 Lombok 插件
- 没点 Enable annotation processing → Settings → Build → Annotation Processors

## 命令速查

```bash
mvn clean                  # 删掉 target 目录
mvn compile                # 编译
mvn test                   # 跑测试
mvn package                # 打包成 jar/war
mvn install                # 打包并安装到本地仓库
mvn clean install          # 最常用：清理 + 打包 + 装到本地
mvn clean package -Pprod   # 指定 profile 打包
mvn dependency:tree        # 查看依赖树
mvn dependency:tree > deps.txt  # 导出依赖树到文件
```
