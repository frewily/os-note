# 76. 最小覆盖子串

---

## 题目

给你一个字符串 `s`、一个字符串 `t`。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果 `s` 中不存在涵盖 `t` 所有字符的子串，则返回空字符串 `""`。

```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
（s 的子串 "BANC" 涵盖了 A、B、C 三个字符，且是最短的）

输入：s = "a", t = "a"
输出："a"
```

---

> 1. **滑动窗口**：右指针扩窗口 → 满足 cover → 左指针缩窗口找更短的 → 不满足再扩右指针
> 2. 两个计数数组：cntS 统计窗口内字符，cntT 统计 t 中字符
> 3. cover 判断：遍历 A-Z、a-z，只要 cntS[i] ≥ cntT[i] 就说明覆盖
> 4. 更新答案：在 while 缩窗口时，每次窗口仍满足 cover 就更新最小边界
> 5. 优化点（可选）：cover 每次 O(52)，可以改成一个 need 计数器——只统计"还缺几个字符"，窗口恰好满足时 need == 0，判断 O(1)

---

## 你的代码

```java
class Solution {
    public String minWindow(String s, String t) {
        int[] cntS = new int[128];  // 统计当前的滑动窗口中的元素有哪些
        int[] cntT = new int[128];  // 统计目标中各元素个数有几个
        for(char c : t.toCharArray()){
            cntT[c]++;  // 字母对应下标的计数加一，表示c的个数
        }
        int len = s.length();
        char[] str = s.toCharArray();
        int left = 0, right = 0;  // 当前窗口的左右边界所在的位置
        int ansLeft = - 1, ansRight = len;  // 最小子串的左右边界
        for(right = 0; right < len; right++){  // 拓展右边界
            cntS[str[right]]++;
            while(cover(cntS, cntT)){  // cover: 当前窗口满足t完全包含于s
                if(right - left < ansRight - ansLeft){  // 当前窗口大小比记录的最小大小还要小，更新最小边界
                    ansRight = right;
                    ansLeft = left;
                }
                cntS[str[left]]--;  // 尝试从左边缩小窗口大小，看看是否还满足cover()函数,同时s[left]因为从左边移出了窗口，窗口中的s[left]个数要减一
                left++;  // 先下标对应的个数减一，再移动下标
            }
        }
        return ansLeft < 0 ? "" : s.substring(ansLeft, ansRight + 1);  // ansLeft默认设置成-1，s中没有符合条件的子串则维持-1不变；substring是左闭右开
    }
    // 判断当前窗口中的元素个数是否满足题干要求
    private boolean cover(int[] cntS, int[] cntT){
        for(int i = 'A'; i <= 'Z'; i++){
            if(cntS[i] < cntT[i]) return false;  // conS中字母个数小于cntT，不满足条件
        }
        for(int i = 'a'; i <= 'z'; i++){
            if(cntS[i] < cntT[i]) return false;
        }
        return true;
    }
}
```

---

## 复杂度

- 时间：O(n × 52) ≈ O(n)，每个字符进出窗口各一次，cover 检查常数级
- 空间：O(1)，两个固定大小数组
