# 560. 和为 K 的子数组（中等）

---

## 题目

给你一个整数数组 `nums` 和一个整数 `k`，请你统计并返回该数组中和为 `k` 的**子数组**的个数。子数组是数组中元素的连续非空序列。

```
输入：nums = [1,1,1], k = 2
输出：2

输入：nums = [1,2,3], k = 3
输出：2
（[1,2] 和 [3]）
```

---

## 你的关键思路

> 1. **问题转化**：`sum[i..j] == k` ⟺ `pre[j] - pre[i-1] == k` ⟺ `pre[i-1] == pre[j] - k`
> 2. **哈希表统计前缀和出现次数**：遍历到 pre[j] 时，查 `pre[j]-k` 之前出现过几次——几次就对应几个满足条件的子数组
> 3. **先查再存**：避免把自己算进去（k=0 时会把空子数组计入）
> 4. `pre[0] = 0` 必须先入表——代表"从数组开头算起"的子数组
> 5. 为什么不能用滑动窗口：数组含负数时窗口和不单调，无法靠收缩左指针调整
> 6. 关键：子串问题用前缀和，本题用hashmap统计前面前缀和出现的次数，让查找的时间复杂度降为O(1)，之后解法类似于两数之和

---

## 你的代码

```java
class Solution {
    public int subarraySum(int[] nums, int k) {
        int n = nums.length;
        int[] s = new int[n + 1];
        s[0] = 0;
        for(int i = 0; i < nums.length; i++){
            s[i + 1] = s[i] + nums[i];
        }
        Map<Integer, Integer> map = new HashMap<>(n + 1, 1);
        int ans = 0;
        for(int sum : s){
            int tar = sum - k;
            if(map.containsKey(tar)){
                ans += map.get(tar);
            }
            map.put(sum, map.getOrDefault(sum, 0) + 1);
        }
        return ans;
    }
}
```

---

## 复杂度

- 时间：O(n)，两遍遍历
- 空间：O(n)，前缀和数组 + 哈希表
