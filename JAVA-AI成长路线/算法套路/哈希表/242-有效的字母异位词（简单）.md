# 242. 有效的字母异位词（简单）

---

## 题目

给定两个字符串 `s` 和 `t`，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。**注意**：若 `s` 和 `t` 中每个字符出现的次数都相同，则称 `s` 和 `t` 互为字母异位词。

```
输入：s = "anagram", t = "nagaram"
输出：true

输入：s = "rat", t = "car"
输出：false
```

---

## 你的关键思路

> 1. **解法一（排序比较）**：异位词排序后相同，直接 `Arrays.equals`——最简洁
> 2. **解法二（双计数数组）**：各统计 26 字母次数再比较——O(n)
> 3. **解法三（单数组加减抵消，最优）**：s 加计数、t 减计数，最后全为 0 即异位词——只用一个数组
> 4. 和 49 的联系：49 是"分组"（排序 key 或计数 key），242 是"两两判断"——同一思想的单人版/双人版
> 5. 进阶：输入含 Unicode 字符时改用 HashMap<Character, Integer>（26 数组只适用于小写字母）

---

## 你的代码

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        char[] c1 = s.toCharArray();
        Arrays.sort(c1);
        char[] c2 = t.toCharArray();
        Arrays.sort(c2);
        return Arrays.equals(c1, c2);
    }
}
```

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        int[] cntS = new int[26];
        for(char c : s.toCharArray()){
            cntS[c - 'a']++;
        }
        int[] cntT = new int[26];
        for(char c : t.toCharArray()){
            cntT[c - 'a']++;
        }
        return Arrays.equals(cntS, cntT);
    }
}
```

```java
class Solution {
    public boolean isAnagram(String s, String t) {
        int[] cnt = new int[26];
        for(char c : s.toCharArray()){
            cnt[c - 'a']++;
        }
        for(char c : t.toCharArray()){
            cnt[c - 'a']--;
        }
        for(int c : cnt){
            if(c != 0) return false;
        }
        return true;
    }
}
```

---

## 复杂度

- 排序法：时间 O(n log n)，空间 O(1)
- 计数数组法：时间 O(n)，空间 O(1)（26 固定长度）
