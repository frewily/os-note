# 13. 罗马数字转整数

---

## 题目

罗马数字包含七种字符：`I(1) V(5) X(10) L(50) C(100) D(500) M(1000)`。通常情况下，小的数字在大的数字右边（相加）；但 4、9、40、90、400、900 例外：小的数字在大的数字左边（相减）。

```
输入：s = "III"
输出：3

输入：s = "IV"
输出：4

输入：s = "MCMXCIV"
输出：1994
```

---

## 你的关键思路

>1.哈希表批量添加元素：Map.of();
>2.特殊规则：直接一次性取前后两个元素，进行比较，ans += x < y ? -x : x; 最后补上最后一个元素

---

## 你的代码

```java
class Solution {
    // 单个罗马数字到整数的映射
    private static final Map<Character, Integer> ROMAN = Map.of(
        'I', 1,
        'V', 5,
        'X', 10,
        'L', 50,
        'C', 100,
        'D', 500,
        'M', 1000
    );

    public int romanToInt(String S) {
        char[] s = S.toCharArray(); // 也可以下面用 charAt，从而保证空间复杂度是 O(1)
        int n = s.length;
        int ans = 0;
        for (int i = 0; i < n - 1; i++) { // 遍历 s
            int x = ROMAN.get(s[i]);
            int y = ROMAN.get(s[i + 1]);
            ans += x < y ? -x : x; // 累加 x 或者 -x，这里 y 只是用来辅助判断 x 的正负
        }
        return ans + ROMAN.get(s[n - 1]); // 加上最后一个罗马数字
    }
}
```
---

## 复杂度

- 时间：O(n)
- 空间：O(1)，Map 固定大小
