---

## 题目

请你判断一个 `9 x 9` 的数独是否有效。只需要根据以下规则，验证已经填入的数字是否有效即可：
1. 数字 `1-9` 在每一行只能出现一次
2. 数字 `1-9` 在每一列只能出现一次
3. 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次

空白格用 `'.'` 表示。只需要验证有效性，不需要填完数独。

```
输入：board = 
[["5","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]]
输出：true
```
