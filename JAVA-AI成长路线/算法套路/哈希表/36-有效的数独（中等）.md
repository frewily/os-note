# 36. 有效的数独（中等）

---

## 题目

请你判断一个 `9 x 9` 的数独是否有效。只需要根据以下规则，验证已经填入的数字是否有效即可：
1. 数字 `1-9` 在每一行只能出现一次
2. 数字 `1-9` 在每一列只能出现一次
3. 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次

空白格用 `'.'` 表示。只需要验证有效性，不需要填完数独。

```
输入：board = 
[["5","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]]
输出：true
```

---

## 你的关键思路

>用两个二维数组判断每一行和每一列是否存在1-9间的数字
>用一个三维数组判断每一个以粗实线分隔的 3x3 宫内是否已经有1-9间的一个数字，其中关键是exit[i / 3][j / 3][cur]，其中[i/3][j/3]恰好可以表示当前的行和列属于哪一个宫格
>之后就是常规的双层for循环遍历

---

## 你的代码

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        boolean[][] rowHas = new boolean[9][9];  // rowHas[i][j]：第i行是否存在数字j
        boolean[][] colHas = new boolean[9][9];  // colHas[i][j]：第i列是否存在数字j
        boolean[][][] exit = new boolean[3][3][9];  // exit[i][j][k]：第i * j 个宫内是否存在数字k
        for(int i = 0; i < board.length; i++){
            for(int j = 0; j < board[0].length; j++){
                if(board[i][j] == '.') continue;
                int cur = board[i][j] - '1';  // 注意是-'1'，布尔数组的取值范围是0-8，而字符范围是'0'-'9'
                if(rowHas[i][cur] || colHas[j][cur] || exit[i / 3][j / 3][cur]) return false;
                rowHas[i][cur] = colHas[j][cur] = exit[i / 3][j / 3][cur] = true;
            }
        }
        return true;
    }
}
```
