# 12. 整数转罗马数字（中等）

---

## 题目

将整数转换为罗马数字。规则见 13 题：通常大的在左小的在右（相加），4、9、40、90、400、900 用减法表示。

```
输入：num = 58
输出："LVIII"
（L=50, V=5, III=3）

输入：num = 1994
输出："MCMXCIV"
（M=1000, CM=900, XC=90, IV=4）
```

---

## 你的关键思路

> 打表解决

---

## 你的代码

```java
class Solution {
    private static final String[][] R = new String[][]{
        {"", "I", "II", "III", "IV", "V", "VI", "VII", "VIII", "IX"}, // 个位
        {"", "X", "XX", "XXX", "XL", "L", "LX", "LXX", "LXXX", "XC"}, // 十位
        {"", "C", "CC", "CCC", "CD", "D", "DC", "DCC", "DCCC", "CM"}, // 百位
        {"", "M", "MM", "MMM"}, // 千位
    };

    public String intToRoman(int num) {
        return R[3][num / 1000] + R[2][num / 100 % 10] + R[1][num / 10 % 10] + R[0][num % 10];
    }
}
```

```java
// 贪心解法：把 4/9 等特殊值也当作"币值"，从大到小除尽
class Solution {
    private static final int[]    VALUES  = {1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1};
    private static final String[] SYMBOLS = {"M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"};

    public String intToRoman(int num) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < VALUES.length; i++) {
            while (num >= VALUES[i]) {   // 能除尽就反复拼
                num -= VALUES[i];
                sb.append(SYMBOLS[i]);
            }
        }
        return sb.toString();
    }
}
// 思路：贪心选最大面值，和"零钱兑换"是同一个思想——局部最优（用最大的）就是全局最优
```

## 复杂度

- 时间：O(1)，固定查表拼接
- 空间：O(1)
