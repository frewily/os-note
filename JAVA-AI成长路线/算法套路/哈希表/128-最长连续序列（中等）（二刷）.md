# 128. 最长连续序列（中等）（二刷）

---

## 题目

给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。请你设计并实现时间复杂度为 **O(n)** 的算法解决此问题。

```
输入：nums = [100,4,200,1,3,2]
输出：4
（最长数字连续序列是 [1,2,3,4]，长度为 4）

输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

---

## 你的关键思路

>1.将数组中的元素放入hashset中，哈希查找的时间复杂度是O(1)
>2.遍历HashSet（不是遍历Nums数组，可能会有大量重复元素）。因为HashSet是无序的，就依次遍历，当num - 1存在set中，就跳过当前元素，直到找到最前面的那个连续的元素，从该元素开始统计长度

> **补充（为什么这是 O(n)）**：
> - 表面看有嵌套 while 像是 O(n²)，但**每个数字最多进入内层 while 一次**——因为只有"序列起点"（num-1 不存在）才会启动内层循环，而每条连续序列只有一个起点
> - 内层 while 推进的所有数字，都属于同一条序列，之后从其他起点不会再数它们 → 均摊 O(n)
> - **遍历 HashSet 而非原数组**：跳过重复元素，也少一次 contain 检查
> - 剪枝：序列互不相交，已有 ans 后剩余元素最多 m-ans 个，若 `ans*2 >= m` 则不可能更长

---

## 你的代码

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for(int num : nums){
            set.add(num);
        }
        int ans = 0;
        for(int num : set){
            if(set.contains(num - 1)){
                continue;
            }
            int cur = num;
            while(set.contains(cur)){
                cur++;
            }
            ans = Math.max(ans, cur - num);
        }
        return ans;
    }
}
```

```java
// 剪枝优化版本
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for(int num : nums){
            set.add(num);
        }
        int m = set.size();
        int ans = 0;
        for(int num : set){
            if(set.contains(num - 1)){
                continue;
            }
            int cur = num;
            while(set.contains(cur)){
                cur++;
            }
            ans = Math.max(ans, cur - num);
            if(ans * 2 >= m) break;  // 剪枝，ans长度大于等于总长度的一半，可以直接返回
        }
        return ans;
    }
}
```

---

## 复杂度

- 时间：O(n)，每个数字最多被访问两次
- 空间：O(n)，HashSet
