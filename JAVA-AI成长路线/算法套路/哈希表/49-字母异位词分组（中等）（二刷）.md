# 49. 字母异位词分组（中等）

---

## 题目

给你一个字符串数组，请你将**字母异位词**组合在一起。可以按任意顺序返回结果列表。字母异位词：由重新排列源单词的所有字母得到的一个新单词。

```
输入：strs = ["eat", "tea", "tan", "ate", "nat", "bat"]
输出：[["bat"],["nat","tan"],["ate","eat","tea"]]

输入：strs = [""]
输出：[[""]]

输入：strs = ["a"]
输出：[["a"]]
```

---

## 你的关键思路

> 二刷感悟：哈希表存储的不是元素映射的下标；将排序好的str作为key，而value存储的是list集合，每次循环都将list集合取出（如果没有对应的key就新建一个），加入新的str并重新放入map集合。最后返回一个ArrayList中的值就填map.values()

---

## 你的代码

```java
class Solution{
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for(String str : strs){
            char[] c = str.toCharArray();
            Arrays.sort(c);
            String key = new String(c);
            List<String> list = map.getOrDefault(key, new ArrayList<String>());
            list.add(str);
            map.put(key, list);
        }
        return new ArrayList<>(map.values());
    }
}
```
