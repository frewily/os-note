# 239. 滑动窗口最大值

---

## 题目

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到最右侧。你只可以看到在滑动窗口内的 `k` 个数字。返回滑动窗口中的最大值。

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]

输入：nums = [1], k = 1
输出：[1]
```

---

## 你的关键思路

> 1. **单调递减双端队列**：队头永远是当前窗口最大值，队列内从队头到队尾递减
> 2. 窗口左移时：滑出的元素若等于队头（即最大值），从队头移除
> 3. 加入新元素前：把队尾所有比它小的元素移除——它们永远不可能是后续窗口的最大值了
> 4. 每个元素最多入队出队各一次，所以总时间 O(n)
> 5. 为什么能删：新元素更大且位置更靠右，旧的小元素"既没它大又先过期"，必然被淘汰

---

## 你的代码

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        if (nums.length == 0 || k == 0)
            return new int[0];
        Deque<Integer> deque = new LinkedList<>(); // 存储递减序列（下面循环中手动维护。当为递减序列时，滑动窗口中最大元素总是在最左边，移除最大元素和将最大元素加入res数组都是操作队头即可）
        int[] res = new int[nums.length - k + 1]; // nums.length - k + 1:滑动窗口长度
        for (int j = 0, i = 1 - k; j < nums.length; i++, j++) { // i 窗口左边界; j 窗口右边界
            if (i > 0 && nums[i - 1] == deque.peekFirst()) {
                // i > 0 -> 形成了一个窗口并且最左边已经有一个元素滑出窗口，初始时i = 1 - k <= 0
                // nums[i - 1] == deque.peekFirst():
                // deque.peekFirst()表示的是最大值（deque单调递减）,nums[i - 1]是左边刚离开窗口的数字
                // 意思是如果窗口最左边滑出的数字恰好是deque中的最大值，则需要更新deque中的最大值
                // 操作就是删除deque中的第一个元素
                deque.removeFirst();
            }
            // 保持deque递减
            while (!deque.isEmpty() && deque.peekLast() < nums[j]) {
                // 如果新加入的元素大于队尾的元素，删除队尾直到满足递减条件。这个值入队之后，所以比这个值小的，并且在这个值之前的，都不可能是答案，所以可以放心删
                deque.removeLast();
            }
            // 满足递减条件后才将最新划入窗口的元素加入deque中
            deque.addLast(nums[j]);
            // i >= 0(形成了滑动窗口才统计deque中的最大值)
            if (i >= 0) {
                res[i] = deque.peekFirst();
            }
        }
        return res;
    }
}
```
---

## 复杂度

- 时间：O(n)，每个元素最多入队出队各一次
- 空间：O(k)，队列最多存 k 个元素
