# 438. 找到字符串中所有字母异位词

---

## 题目

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的**字母异位词**的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

```
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
（起始索引 0 的子串 "cba" 是 "abc" 的异位词
  起始索引 6 的子串 "bac" 是 "abc" 的异位词）

输入：s = "abab", p = "ab"
输出：[0,1,2]
```

---

## 你的关键思路

> 排序法：截取字符串，转为数组，排序后再比较，直观，但性能一般
> 滑动窗口：定长滑动窗口，每次一进一出。关键是不再转为数组再排序比较，而是新建两个统计字符出现次数的数组，直接比较数组的内容是否相等就行。每次滑动窗口改变的是数组中的出现次数。不需要排序，不需要截取字符串，数组比较是常数时间

---

## 你的代码

```java
// 排序法，性能较差
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ans = new ArrayList<>();
        char[] arr = p.toCharArray();
        Arrays.sort(arr);
        int s_len = s.length();
        int p_len = p.length();
        for (int i = 0; i <= s_len - p_len; i++) {
            char[] arr1 = s.substring(i, i + p_len).toCharArray();
            Arrays.sort(arr1);
            if (Arrays.equals(arr, arr1)) {
                ans.add(i);
            }
        }
        return ans;
    }
}
```

```java
// 滑动窗口
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> ans = new ArrayList<>();
        int s_len = s.length();
        int p_len = p.length();
        if(s_len < p_len) return ans;
        int[] conS = new int[26];  // 统计s中各字符出现的次数
        int[] conP = new int[26];  // 同理统计p，二者完全相同就表示是异位词
        for(char c : p.toCharArray()){
            conP[c - 'a']++;
        }
        char[] arr = s.toCharArray();
        for(int right = 0; right < s_len; right++){
            conS[arr[right] - 'a']++;  // 右边滑入窗口
            int left = right - p_len + 1;
            if(left < 0) continue;
            if(Arrays.equals(conP, conS)){  // 长度相同且各字符出现频率相同，满足异位词条件
                ans.add(left);
            }
            conS[arr[left] - 'a']--;  // 左边滑出窗口
        }
        return ans;
    }
}
```

---

## 复杂度

- 排序法：时间 O(n × p_len × log p_len)，空间 O(p_len)
- 滑动窗口：时间 O(n × 26) ≈ O(n)，空间 O(1)（两个固定 26 数组）
