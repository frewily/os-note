# 3. 无重复字符的最长子串（中等）（二刷）

---

## 题目

给定一个字符串 `s`，请你找出其中不含有重复字符的**最长子串**的长度。

```
输入：s = "abcabcbb"
输出：3
（"abc" 长度为 3）

输入：s = "bbbbb"
输出：1

输入：s = "pwwkew"
输出：3
（"wke" 长度为 3，注意答案必须是子串，"pwke" 是子序列）
```

---

## 你的关键思路

> 1. **HashSet 维护窗口内容**：set 里存当前窗口 [left, right] 的字符
> 2. **右指针扩张**：发现 arr[right] 已在窗口中（重复）→ 从左边逐个删直到不重复
> 3. 加入新字符，更新 `maxLen = max(maxLen, right - left + 1)`
> 4. **均摊 O(n)**：left 最多移动 n 次，虽然内层有 while 但总移动量是 O(n)
> 5. 优化方向（HashMap 版）：用 map 记录字符最后出现的位置，left 直接跳到 `重复位置+1`，省去逐个删——面试可以提这个优化

---

## 你的代码

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        char[] arr = s.toCharArray();
        int maxLen = 0;
        Set<Character> set = new HashSet<>();
        int left = 0;
        for(int right = 0; right < arr.length; right++){
            while(set.contains(arr[right])){
                set.remove(arr[left]);
                left++;
            }
            set.add(arr[right]);
            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}
```
---

## 复杂度

- 时间：O(n)，均摊（left 最多移动 n 次）
- 空间：O(字符集大小)，HashSet 最多存窗口大小
