# 279. 完全平方数（中等）

---

## 题目

给你一个整数 `n`，返回和为 `n` 的完全平方数的最少数量。完全平方数是整数 `k` 的平方，如 `1, 4, 9, 16...`

```
输入：n = 12
输出：3
（12 = 4 + 4 + 4）

输入：n = 13
输出：2
（13 = 4 + 9）
```

---

## 你的关键思路

> 1. 把每个完全平方数看成"硬币"，`dp[j]` = 凑出 j 的最少个数——完全背包模板
> 2. 外层遍历物品（完全平方数），内层**正序**遍历容量（完全背包允许重复选）
> 3. 转移：`dp[j] = min(dp[j], dp[j - sq] + 1)`
> 4. 与 0-1 背包的区别：内层正序（可重复选）vs 倒序（不可重复选）

---

## 你的代码

```java
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[n + 1];
        Arrays.fill(dp, Integer.MAX_VALUE);
        dp[0] = 0;
        // 外层：遍历所有完全平方数
        for(int i = 1; i * i <= n; i++){
            int sq = i * i;
            // 内层：遍历容量
            for(int j = sq; j <= n; j++){
                if(dp[j - sq] != Integer.MAX_VALUE){
                    dp[j] = Math.min(dp[j], dp[j - sq] + 1);
                }
            }
        }
        return dp[n];
    }
}
```

---

## 复杂度

- 时间：O(n√n)，物品数 √n × 容量 n
- 空间：O(n)
