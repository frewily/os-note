# 416. 分割等和子集（中等）

---

## 题目

给你一个只包含正整数的非空数组 `nums`。判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

```
输入：nums = [1,5,11,5]
输出：true
（可以分割为 [1,5,5] 和 [11]）

输入：nums = [1,2,3,5]
输出：false
```

---

## 你的关键思路

> 1. 转化：总和为偶数时，问题变成"能否选出若干个数凑出 sum/2"——经典 0/1 背包
> 2. `dp[j]` = 能否选出若干数使和为 j，`dp[0] = true`
> 3. **内层倒序遍历**：每个数只能用一次，正序会重复使用同一个数（那是完全背包的写法）
> 4. 剪枝：总和为奇数直接 false；dp[target] 提前达成提前返回

---

## 你的代码

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int num : nums) sum += num;
        
        // 奇数直接不可能
        if (sum % 2 != 0) return false;
        
        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];  // dp[j] = 能否从数组中选出若干个数，使它们的和恰好等于 j
        dp[0] = true;  // 和为 0 总是可以达到
        
        for (int num : nums) {
            // 倒序遍历！每个数只能用一次
            for (int j = target; j >= num; j--) {
                dp[j] = dp[j] || dp[j - num];
            }
            // 提前结束优化
            if (dp[target]) return true;
        }
        
        return dp[target];
    }
}
```
---

## 复杂度

- 时间：O(n × target)
- 空间：O(target)
