# 动态规划模板

---

## 核心

动态规划本质是**用空间换时间**——把大问题拆成子问题，记录子问题的答案，避免重复计算。

```
递归（自顶向下，重复计算） → 记忆化搜索 → 动态规划（自底向上，填表）
```

---

## 五步法

做任何 DP 题都按这五步走：

```
① 状态定义    dp[i] 代表什么？这是最重要的一步
② 转移方程    当前状态怎么由之前的状态得到？
③ 初始化      dp[0] 或边界是什么？
④ 遍历顺序    正序？倒序？双重循环？
⑤ 答案        dp[n]？还是 max(dp)？
```

## 六种题型速查表

| 题型 | 代表题 | 状态定义 | 遍历方式 | 关键点 |
|------|--------|---------|---------|--------|
| **序列 DP** | [[198-打家劫舍]] | dp[i] = 前 i 个的最优值 | 单层 | 选/不选两种选择 |
| **LIS 类** | [[300-最长递增子序列]] | dp[i] = 以 i 结尾的最长值 | 双重循环 | 答案要取 max(dp)，不是 dp[n-1] |
| **子串 DP** | [[139-单词拆分]] | dp[i] = 前 i 个字符能否满足 | 双重循环 | 枚举切割点 j，dp[j] && 后段满足 |
| **完全背包** | [[279-完全平方数]]、[[322-零钱兑换]] | dp[j] = 容量 j 的最优值 | 外层物品，**内层正序** | 物品可无限使用 |
| **0/1 背包** | [[416-分割等和子集]] | dp[j] = 容量 j 能否达到 | 外层物品，**内层倒序** | 物品只能用一次 |
| **状态扩展** | [[152-乘积最大子数组]] | 两个状态 dpMax[i] / dpMin[i] | 单层 | 一个状态不够，就维护两个 |

## 识别题型

拿到一道题，先问自己三个问题：

### ① 这是不是 DP？
- 最优子结构：大问题的最优解由子问题的最优解组成
- 重叠子问题：同一个子问题被反复计算

### ② 物品能不能重复用？
```
能重复 → 完全背包 → 内层正序
只能用一次 → 0/1 背包 → 内层倒序
```

### ③ 答案是哪个位置？
```
dp[n]（最后状态）    → 打家劫舍、零钱兑换
max(dp)（所有状态）  → LIS、乘积最大子数组
```

## 各种题型的代码骨架

### 序列 DP（选/不选）

```java
int[] dp = new int[n + 1];
for (int i = 1; i <= n; i++) {
    dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i - 1]);
}
```

### 完全背包（内层正序）

```java
int[] dp = new int[target + 1];
Arrays.fill(dp, Integer.MAX_VALUE);
dp[0] = 0;
for (int item : items) {          // 外层：物品
    for (int j = item; j <= target; j++) {  // 内层：正序
        dp[j] = Math.min(dp[j], dp[j - item] + 1);
    }
}
```

### 0/1 背包（内层倒序）

```java
boolean[] dp = new boolean[target + 1];
dp[0] = true;
for (int num : nums) {
    for (int j = target; j >= num; j--) {  // 内层：倒序
        dp[j] = dp[j] || dp[j - num];
    }
}
```

### LIS 类（双重循环）

```java
int[] dp = new int[n];
Arrays.fill(dp, 1);
int maxLen = 1;
for (int i = 0; i < n; i++) {
    for (int j = 0; j < i; j++) {
        if (nums[j] < nums[i]) {
            dp[i] = Math.max(dp[i], dp[j] + 1);
        }
    }
    maxLen = Math.max(maxLen, dp[i]);
}
```

## 常用优化

### 滚动数组

dp 只依赖前几个状态时，用变量代替数组：

```java
// 打家劫舍：dp[i] 只依赖 dp[i-1] 和 dp[i-2]
int prev2 = 0, prev1 = nums[0];
for (int i = 2; i <= n; i++) {
    int cur = Math.max(prev1, prev2 + nums[i - 1]);
    prev2 = prev1;
    prev1 = cur;
}
// 空间 O(n) → O(1)
```

## 举一反三

DP 题的难点不在代码，在于**状态定义**——定义对了，转移方程水到渠成。

遇到新题，先想：这个问题的"状态"是什么？是下标、容量、还是组合？
