# 198. 打家劫舍

---

## 题目

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金。如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。求不触发警报的情况下，一夜之内能够偷窃到的最高金额。

```
输入：[1,2,3,1]
输出：4
（偷 1 号屋(1) + 3 号屋(3) = 4）

输入：[2,7,9,3,1]
输出：12
（偷 1 号屋(2) + 3 号屋(9) + 5 号屋(1) = 12）
```

---

## 你的关键思路

> 1. 子问题定义：`dp[i]` = 偷前 i 间房子的最大金额
> 2. 状态转移：`dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])`
>    - 不偷第 i 间 → 等于偷前 i-1 间的最大值
>    - 偷第 i 间 → 不能偷第 i-1 间，等于偷前 i-2 间 + 本间金额
> 3. 边界：`dp[0] = 0`，`dp[1] = nums[0]`

---

## 你的代码

```java
class Solution {
    public int rob(int[] nums) {
        if(nums.length == 0) return 0;
        // 子问题：
        // f(k) = 偷 [0..k) 房间中的最大金额

        // f(0) = 0
        // f(1) = nums[0]
        // f(k) = max{ rob(k-1), nums[k-1] + rob(k-2) }

        int N = nums.length;
        int[] dp = new int[N + 1];
        dp[0] = 0;
        dp[1] = nums[0];
        for(int i = 2; i <= N; i++){
            // 偷前i间房子，可分为：
            // 1. 最后一间不偷，考虑在前i-1间选房子偷 -> 划分成子问题 dp[i - 1];
            // 2. 最后一间偷，那倒数第二间就不能偷，接着考虑在前i-2间选房子偷，划分成子问题 -> dp[i - 2] + nums[i - 1](0到i-1,i-1下标对应第i间房子)
            // 子问题一共分为两种情况，二者取最大值即可
            dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i - 1]);
        }
        return dp[N];
    }
}
```
---

## 复杂度

- 时间：O(n)
- 空间：O(n)（可优化为 O(1)，只保留 dp[i-1] 和 dp[i-2] 两个变量）
