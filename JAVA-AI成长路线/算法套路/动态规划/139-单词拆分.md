# 139. 单词拆分

---

## 题目

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。判断是否可以利用字典中出现的单词拼接出 `s`。字典中的单词可以重复使用。

```
输入：s = "leetcode", wordDict = ["leet", "code"]
输出：true
（"leetcode" 可以由 "leet" + "code" 拼接）

输入：s = "applepenapple", wordDict = ["apple", "pen"]
输出：true

输入：s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出：false
```

---

## 你的关键思路

> 剪枝优化：如果字典里最长单词长度为 maxLen，内层循环只需从 Math.max(0, i - maxLen) 开始，减少无效检查。因为当i 大于 maxlen时，j再从零开始截取字符串，长度大于最长的单词，一定不是我们需要的，所以i 超过 maxLen时，j从i - maxLen开始可以确保截取的字符串长度在字典单词范围内

---

## 你的代码

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        Set<String> dictSet = new HashSet<>(wordDict); // 存入哈希表中,o(1)的查找
        int len = s.length();
        boolean[] dp = new boolean[len + 1];
        dp[0] = true;  // 空字符串默认可以查找
        for(int i = 1; i <= len; i++){   // 我想拼到第 i 个位置
            for(int j = 0; j < i; j++){  // 试试从哪个位置 j 切一刀
                if(dp[j] && dictSet.contains(s.substring(j, i))){  // 前面 j 之前已经能拼 + j..i 这段是个单词
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[len];
    }
}
```

```java
// 剪枝优化版
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        int maxLen = 0;
        for(String word : wordDict){
            maxLen = Math.max(maxLen, word.length());
        }
        Set<String> dictSet = new HashSet<>(wordDict); // 存入哈希表中,o(1)的查找
        int len = s.length();
        boolean[] dp = new boolean[len + 1];
        dp[0] = true;  // 空字符串默认可以查找
        for(int i = 1; i <= len; i++){   // 我想拼到第 i 个位置
            for(int j = Math.max(0, i - maxLen); j < i; j++){  // 试试从哪个位置 j 切一刀
                if(dp[j] && dictSet.contains(s.substring(j, i))){  // 前面 j 之前已经能拼 + j..i 这段是个单词
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[len];
    }
}
```
