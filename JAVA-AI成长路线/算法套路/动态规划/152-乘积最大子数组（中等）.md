# 152. 乘积最大子数组（中等）

---

## 题目

给你一个整数数组 `nums`，找出数组中乘积最大的非空连续子数组，并返回该子数组所对应的乘积。

```
输入：nums = [2,3,-2,4]
输出：6
（子数组 [2,3] 的乘积最大，为 6）

输入：nums = [-2,0,-1]
输出：0
```

---

## 你的关键思路

> 同时维护以当前元素结尾的最大乘积和最小乘积，因为负数 × 负数 = 正数，最小值可能在下一步翻转为最大值。
>Word Break    → dp[i] 依赖之前所有 j 的切割
>LIS           → dp[i] 依赖之前所有 j < i 且 nums[j] < nums[i]
>乘积最大子数组 → maxSoFar[i] 依赖 maxSoFar[i-1] 和 minSoFar[i-1]

---

## 你的代码

```java
class Solution {
    public int maxProduct(int[] nums) {
        int n = nums.length - 1;
        int maxSoFar = nums[0];
        int minSoFar = nums[0];
        int result = nums[0];
        for(int i = 1; i <= n; i++){  // 前面已经用nums[0]初始化了
            int tempMax = Math.max(nums[i], Math.max(maxSoFar * nums[i], minSoFar * nums[i]));
            int tempMin = Math.min(nums[i], Math.min(maxSoFar * nums[i], minSoFar * nums[i]));
            maxSoFar = tempMax;
            minSoFar = tempMin;
            result = Math.max(result, maxSoFar);
        }
        return result;
    }
}
```

---

## 复杂度

- 时间：O(n)
- 空间：O(1)，只用两个变量滚动
