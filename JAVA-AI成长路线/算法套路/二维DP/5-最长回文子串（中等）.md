# 5. 最长回文子串（中等）

---

## 题目

给你一个字符串 `s`，找到 `s` 中最长的回文子串。

```
输入：s = "babad"
输出："bab"（"aba" 也符合）

输入：s = "cbbd"
输出："bb"
```

---

## 你的关键思路

> **解法一（中心扩展法，O(1) 空间）**
> 1. 每个字符都可以是回文中心
> 2. 分奇偶两种情况向两边扩展：奇数中心 (i,i)，偶数中心 (i,i+1)
> 3. 扩展时两边字符相等就继续，不等就停
> 4. 注意起点计算：`i - (len-1)/2`

> **解法二（二维 DP，O(n²) 空间）**
> 1. `dp[i][j]` = s[i..j] 是否是回文
> 2. 转移：`s[i]==s[j] && dp[i+1][j-1]`
> 3. **按子串长度遍历**（外层 len，内层 i），不是按 i 遍历——因为 dp[i][j] 依赖更短的 dp[i+1][j-1]，必须先算完所有短子串

---

## 你的代码

```java
// 中心扩展法
class Solution {
    public String longestPalindrome(String s) {
        if(s.length() < 2 || s == null) return s;
        int cur = 0, maxLen = 1;
        // 遍历每一个元素，假设当前的i为回文的中心
        for(int i = 0; i < s.length(); i++){
            // 假设是长度为奇数的回文
            int Len1 = expand(s, i , i);
            // 假设是长度为偶数的回文
            int Len2 = expand(s, i , i + 1);
            // 统计上面两种可能的情况中回文长度的最大值
            int len = Math.max(Len1, Len2);
            if(maxLen < len){
                // 更新回文长度以及回文开始的索引
                maxLen = len;
                // i是回文的中心，i - len/2得到起始索引，写成i-1是考虑len-1为奇数的情况
                cur = i - (len - 1) / 2;
            }
        }
        return s.substring(cur, cur + maxLen);
    }
    // 假设以i为回文中心，向两边扩展，如果满足回文条件就继续，返回回文串长度
    private int expand(String s, int left, int right){
        while(left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)){
            left--;
            right++;
        }
        return right - left - 1;
    }
}
```

```java
// 多维动态规划
class Solution {
    public String longestPalindrome(String s) {
        int n = s.length();
        if (n < 2) return s;

        boolean[][] dp = new boolean[n][n];
        int start = 0, maxLen = 1;

        // 长度为 1
        for (int i = 0; i < n; i++) {
            dp[i][i] = true;
        }

        // 枚举长度
        for (int len = 2; len <= n; len++) {
            for (int i = 0; i + len - 1 < n; i++) {
                int j = i + len - 1;

                if (s.charAt(i) != s.charAt(j)) {
                    dp[i][j] = false;
                } else {
                    // 长度 <= 3，直接是回文
                    if (len <= 3) {
                        dp[i][j] = true;
                    } else {
                        dp[i][j] = dp[i + 1][j - 1];
                    }
                }

                // 更新答案
                if (dp[i][j] && len > maxLen) {
                    start = i;
                    maxLen = len;
                }
            }
        }
        return s.substring(start, start + maxLen);
    }
}
```

---

## 复杂度

- 中心扩展法：时间 O(n²)，空间 O(1)
- 二维 DP：时间 O(n²)，空间 O(n²)
