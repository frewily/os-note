# 62. 不同路径

---

## 题目

一个机器人位于 `m x n` 网格的左上角，每次只能向下或者向右移动一步。机器人试图达到网格的右下角。问总共有多少条不同的路径？

```
输入：m = 3, n = 7
输出：28
```

---

## 你的关键思路

> 1. **组合数学**：总共走 m+n-2 步（向下 m-1 步 + 向右 n-1 步），答案 = C(m+n-2, m-1) = C(m+n-2, n-1)
> 2. 取 k = min(m-1, n-1) 计算 C(m+n-2, k)，减少循环次数（C 的对称性：C(n,k) = C(n,n-k)）
> 3. 边乘边除保持中间值始终是整数，用 long 防溢出
> 4. 这不是 DP，是纯数学解——比 DP 的 O(mn) 更快

---

## 你的代码

```java
class Solution {
    public int uniquePaths(int m, int n) {
       int k = Math.min(m - 1, n - 1);
       long ans = 1;
       for(int i = 1; i <= k; i++){
        ans = ans * (m + n - 2 - k + i) / i;
       }
       return (int)ans;
    }
}
```
---

## 复杂度

- 时间：O(min(m, n))
- 空间：O(1)

---

## 补充：标准 DP 解法

组合数学是这题的特解，面试中也可以展示更通用的 DP 思路：

```java
public int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    // 第一行和第一列只有一种走法（一路向右/向下）
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            // 到 (i,j) = 从上方来 + 从左方来
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
        }
    }
    return dp[m-1][n-1];
}
// 时间 O(mn)，空间 O(mn)（可优化为 O(n)，只用一行滚动）
```
