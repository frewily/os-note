# 64. 最小路径和

---

## 题目

给定一个包含非负整数的 `m x n` 网格 `grid`，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。每次只能向下或者向右移动一步。

```
输入：grid = [[1,3,1],
             [1,5,1],
             [4,2,1]]
输出：7
（路径 1 → 3 → 1 → 1 → 1 的总和最小）
```

---

## 你的关键思路

> 1. `dp[i][j]` = 从左上角到 (i,j) 的最小路径和
> 2. 转移：`dp[i][j] = min(上方, 左方) + grid[i][j]`——只能从两个方向到达
> 3. 边界：第一行只能从左来（累加左边），第一列只能从上来（累加上边）
> 4. **原地 DP**：直接修改 grid 数组，省掉额外 dp 数组，空间 O(1)
---

## 你的代码

```java
class Solution {
    public int minPathSum(int[][] grid) {
        for(int i = 0; i < grid.length; i++){
            for(int j = 0; j < grid[0].length; j++){
                if(i == 0 && j == 0) continue;
                else if(i == 0) grid[i][j] += grid[i][j - 1];
                else if(j == 0) grid[i][j] += grid[i - 1][j];
                else grid[i][j] += Math.min(grid[i][j - 1], grid[i - 1][j]);
            }
        }
        return grid[grid.length - 1][grid[0].length - 1];
    }
}
```

---

## 复杂度

- 时间：O(m × n)
- 空间：O(1)（原地修改）
