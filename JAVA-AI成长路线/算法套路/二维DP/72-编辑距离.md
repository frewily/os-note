# 72. 编辑距离

---

## 题目

给你两个单词 `word1` 和 `word2`，请返回将 `word1` 转换成 `word2` 所使用的最少操作数。可以对一个单词进行三种操作：插入一个字符、删除一个字符、替换一个字符。

```
输入：word1 = "horse", word2 = "ros"
输出：3
（horse → rorse → rose → ros）

输入：word1 = "intention", word2 = "execution"
输出：5
```

---

## 你的关键思路

> 1. `dp[i][j]` = word1 前 i 个字符 → word2 前 j 个字符的最少操作数（i、j 是长度不是下标）
> 2. 初始化：`dp[i][0] = i`（删 i 次）、`dp[0][j] = j`（插 j 次）
> 3. 转移：
>    - 字符相等：`dp[i][j] = dp[i-1][j-1]`（不用操作）
>    - 不等：三种操作取最小 + 1
>      - 删除 → `dp[i-1][j]`
>      - 插入 → `dp[i][j-1]`
>      - 替换 → `dp[i-1][j-1]`
> 4. 答案：`dp[m][n]`

---

## 你的代码

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        // dp[i][j]:将 word1 的前 i 个字符，转换成 word2 的前 j 个字符，所需的最少操作次数。
        // i j 表示字符串长度，不是指下标
        int[][] dp = new int[m + 1][n + 1];
        // 初始化
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i; // 将i长的转为空串，删i次
        }
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j; // 将空串转为j长的，插入i次
        }
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 前i和前j 相等，不操作，次数和前面一次相等
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 取删除，插入，替换中最小的,
                    // Math.min表示进行各操作前对应的操作次数的状态
                    // +1就表示进行删除，插入或替换中最小的
                    dp[i][j] = Math.min(
                            dp[i - 1][j], Math.min(dp[i][j - 1], dp[i - 1][j - 1])) + 1;
                }
            }
        }
        return dp[m][n];
    }
}
```

---

## 复杂度

- 时间：O(m × n)
- 空间：O(m × n)（可滚动数组优化为 O(n)）
