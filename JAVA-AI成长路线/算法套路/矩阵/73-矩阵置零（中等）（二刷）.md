# 73. 矩阵置零（中等）

---

## 题目

给定一个 `m x n` 的矩阵，如果一个元素为 **0**，则将其所在行和列的所有元素都设为 0。请使用**原地**算法。进阶：一个直观的解决方案是 O(mn) 的额外空间；一个更简单的改进方案是 O(m+n) 的额外空间；你能想出一个仅使用常量空间的解决方案吗？

```
输入：matrix = [[1,1,1],[1,0,1],[1,1,1]]
输出：[[1,0,1],[0,0,0],[1,0,1]]

输入：matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
输出：[[0,0,0,0],[0,4,5,0],[0,3,1,0]]
```

---

## 你的关键思路

> 1. 第一遍扫描：记录哪些行/列含 0（两个 boolean 标记数组，O(m+n) 空间）
> 2. 第二遍扫描：按标记置零
> 3. 关键：**不能边遍历边置零**——会污染还没检查过的位置
> 4. 进阶 O(1) 空间：用第一行/第一列当标记数组（下方补充）

---

## 你的代码

```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;
        boolean[] row = new boolean[m];
        boolean[] col = new boolean[n];
        for(int i = 0; i < m; i++){
            for(int j = 0; j < n; j++){
                if(matrix[i][j] == 0){
                    row[i] = col[j] = true;
                }
            }
        }
        for(int i = 0; i < m; i++){
            for(int j = 0; j < n; j++){
                if(row[i] || col[j]){
                    matrix[i][j] = 0;
                }
            }
        }
    }
}
```

```java
// 进阶：O(1) 空间——用第一行/第一列当标记，两个额外变量处理标记行本身有 0 的情况
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length, n = matrix[0].length;
        boolean row0 = false, col0 = false;
        // ① 记录第一行/第一列本身是否有 0
        for (int j = 0; j < n; j++) if (matrix[0][j] == 0) row0 = true;
        for (int i = 0; i < m; i++) if (matrix[i][0] == 0) col0 = true;
        // ② 用第一行/第一列做标记：matrix[i][0] / matrix[0][j] 置 0 表示第 i 行/第 j 列需要清零
        for (int i = 1; i < m; i++)
            for (int j = 1; j < n; j++)
                if (matrix[i][j] == 0) matrix[i][0] = matrix[0][j] = 0;
        // ③ 按标记置零（跳过第一行/第一列，最后单独处理）
        for (int i = 1; i < m; i++)
            for (int j = 1; j < n; j++)
                if (matrix[i][0] == 0 || matrix[0][j] == 0) matrix[i][j] = 0;
        // ④ 处理第一行/第一列本身
        if (row0) for (int j = 0; j < n; j++) matrix[0][j] = 0;
        if (col0) for (int i = 0; i < m; i++) matrix[i][0] = 0;
    }
}
```
---

## 复杂度

- 标记数组版：时间 O(m×n)，空间 O(m+n)
- O(1) 版：时间 O(m×n)，空间 O(1)
