# 48. 旋转图像（中等）（二刷）

---

## 题目

给定一个 `n × n` 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。**必须**在原地修改输入矩阵，不要使用另一个矩阵来旋转图像。

```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]

输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

---

## 你的关键思路

> 1. 观察位置对应关系：顺时针旋转 90° = **先转置 + 再每行反转**
> 2. 转置：沿主对角线对称交换（只需遍历下三角，j < i）
> 3. 行反转：每行首尾交换到中间
> 4. 全程原地，不用额外矩阵
> 5. 逆时针旋转 = 先转置 + 再每列反转（对称记忆）

---

## 你的代码

```java
class Solution {
    public void rotate(int[][] matrix) {
        // 思路：1.先将矩阵转置，即第一列变到第一行，第二列变到第二行...  依次类推
        //         具体操作方法是主对角线外的数字沿着主对角线对称交换
        //      2.将每一行的元素顺序前后调换一下即可，一首一尾交换
        for(int i = 0; i < matrix.length; i++){
            for(int j = 0; j < i; j++){
                swap(matrix, i, j);
            }
        }
        for(int i = 0; i < matrix.length; i++){
            for(int j = 0; j < matrix[0].length / 2; j++){
                swapLine(matrix, i, j);
            }
        }
    }
    private void swap(int[][] arr, int a, int b){
        int tmp = arr[a][b];
        arr[a][b] = arr[b][a];
        arr[b][a] = tmp;
    }
    private void swapLine(int[][] arr,int i,int j){
        int tmp = arr[i][j];
        arr[i][j] = arr[i][arr[0].length - j - 1];
        arr[i][arr[0].length - j - 1] = tmp;
    }
}
```

---

## 复杂度

- 时间：O(n²)，每个元素访问常数次
- 空间：O(1)，原地交换
