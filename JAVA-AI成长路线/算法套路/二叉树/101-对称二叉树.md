# 101. 对称二叉树

---

## 题目

给你一个二叉树的根节点 `root`，检查它是否轴对称。

```
输入：root = [1,2,2,3,4,4,3]
输出：true

输入：root = [1,2,2,null,3,null,3]
输出：false

输入：root = [1,2,3]
输出：false
```

**进阶**：你可以运用递归和迭代两种方法解决这个问题吗？

---

## 你的关键思路

**两种解法对比**

| 对比项 | 递归（交叉检查） | 迭代（成对入队） |
|--------|----------------|----------------|
| 核心 | `check(左, 右)` 交叉递归 | 队列每次弹出**一对**对称位置节点 |
| 入队顺序 | — | `r1.left, r2.right, r1.right, r2.left`（交叉成对） |
| 空间 | O(h) 递归栈 | O(w) 队列 |

**易错点**：递归时是 `check(r1.left, r2.right)` **交叉**的——写成 `check(r1.left, r2.left)` 就变成了"克隆比较"。

**小提示**：递归版入口 `check(root.left, root.right)` 在 `root == null` 时会 NPE——本题约束节点数 ≥ 1 所以安全，但严谨写法可以是 `root == null || check(root.left, root.right)`。

---

## 你的代码

```java
// 迭代
class Solution {
    public boolean isSymmetric(TreeNode root) {
        return check(root, root);
    }
    private boolean check(TreeNode r1, TreeNode r2){
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(r1);
        queue.offer(r2);
        while(!queue.isEmpty()){
            r1 = queue.poll();
            r2 = queue.poll();
            if(r1 == null && r2 == null) continue;
            if(r1 == null || r2 == null || r1.val != r2.val){
                return false;
            }
            queue.offer(r1.left);
            queue.offer(r2.right);
            queue.offer(r1.right);
            queue.offer(r2.left);
        }
        return true;
    }
}
```

```java
// 递归
class Solution {
    public boolean isSymmetric(TreeNode root) {
        return check(root.left, root.right);
    }
    private boolean check(TreeNode r1, TreeNode r2){
        if(r1 == null && r2 == null){
            return true;
        }
        if(r1 == null || r2 == null){
            return false;
        }
        return r1.val == r2.val && check(r1.left, r2.right) && check(r1.right, r2.left);
    }
}
```

---

## 复杂度

- 时间：O(n)，每个节点访问一次
- 空间：O(h)（递归栈）/ O(w)（迭代队列，w = 最宽层）
