# 124. 二叉树中的最大路径和（困难）

---

## 题目

二叉树中的**路径**被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中至多出现一次。路径和是路径中各节点值的总和。给你一个二叉树的根节点 `root`，返回其最大路径和。

```
输入：root = [1,2,3]
输出：6
（最优路径是 2 → 1 → 3，路径和为 2 + 1 + 3 = 6）

输入：root = [-10,9,20,null,null,15,7]
输出：42
（最优路径是 15 → 20 → 7，路径和为 42）
```

---

## 你的关键思路

> 1. **后序遍历**：先算左右子树，再处理当前节点——路径信息自底向上汇总
> 2. **两个不同的"值"**：
>    - `ans`：全局最大值，考虑"路径穿过当前节点"（左 + 右 + 当前值），可以拐弯
>    - 返回值：只返回**单边向下**的最大路径（max(左, 右) + 当前值），因为向上走只能走一条边
> 3. **与 0 取 max**：子树贡献为负时直接丢弃（不选），相当于把路径从这里截断
> 4. `ans` 初始化为 `Integer.MIN_VALUE` 而非 0——节点值可能全为负数，0 会导致错误答案
> 5. 关键理解：**返回值是"线"，ans 是"线+弯"**——穿过节点可以拐弯，向上传只能走直线

---

## 你的代码

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {
    private int ans = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        dfs(root);
        return ans;
    }
    private int dfs(TreeNode node){
        if(node ==null) return 0;
        int sumL = dfs(node.left);
        int sumR = dfs(node.right);
        ans = Math.max(ans, sumL + sumR + node.val);
        return Math.max(Math.max(sumL, sumR) + node.val, 0);
    }
}
```

---

## 复杂度

- 时间：O(n)，每个节点访问一次
- 空间：O(h)，递归栈深度（h 为树高，最坏 O(n)）
