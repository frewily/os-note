# 94. 二叉树的中序遍历

---

## 题目

给定一个二叉树的根节点 `root`，返回它的**中序遍历**（左 → 根 → 右）结果。

```
输入：root = [1,null,2,3]
输出：[1,3,2]

输入：root = []
输出：[]
```

**进阶**：用迭代算法完成。

---

## 你的关键思路

> 迭代：引入栈，当 `root != null || !stack.isEmpty()` 就一直循环，内循环先将左节点不断压入栈中，然后弹出一个栈中节点 node，放入 ans  数组中，更新 root 为 node，继续重复内循环，遍历左子树。

---

## 你的代码

```java
// 递归
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        inorder(root,res);
        return res;
    }

    public void inorder(TreeNode root,List<Integer> res){
        if(root == null){
            return;
        }
        inorder(root.left,res);
        res.add(root.val);
        inorder(root.right,res);
    }
}
```

```java
// 迭代
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        Deque<TreeNode> stack = new LinkedList<>();
        while(root != null || !stack.isEmpty()){
            while(root != null){
                stack.push(root);
                root = root.left;
            }
            TreeNode top = stack.pop();
            ans.add(top.val);
            root = top.right;
        }
        return ans;
    }
}
```
