# 94. 二叉树的中序遍历

---

## 题目

给定一个二叉树的根节点 `root`，返回它的**中序遍历**（左 → 根 → 右）结果。

```
输入：root = [1,null,2,3]
输出：[1,3,2]

输入：root = []
输出：[]
```

**进阶**：用迭代算法完成。

---

## 你的关键思路

> 迭代：引入栈，当 `root != null || !stack.isEmpty()` 就一直循环，内循环先将左节点不断压入栈中，然后弹出一个栈中节点 node，放入 ans  数组中，更新 root 为 node，继续重复内循环，遍历左子树。

**补充：迭代解法分步拆解**

**核心思想**：用栈模拟递归的调用栈——中序 = "左 根 右"，所以先把一路左孩子全部压栈（这些是最先要输出的），走到头了再弹出（输出"根"），然后转向右子树重复。

**三步循环**（每轮迭代做三件事）：

```
① 一路向左：while(root != null) { push(root); root = root.left; }
   —— 把"还没处理的最左边路径"全部入栈
② 弹出栈顶输出：node = pop(); ans.add(node.val);
   —— 栈顶就是当前最"左"的待处理节点（左已处理完，轮到自己）
③ 转向右子树：root = node.right;
   —— 右子树同样遵循"再一路左"的规则
```

**外层条件为什么是 `root != null || !stack.isEmpty()`**：

- `root != null`：还有节点要处理（新的一路向左）
- `!stack.isEmpty()`：栈里还有"欠着的根节点"没输出
- 两者都空 = 全部处理完

**与递归的对应关系**：

| 递归 | 迭代 |
|------|------|
| `inorder(left)` | 内循环一路压栈 |
| `res.add(root.val)` | pop 后加入 ans |
| `inorder(right)` | `root = top.right` |

**统一模板（进阶了解）**：所有遍历都可以用"标记法"——压栈时对"待输出节点"加个标记，遇标记就输出。这样前/中/后序只改一行顺序，代码更统一。

---

## 你的代码

```java
// 递归
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        inorder(root,res);
        return res;
    }

    public void inorder(TreeNode root,List<Integer> res){
        if(root == null){
            return;
        }
        inorder(root.left,res);
        res.add(root.val);
        inorder(root.right,res);
    }
}
```

```java
// 迭代
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ans = new ArrayList<>();
        Deque<TreeNode> stack = new LinkedList<>();
        while(root != null || !stack.isEmpty()){
            while(root != null){
                stack.push(root);
                root = root.left;
            }
            TreeNode top = stack.pop();
            ans.add(top.val);
            root = top.right;
        }
        return ans;
    }
}
```

---

## 复杂度

- 时间：O(n)，每个节点访问一次
- 空间：O(h)，栈深度 = 树高（最坏 O(n)，平衡树 O(log n)）
