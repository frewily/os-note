# 104. 二叉树的最大深度

---

## 题目

给定一个二叉树 `root`，返回其最大深度。二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数。

```
输入：root = [3,9,20,null,null,15,7]
输出：3

输入：root = [1,null,2]
输出：2
```

---

## 你的关键思路

> 递归，分别深入左右节点，最后返回左右节点的最大值再 + 1

**补充：BFS 解法（层序遍历数层数）**

思路：用队列逐层遍历，每处理完一层深度 +1，队列为空时返回深度。

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int depth = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();       // 当前层的节点数
            for (int i = 0; i < size; i++) {  // 一次处理完整层
                TreeNode node = queue.poll();
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            depth++;                        // 一层处理完，深度 +1
        }
        return depth;
    }
}
```

**两种解法对比**：

| 对比项 | 后序递归（你的） | 层序遍历 BFS |
|--------|----------------|-------------|
| 思路 | 子树深度自底向上汇总 | 逐层计数 |
| 空间 | O(h) 递归栈 | O(w) 队列（w = 最宽层） |
| 应用 | 看"子树信息"类问题的通式 | "按层处理"类问题的通式（102 层序遍历的基础） |

---

## 你的代码

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if(root == null){
            return 0;
        }
        int left = maxDepth(root.left);
        int right = maxDepth(root.right);
        return Math.max(left, right) + 1;
    }
}
```

---

## 复杂度

- 时间：O(n)，每个节点访问一次
- 空间：O(h)，递归栈深度（最坏 O(n)，平衡树 O(log n)）
