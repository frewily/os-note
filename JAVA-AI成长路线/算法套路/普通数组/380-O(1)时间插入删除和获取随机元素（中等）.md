# 380. O(1) 时间插入、删除和获取随机元素（中等）

---

## 题目

实现 `RandomizedSet` 类：`insert(val)`、`remove(val)`、`getRandom()` 三个操作平均时间复杂度都是 O(1)。元素不重复。

```
输入：
["RandomizedSet","insert","remove","insert","getRandom","remove","insert","getRandom"]
[[],[1],[2],[2],[],[1],[2],[]]

输出：[null,true,false,true,2,true,false,2]
```

---

## 你的关键思路

> O(1)时间的查找和删除：哈希表
> 随机检索：new Random()+数组
> 删除时要保证O(1)，那在操作数组时就不可以直接删，否则删除后移动元素的时间复杂度为O(n);
> "交换删除"：把要删的元素和数组最后一个交换再删，避免数组中间删除的 O(n) 搬移。

---

## 你的代码

```java
class RandomizedSet {
    static int[] nums = new int[200010];
    Random random = new Random();
    Map<Integer, Integer> map = new HashMap<>();
    // 数组索引，用于手动改变数组长度
    int idx = -1;
    public boolean insert(int val) {
        if (map.containsKey(val)) return false;
        nums[++idx] = val;
        map.put(val, idx);
        return true;
    }
    public boolean remove(int val) {
        if (!map.containsKey(val)) return false;
        int loc = map.remove(val);
        if (loc != idx) map.put(nums[idx], loc);
        // 直接覆盖成数组最后一个元素，同时移动idx来改变数组长度
        nums[loc] = nums[idx--];
        return true;
    }
    public int getRandom() {
        return nums[random.nextInt(idx + 1)];
    }
}
```

---

## 复杂度

- 时间：O(1) 每个操作
- 空间：O(n)
