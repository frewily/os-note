# 53. 最大子数组和（二刷）

---

## 题目

给你一个整数数组 `nums`，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
（连续子数组 [4,-1,2,1] 的和最大，为 6）

输入：nums = [1]
输出：1

输入：nums = [5,4,-1,7,8]
输出：23
```

---

## 你的关键思路

> Kadane 算法（O(n)）:如果当前子数组的和已经变成负数，不如从当前元素重新开始(动态规划)

> **补充（标准 DP 视角）**：
> - 状态定义：`dp[i]` = 以 i 结尾的最大子数组和
> - 转移方程：`dp[i] = max(nums[i], dp[i-1] + nums[i])`——前者是"另起炉灶"，后者是"接着前面"
> - 你的写法（sum 为负就清零）和它在数学上等价，但注意：**清零时机影响全负数场景的处理**——靠"每次循环都更新 max"兜底
> - 标准写法（一个变量滚动）：
>   ```java
>   int cur = nums[0], max = nums[0];
>   for (int i = 1; i < nums.length; i++) {
>       cur = Math.max(nums[i], cur + nums[i]);
>       max = Math.max(max, cur);
>   }
>   ```
> - 这题和 152-乘积最大子数组是"兄弟题"（最大和 vs 最大积），152 需要维护两个状态是因为负负得正，这题单状态就够

---

## 你的代码

```java
class Solution {
    public int maxSubArray(int[] nums) {
        if(nums.length == 1) return nums[0];
        int max = nums[0];
        int sum = 0;
        for(int num : nums){
            sum += num;
            if(sum < 0){
                max = Math.max(sum, max);
                sum = 0;
                continue;
            }
            max = Math.max(sum, max);
        }
        return max;
    }
}
```

---

## 复杂度

- 时间：O(n)，单遍扫描
- 空间：O(1)
