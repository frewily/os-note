# 238. 除自身以外数组的乘积（中等）

---

## 题目

给你一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。题目数据保证数组之中任意元素的全部前缀元素和后缀的乘积都在 32 位整数范围内。**不要使用除法**，且在 O(n) 时间复杂度内完成。

```
输入：nums = [1,2,3,4]
输出：[24,12,8,6]

输入：nums = [-1,1,0,-3,3]
输出：[0,0,9,0,0]
```

---

## 你的关键思路

>二刷，自己做出来啦，关键：
>“题目数据 保证 数组 nums之中任意元素的全部前缀元素和后缀的乘积都在  32 位 整数范围内。”
>这里已经暗示了用前缀和以及后缀和思想进行求解，先初始化前缀积以及后缀积数组起始值为1，两个for循环求前缀和后缀，一个for循环求ans。
>当然求ans的for循环也可以归并到第二个for循环中，只是这样更直观
>前缀和的思想就是：把“反复算的区间和”，提前算好存起来，用“两个前缀和相减”来替代“遍历区间”。空间换时间

---

## 你的代码

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        int[] pre = new int[n];
        pre[0] = 1;
        int[] end = new int[n];
        end[n - 1] = 1;
        for(int i = 1; i < n; i++){
            pre[i] = pre[i - 1] * nums[i - 1];
        }
        for(int i = n - 2; i >= 0; i--){
            end[i] = end[i + 1] * nums[i + 1];
        }
        for(int i = 0; i < n; i++){
            ans[i] = pre[i] * end[i];
        }
        return ans;
    }
}
```

```java
// 优化，只需要两个for循环，同时舍去ans数组，答案只要将end[i] * pre[i]即可，不需要再建一个新数组
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] pre = new int[n];
        pre[0] = 1;
        int[] end = new int[n];
        end[n - 1] = 1;
        for(int i = 1; i < n; i++){
            pre[i] = pre[i - 1] * nums[i - 1];
        }
        for(int i = n - 2; i >= 0; i--){
            end[i] = end[i + 1] * nums[i + 1];
            pre[i] *= end[i];
        }
        return pre;
    }
}
```

---

## 复杂度

- 解法一：时间 O(n)，空间 O(n)
- 解法二：时间 O(n)，空间 O(n)（省了 ans 数组，仍需 pre + end）

**终极优化（O(1) 额外空间）**：答案数组本身不算额外空间，直接把"前缀积"存在 answer 里，第二遍从右往左用"后缀积"变量直接乘：

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        // 第一遍：ans[i] = 左边所有数的乘积
        ans[0] = 1;
        for (int i = 1; i < n; i++) {
            ans[i] = ans[i - 1] * nums[i - 1];
        }
        // 第二遍：从右往左，r 维护右边所有数的乘积
        int r = 1;
        for (int i = n - 1; i >= 0; i--) {
            ans[i] *= r;
            r *= nums[i];
        }
        return ans;
    }
}
```
