# 88. 合并两个有序数组（简单）

---

## 题目

给你两个按非递减顺序排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。请你**合并** `nums2` 到 `nums1` 中，使合并后的数组同样按非递减顺序排列。`nums1` 的长度是 m + n，后 n 个位置是空的（0）。

```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]

输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
```

---

## 你的关键思路

> 倒序三指针，防止前面的元素被覆盖。三个指针分别是指向m-1 n-1 m+n-1
> **从后往前填**，因为 nums1 尾部是空的，从后往前填可以避免覆盖还没用的元素，实现 O(1) 额外空间。

---

## 你的代码

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        if(n == 0) return;
        int p1 = m - 1;
        int p2 = n - 1;
        int p = m + n - 1;
        while(p2 >= 0){
            if(p1 >= 0 && nums1[p1] > nums2[p2]){
                nums1[p--] = nums1[p1--];
            }else{
                nums1[p--] = nums2[p2--];
            }
        }
    }
}
```

---

## 复杂度

- 时间：O(m + n)，每个元素处理一次
- 空间：O(1)，原地合并
