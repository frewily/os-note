# 56. 合并区间

---

## 题目

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]`。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
（区间 [1,3] 和 [2,6] 重叠，合并为 [1,6]）

输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
```

---

## 你的关键思路

>1.二维数组的排序方式要自己指定如何排序
>2.List`<int[]>`的写法可以作为`int[][]`的动态数组的形式，但同时也要注意如何将 `Lit<int[]>` 转为 `int[][]`：`ans.toArray(new int[ans.size()][]);`
>3.java中二维数组也有类似有一维数组、集合那样的遍历方式，`for(int[] p : intervals)`，将二维数组中的每一个一维数组拿出来遍历
>4.本题的关键就是如何将二维数字排序以及如何用代码描述区间合并的逻辑

---

## 你的代码

```java
class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        List<int[]> ans = new ArrayList<>();
        for(int[] p : intervals){
            int m = ans.size();
            if(m > 0 && ans.get(m - 1)[1] >= p[0]){
                ans.get(m - 1)[1] = Math.max(ans.get(m - 1)[1], p[1]);
            }else{
                ans.add(p);
            }
        }
        return ans.toArray(new int[ans.size()][]);
    }
}
```

---

## 复杂度

- 时间：O(n log n)，排序主导
- 空间：O(n)，结果数组（排序栈 O(log n)）
