# 169. 多数元素（简单）

---

## 题目

给定一个大小为 `n` 的数组 `nums`，返回其中的多数元素。多数元素是指在数组中出现次数**大于** ⌊n/2⌋ 的元素。你可以假设数组是非空的，并且给定的数组总是存在多数元素。

```
输入：nums = [3,2,3]
输出：3

输入：nums = [2,2,1,1,1,2,2]
输出：2
```

---

## 你的关键思路

> 方法一：类比擂台比赛

---

## 你的代码

```java
class Solution {
    public int majorityElement(int[] nums) {
        int cur = 0;
        int life = 0;
        for(int num : nums){
            if(life == 0){
                cur = num;
                life = 1;
            }else{
                life += (cur == num ? 1 : -1);
            }
        }
        return cur;
    }
}
```

```java
// 法二：排序
class Solution {
    public int majorityElement(int[] nums) {
        Arrays.sort(nums);
        return nums[nums.length / 2];
    }
}
```

```java
// 法三：哈希检索
class Solution {
    public int majorityElement(int[] nums) {
        Map<Integer, Integer> map = new HashMap<>();
        for(int num : nums){
            map.put(num, map.getOrDefault(num, 0) + 1);
        }
        for(int num : nums){
            if(map.get(num) > nums.length / 2){
                return num;
            }
        }
        return -1;
    }
}
```

---

## 复杂度

- Boyer-Moore 投票：时间 O(n)，空间 O(1)
- 排序法：时间 O(n log n)，空间 O(1)（或 O(log n) 栈）
- 哈希法：时间 O(n)，空间 O(n)

**最优解是 Boyer-Moore**——利用"多数元素出现次数 > 一半"的性质，抵消后必然剩它。排序法因为多数元素必然落在中间位置所以也能解，但 O(n log n) 不如投票 O(n)。
