# 41. 缺失的第一个正数（困难）

---

## 题目

给你一个未排序的整数数组 `nums`，请你找出其中没有出现的最小的正整数。请实现时间复杂度为 O(n) 并且只使用常数级别额外空间的解决方案。

```
输入：nums = [1,2,0]
输出：3

输入：nums = [3,4,-1,1]
输出：2

输入：nums = [7,8,9,11,12]
输出：1
```

---

## 你的关键思路

> 1. **把数组当哈希表用**：值 v 应该待在索引 v-1 的位置（值范围 1..len 与下标 0..len-1 天然对应）
> 2. 原地交换：`nums[i]` 合法（1..len）且不在正确位置时，循环交换到正确位置
> 3. **用 while 不用 if**：换过来的元素可能也不在正确位置，需要继续修正
> 4. 交换终止条件：`nums[nums[i]-1] == nums[i]`——要么已归位，要么目标位置已有相同值（重复元素，不用再换）
> 5. 第二遍扫描：第一个 `nums[i] != i+1` 的位置就是答案；全部归位则答案是 len+1

---

## 你的代码

```java
class Solution {

    public int firstMissingPositive(int[] nums) {
        int len = nums.length;
        for(int i = 0; i < len; i++){
            // nums[i] 是当前数字的值
            // nums[i] - 1 是这个值「应该待的索引位置」
            // nums[nums[i] - 1]表示：「目标位置上现在放的是谁」
            // nums[nums[i] - 1] != nums[i]:「当前数字 nums[i] 应该去的位置上，放的并不是它自己」
            // 用while:交换过来的元素不一定就是符合当前位置的要求，所以需要不断修正，直到 i 位置的数字要么无效，要么已经在正确位置
            while(nums[i] > 0 && nums[i] <= len && nums[nums[i] - 1] != nums[i]){
                swap(nums, nums[i] - 1, i);
            }
        }
        for(int i = 0; i < len; i++){
            if(nums[i] - 1 != i){
                return i + 1;
            }
        }
        return len + 1;
    }

    private void swap(int[] nums, int index1, int index2) {
        int temp = nums[index1];
        nums[index1] = nums[index2];
        nums[index2] = temp;
    }
}
```

---

## 复杂度

- 时间：O(n)，均摊——每次交换都把至少一个数放到正确位置，总交换次数 ≤ n
- 空间：O(1)，原地交换
