# 287. 寻找重复数

---

## 题目

给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 范围内（含 1 和 n）。假设只有一个重复的整数，返回这个重复的数。**不能修改数组**，且只能使用常数级额外空间。

```
输入：nums = [1,3,4,2,2]
输出：2

输入：nums = [3,1,3,4,2]
输出：3
```

---

## 你的关键思路

> 把数组下标 i​ 当作链表节点，nums[i]​ 当作这个节点的 next 指针
>因为存在重复数字，这个「链表」必然有环；而环的入口对应的数值，就是那个重复的数。
>
> **Floyd 判圈两阶段**：
> - 阶段一：slow 走 1 步，fast 走 2 步，必在环内相遇（重复数保证有环）
> - 阶段二：新指针从起点出发，slow 从相遇点继续，都走 1 步——相遇点就是环入口
> - 数学原理：起点到环入口距离 = 相遇点绕环再走到入口的距离

---

## 你的代码

```java
class Solution {
    public int findDuplicate(int[] nums) {
        // 定义快慢指针
        int slow = 0;
        int fast = 0;
        // slow向前走一步，fast向前走两步，步数一致会导致无法进入循环
        // slow = nums[slow]：slow 走 1 步（等价于链表里的 slow = slow.next）
        // fast = nums[nums[fast]]：fast 走 2 步（等价于链表里的 fast = fast.next.next）
        slow = nums[slow];
        fast = nums[nums[fast]];
        // 因为有环，两者最终一定会在环上的某个位置 y（相遇点）碰面。
        while(slow != fast){
            slow = nums[slow];
            fast = nums[nums[fast]];
        }
        int pre1 = 0;
        int pre2 = slow;
        // 从起点出发的指针，和从相遇点出发的指针，每次都走 1 步，最终一定会在环入口相遇(数学推论)
        while(pre1 != pre2){
            pre1 = nums[pre1];
            pre2 = nums[pre2];
        }
        return pre1;
    }
}
```

---

## 复杂度

- 时间：O(n)
- 空间：O(1)
