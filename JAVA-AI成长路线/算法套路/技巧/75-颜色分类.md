# 75. 颜色分类

---

## 题目

给定一个包含红色、白色和蓝色、共 `n` 个元素的数组 `nums`，**原地**对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列。0 表示红色、1 表示白色、2 表示蓝色。只能使用常数空间，且**只能扫描一遍**。

```
输入：nums = [2,0,2,1,1,0]
输出：[0,0,1,1,2,2]
```

---

## 你的关键思路

> 1. **三指针**：left 指向下一个 0 的位置，right 指向下一个 2 的位置，i 遍历数组
> 2. `nums[i] == 0` → 和 left 交换，left++ 且 i++（换过来的只可能是 0 或已处理的 1）
> 3. `nums[i] == 2` → 和 right 交换，right-- **但 i 不动**（换过来的可能是 0，需要再判断）
> 4. `nums[i] == 1` → 直接 i++
> 5. 核心：只有换 2 时 i 不前进——因为右边换过来的元素还没处理过

---

## 你的代码

```java
class Solution {
    public void sortColors(int[] nums) {
        int left = 0, right = nums.length - 1;
        int i = 0;
        while (i <= right) {
            if (nums[i] == 0) {
                swap(nums, i++, left++);
            } else if (nums[i] == 2) {
                swap(nums, i, right--);
            } else if (nums[i] == 1) {
                i++;
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
}
```

---

## 复杂度

- 时间：O(n)，单遍扫描
- 空间：O(1)，原地交换
