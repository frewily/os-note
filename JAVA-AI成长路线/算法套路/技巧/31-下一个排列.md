# 31. 下一个排列

---

## 题目

整数数组的一个**排列**就是将其所有成员以序列或线性顺序排列。下一个排列是字典序中更大的下一个排列。如果不存在下一个更大的排列，则将数字重新排列成最小的排列（升序）。必须**原地**修改。

```
输入：nums = [1,2,3]
输出：[1,3,2]

输入：nums = [3,2,1]
输出：[1,2,3]（已经是最大排列，返回最小排列）

输入：nums = [1,1,5]
输出：[1,5,1]
```

---

## 你的关键思路

> 三步走：
> 1. 从右往左找到第一组升序 (i, j)，nums[i] < nums[j]
> 2. 从右往左找到第一个 k，nums[k] > nums[i]，交换
> 3. 反转 j 到末尾（把降序变升序）

> **为什么这样想（不用死背）**：
> - 排列的后缀是降序时，已经是该后缀能组成的最大排列，无法再变大
> - 所以第一步找的"第一个升序对 (i,j)"，就是从右往左数**第一个还能变大的位置**——改变 i 处的数，排列才会变大
> - 第二步：为了让增幅最小，选比 nums[i] 大一点点 的数（从右往左第一个大于它的）换过来
> - 第三步：交换后 j 之后仍是降序（最大序），反转成升序（最小序）——保证是"下一个"而不是"随便一个更大的"

---

## 你的代码

```java
class Solution {
    public void nextPermutation(int[] nums) {
        if (nums.length <= 1)
            return;
        int n = nums.length;
        int i = n - 2, j = n - 1; // i指向倒数第二个元素，j指向倒数第一个元素
        int k = n - 1; // 用于后面进行元素的交换
        // 找到第一个nums[i] < nums[j] 的情况,即第一组升序
        while (i >= 0 && nums[i] >= nums[j]) {
            i--;
            j--;
        }
        if (i >= 0) {
            // 从右往左找第一个nums[k] > nums[i],并进行交换
            while (nums[k] <= nums[i]) {
                k--;
            }
            swap(nums, i, k);
        }
        // 将j -> end的所有序列改成升序，保证是最小的
        reverse(nums, j, nums.length - 1);
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }

    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            swap(nums, left, right);
            left++;
            right--;
        }
    }
}
```

---

## 复杂度

- 时间：O(n)，三次线性扫描
- 空间：O(1)，原地修改
