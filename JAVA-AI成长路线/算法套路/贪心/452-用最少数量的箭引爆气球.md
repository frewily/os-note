# 452. 用最少数量的箭引爆气球

---

## 题目

有一些球形气球贴在一堵用 XY 平面表示的墙面上。墙面上的气球记录在整数数组 `points`，其中 `points[i] = [xstart, xend]` 表示水平直径在 `xstart` 和 `xend` 之间的气球。一支弓箭可以沿着 x 轴从不同点完全垂直地射出。在坐标 x 处射出一支箭，若有一个气球的直径的开始和结束坐标为 `xstart`、`xend`，且满足 `xstart ≤ x ≤ xend`，则该气球会被引爆。可以射出的弓箭的数量没有限制。返回引爆所有气球所必须射出的最小弓箭数。

```
输入：points = [[10,16],[2,8],[1,6],[7,12]]
输出：2
（射 x=6 引爆 [2,8] 和 [1,6]，射 x=11 引爆 [10,16] 和 [7,12]）

输入：points = [[1,2],[3,4],[5,6],[7,8]]
输出：4
（互不重叠，每个都要单独射）

输入：points = [[1,2],[2,3],[3,4],[4,5]]
输出：2
```

---

## 你的关键思路

> 排序用 Integer.compare​ —— 杜绝减法溢出
> 重叠时必须 cur = min(cur, p[1])​ —— 维护公共交集

> **补充（两种解法对比）**：
> - **你的解法（按左端点排序 + 维护交集）**：cur 记录当前所有重叠气球公共交集的右边界，下一个气球左端点超了就开新箭。正确且直观
> - **标准解法（按右端点排序）**：cur 直接是"当前箭的坐标"（第一个气球的右端点），下一个气球左端点 > cur 就加箭。更简洁，不需要 min 维护
> - 为什么右端点排序更优：右端点最早结束的气球决定了箭的最优位置——"贪心地让箭射在最右端"
> - **区间贪心家族**：56-合并区间（合并）、763-划分字母区间（切段）、452（选点）——都是"排序 + 贪心扫描"，区别只在排序键和判定条件

## 你的代码

```java
class Solution {
    public int findMinArrowShots(int[][] points) {
        Arrays.sort(points, (a, b) -> Integer.compare(a[0], b[0]));
        int cur = points[0][1];
        int ans = 1;
        for (int[] point : points) {
            if (point[0] > cur) {
                ans++;
                cur = point[1];
            } else {
                cur = Math.min(cur, point[1]); // ← 关键：维护交集
            }
        }
        return ans;
    }
}
```

## 复杂度

- 时间：O(n log n)，排序主导
- 空间：O(1)（不含排序空间）
