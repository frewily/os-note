# 55. 跳跃游戏

---

## 题目

给定一个非负整数数组 `nums`，最初位于第一个下标。数组中的每个元素代表在该位置可以跳跃的最大长度。判断是否能够到达最后一个下标。

```
输入：nums = [2,3,1,1,4]
输出：true

输入：nums = [3,2,1,0,4]
输出：false
```

---

## 你的关键思路

> 方法一：
	你的直觉：  这题要"试"很多种可能 → 回溯 ✅ 直觉没错
	实际情况：  同一位置被反复试 → 指数爆炸 ❌
	解决方式：  加 visited → 记忆化搜索（DP）✅ 能 AC
	最优方式：  发现"能到这就能到那"的性质 → 贪心 ✅ O(n)

>方法二：
	如果某一个作为 起跳点 的格子可以跳跃的距离是 3，那么表示后面 3 个格子都可以作为 起跳点
	可以对每一个能作为 起跳点 的格子都尝试跳一次，把 能跳到最远的距离 不断更新
	如果可以一直跳到最后，就成功了

>8.23二刷：
>	依旧没有独立做出来，总结一下关键思路：不关心具体是从哪个格子跳到最后的，只判断能否跳到最后。因此用一个max记录能跳到的最大值，只要这个max大于等于当前的格子对应的下标，就能跳到当前的格子，再维护max即可

## 你的代码

```java
// 解法一：回溯+路径标记
class Solution {
    public boolean canJump(int[] nums) {
        boolean[] visited = new boolean[nums.length];
        return backTrack(nums, 0, visited);
    }
    private boolean backTrack(int[] nums, int cur, boolean visited[]){
        if(cur == nums.length - 1) return true;
        if(visited[cur]) return false; // 已经试过cur走不通，直接跳过
        visited[cur] = true;  // 第一次访问cur，标记为true，防止后面重复访问
        for(int i = 1; i <= nums[cur] && cur + i < nums.length; i++){
            if(backTrack(nums, cur + i, visited)){
                return true;
            }
        }
        return false;
    }
}
```

```java
// 解法二：贪心算法
class Solution {
    public boolean canJump(int[] nums) {
        int max = 0; // 每一步能达到的最远距离
        for(int i = 0; i < nums.length; i++){
            if(max < i) return false;  // 前一轮能达到的最远距离还达不到i，返回false
            max = Math.max(max, i + nums[i]);  // 更新能到达的最远距离
        }
        return true;
    }
}
```

---

## 复杂度

- 解法一：时间 O(n²) 最坏，空间 O(n)
- 解法二：时间 O(n)，空间 O(1)
