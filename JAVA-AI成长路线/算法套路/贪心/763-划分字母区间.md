# 763. 划分字母区间

---

## 题目

给你一个字符串 `s`。要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。返回表示每个字符串片段长度的列表。

```
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
（"ababcbaca"、"defegde"、"hijhklij"）
```

---

## 你的关键思路

> 先预处理每个字母的"最远势力范围"，然后从左往右扫描，动态维护当前段的右边界；一旦到达边界就果断切开——这就是贪心划分字母区间的完整思路。
>贪心体现在：每当发现当前段已经"自包含"（end == i），就毫不犹豫地立刻切开——不做任何观望、不尝试更长的组合。这个"能切就切、绝不拖延"的策略，恰好就是全局最优的。

---

## 你的代码

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        char[] c = s.toCharArray();
        int[] len = new int[26]; // 统计每个字母最后出现的位置
        for(int i = 0; i < c.length; i++){
            len[c[i] - 'a'] = i;  // 更新字母最后出现的位置为 i
        }
        int start = 0, end = 0;
        List<Integer> ans = new ArrayList<>();
        for(int i = 0; i < c.length; i++){
            end = Math.max(end, len[c[i] - 'a']); // 注意len中为c[i] - 'a'，字母和下标的对应关系
            if(end == i){  // 当前区间合并完毕
                ans.add(end - start + 1);
                start = end + 1;
            }
        }
        return ans;
    }
}
```
---

## 复杂度

- 时间：O(n)，两次遍历
- 空间：O(1)，固定 26 长度的数组
