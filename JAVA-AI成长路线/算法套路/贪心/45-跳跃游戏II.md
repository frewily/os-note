# 45. 跳跃游戏 II

---

## 题目

给定一个非负整数数组，最初位于第一个下标。数组中的每个元素代表在该位置可以跳跃的最大长度。使用最少的跳跃次数到达数组的最后一个位置。

```
输入：nums = [2,3,1,1,4]
输出：2
（跳 1 步到下标 1，再跳 3 步到终点）
```

---

## 你的关键思路

> 循环条件是 i < nums.length - 1，不是​ i < nums.length。
	原因是当你已经覆盖到终点时，不需要再跳一步了。如果在最后一个位置还触发 i == curEnd，会多算一步。
	
>贪心计数不是"发现了更远就+1"，而是"不得不跳的时候才+1"。
	curEnd 就是那个"不得不"的分界线。

>8.23二刷：
>for循环遍历整个数组，curEnd记录当前的位置，step记录跳跃的次数，max记录能达到的最大距离。实际上就是在跳跃游戏的记录上加上step，当遍历到的当前下标等于curEnd时，就进行跳跃。

---

## 你的代码

```java
class Solution {
    public int jump(int[] nums) {
        int max = 0;  // 每一步能达到的最远点位下标
        int step = 0;
        int curEnd = 0;
        if(nums.length == 1) return 0;
        for(int i = 0; i < nums.length - 1; i++){
            max = Math.max(max, nums[i] + i);
            if(i == curEnd){  // 当前步的覆盖范围用完了
                step++;       // 必须要跳一步
                curEnd = max; // 更新到下一步的覆盖范围
            }
        }
        return step;
    }
}
```
---

## 复杂度

- 时间：O(n)，单次遍历
- 空间：O(1)
