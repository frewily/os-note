# 71. 简化路径

---

## 题目

给你一个字符串 `path`，表示指向某一文件或目录的 Unix 风格绝对路径，请你将其转化为更加简洁的规范路径。规则：单个点 `.` 表示当前目录；两个点 `..` 表示上一级目录；多个连续斜杠视为一个；返回的规范路径必须以 `/` 开头，且两个目录名之间必须只有一个斜杠，最后一个目录名（如果存在）不能以 `/` 结尾。

```
输入：path = "/home/"
输出："/home"

输入：path = "/../"
输出："/"

输入：path = "/home//foo/"
输出："/home/foo"

输入：path = "/a/./b/../../c/"
输出："/c"
```
