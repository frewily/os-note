# 20. 有效的括号

---

## 题目

给定一个只包括 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串 `s`，判断字符串是否有效。有效字符串需满足：左括号必须用相同类型的右括号闭合；左括号必须以正确的顺序闭合；每个右括号都有一个对应的相同类型的左括号。

```
输入：s = "()"
输出：true

输入：s = "()[]{}"
输出：true

输入：s = "(]"
输出：false

输入：s = "([)]"
输出：false
```

---

## 你的关键思路

> 用 hashmap 存放匹配的一对括号，key 为右括号，value 为左括号，然后遍历 s 中的元素，匹配到 key 就看栈顶元素，匹配到 value push 到栈中。最后栈中为空就返回 true，否则返回 false
> 注意：批量放入 hashmap 用 Map.of()；入栈的方法是 push，不是 add（用 add 不会报错，但是是往末尾追加元素）

> **二刷修正（原代码的隐藏坑）**：
> 1. `map.get(c) == stack.peek()` 用 `==` 比较 **Character 对象**是隐患——碰巧能过是因为 Java 缓存了 -128~127 的 Character 对象，括号 ASCII 都在该范围。规范写法用 `.equals()`
> 2. 空栈时 `peek()` 返回 null，原代码靠 `== null` 判断碰巧兜住——显式加 `!stack.isEmpty()` 更清晰
> 3. 修正后的判断：`else if (!stack.isEmpty() && map.get(c).equals(stack.peek()))`
> 4. 这和 25 题 `pre = head` 是同一类问题：**碰巧能过 ≠ 正确**，面试官会追问

---

## 你的代码

```java
class Solution {
    public boolean isValid(String s) {
        if(s.length() % 2 != 0) return false;
        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Character> map = new HashMap<>(Map.of(
            ')','(',
            ']','[',
            '}','{'
        ));
        for(char c : s.toCharArray()){
            if(!map.containsKey(c)){
                stack.push(c);
            }else if(!stack.isEmpty() && map.get(c).equals(stack.peek())){
                // 修正：== → equals()（比较内容不比较引用）；显式判空
                stack.pop();
            }else{
                return false;
            }
        }
        return stack.isEmpty();
    }
}
```

## 复杂度

- 时间：O(n)，每个字符入栈/出栈各一次
- 空间：O(n)，栈最坏存 n/2 个左括号
