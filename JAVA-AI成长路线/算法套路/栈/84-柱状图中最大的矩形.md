# 84. 柱状图中最大的矩形

---

## 题目

给定 `n` 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1。求在该柱状图中，能够勾勒出来的矩形的最大面积。

```
输入：heights = [2,1,5,6,2,3]
输出：10
（最大矩形：高度 5 和 6 的柱子，面积 5 × 2 = 10）
```

---

## 你的关键思路

> 用单调递增栈，在柱子“被挡住”的那一刻，立刻计算它能形成的最大矩形，左右边界由栈自动给出。
>因为矩形高度被当前柱子锁死，所以左右都不能跨过“第一个更矮的柱子”；左边第一个更矮的位置，就是矩形能扩展到的最左边界。

> **复习拆解（下次复习先看这段）**：
> 1. **核心思想**：每根柱子 i 作为"矩形高"时，矩形宽度 = 右边第一个更矮 - 左边第一个更矮 - 1。暴力做法是每根柱子左右扩展找边界，O(n²)
> 2. **单调递增栈**（栈内高度严格递增）：栈里的柱子都是"还没找到右边界"的候选。新柱子 h 比栈顶矮时，栈顶柱子的右边界确定了（就是 h 这根）→ 出栈结算
> 3. **出栈结算公式**：`heights[i] × (right - left - 1)`——i 是出栈柱，left 是它下面那根（左边第一个更矮），right 是当前柱子（右边第一个更矮）
> 4. **两个哨兵**：
>    - 栈底 `-1`：让第一根柱子也有 left（-1 表示扩展到最左边）
>    - 数组末尾虚拟高度 `-1`：强制所有柱子出栈结算
> 5. **和 739 的联系**：739 是"遇到更大出栈算距离"，这题是"遇到更矮出栈算面积"——同一套单调栈骨架，判断方向相反

---

## 你的代码

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        Deque<Integer> st = new ArrayDeque<>();
        st.push(-1); // 在栈中只有一个数的时候，栈顶的「下面那个数」是 -1，对应 left[i] = -1 的情况
        int ans = 0;
        for (int right = 0; right <= n; right++) {
            int h = right < n ? heights[right] : -1;
            while (st.size() > 1 && heights[st.peek()] >= h) {
                int i = st.pop(); // 矩形的高（的下标）
                int left = st.peek(); // 栈顶下面那个数就是 left
                ans = Math.max(ans, heights[i] * (right - left - 1));
            }
            st.push(right);
        }
        return ans;
    }
}
```

---

## 复杂度

- 时间：O(n)，每个下标入栈出栈各一次
- 空间：O(n)，栈
