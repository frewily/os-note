# 32. 最长有效括号（困难）

---

## 题目

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

```
输入：s = "(()"
输出：2
（最长有效括号子串是 "()"）

输入：s = ")()())"
输出：4
（最长有效括号子串是 "()()"）

输入：s = ""
输出：0
```

---

## 你的关键思路

> 1. **栈里存下标，不存括号**——需要下标计算长度
> 2. **解法一（标记法）**：匹配成功的括号标记为 true，然后找最长连续 true 段——直观但需要两遍扫描
> 3. **解法二（栈底基准法）**：栈底永远存"最近一个无法配对的括号下标"作为基准，`i - 基准` 就是当前有效长度；遇到无法配对的右括号就替换基准
> 4. 核心理解：**有效括号长度 = 当前位置 - 最近失配位置**

---

## 你的代码

```java
class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length();
        boolean[] isValid = new boolean[n];
        Deque<Integer> st = new ArrayDeque<>();  // 存储左括号的下标
        for(int i = 0; i < n; i++){
            if(s.charAt(i) == '('){
                st.push(i);
            }else if(!st.isEmpty()){
                isValid[i] = isValid[st.pop()] = true;  // 匹配成功的标记为true
            }
        }
        // 最长有效括号即为 isValid 中的最长连续 true
        int ans = 0;
        int seq = 0; // 记录目前连续的序列
        for(boolean b : isValid){
            if(b){
                seq++;
                // 注意计数的时候是计数完之后立马就要更新最大值，而不是等seq清零后才更新最大值。
                ans = Math.max(ans, seq);
            }else{
                seq = 0;
            }
        }
        return ans;
    }
}
```

```java
// 优化成一次循环
class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length();
        Deque<Integer> st = new ArrayDeque<>();  // 存储左括号的下标
        st.push(-1);  // // 栈底元素表示永远无法配对的括号下标
        int ans = 0;
        for(int i = 0; i < n; i++){
            if(s.charAt(i) == '('){
                st.push(i);
            }else if(st.size() > 1){  // 右括号，情况一:有左括号，弹出左括号，进行配对
                st.pop();
                ans = Math.max(ans, i - st.peek());  // st.peek() + 1 到 i 都是配好队的
            }else{  // 右括号，情况二：没有左括号，压入栈底，s[i] 是永远无法配对的右括号
                st.pop();
                st.push(i);  // 替换栈底
            }
        }
        return ans;
    }
}
```
