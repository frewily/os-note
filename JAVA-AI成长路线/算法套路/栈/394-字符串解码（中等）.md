# 394. 字符串解码（中等）

---

## 题目

给定一个经过编码的字符串，返回解码后的字符串。编码规则：`k[encoded_string]`，表示 `encoded_string` 重复 k 次。

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"

输入：s = "3[a2[c]]"
输出："accaccacc"
```

---

## 你的关键思路

> 遇到`[`就存档（倍数+字符串都压栈，完事后要清零倍数），遇到`]`就读档（弹栈、展开、拼回去，拼回去时要注意时新建一个sb对象，先拷贝resStack中暂存的结果，再在末尾追加乘完倍数的字符串）。
就像打游戏进了副本 → 存档 → 打完 Boss → 读档回到主世界继续走
凡是遇到"一层套一层、需要从内往外算"的结构，第一反应就是栈。（存档，读档）

---

## 你的代码

```java
class Solution {
    public String decodeString(String s) {

        /* ===== 核心变量说明 ===== */
        // res：当前层正在拼接的字符串（遇到 [ 时会重置，遇到 ] 时会拼回去）
        StringBuilder res = new StringBuilder();

        // multi：当前层累积的数字倍数（比如 "100" 会逐步算成 100）
        int multi = 0;

        // stackMulti：倍数栈，遇到 [ 时把当前 multi 压进去，遇到 ] 时弹出来用
        Deque<Integer> stackMulti = new ArrayDeque<>();

        // stackRes：字符串栈，遇到 [ 时把 res 暂存，遇到 ] 时弹出来拼回去
        Deque<String> stackRes = new ArrayDeque<>();


        /* ===== 逐个遍历字符 ===== */
        for (char c : s.toCharArray()) {

            // ── 情况1：遇到左括号 [ ──────────────────────
            if (c == '[') {
                // 把当前倍数压入栈，等对应的 ] 来了再用
                stackMulti.push(multi);

                // 把当前已拼好的字符串暂存到栈里
                stackRes.push(res.toString());

                // 重置：进入新的一层嵌套，倍数和结果都要从头开始
                multi = 0;
                res = new StringBuilder();
            }

            // ── 情况2：遇到右括号 ] ──────────────────────
            else if (c == ']') {
                // 弹出这一层对应的倍数
                int curMulti = stackMulti.pop();

                // 把当前 res 重复 curMulti 次，得到展开后的子串
                StringBuilder tmp = new StringBuilder();
                for (int i = 0; i < curMulti; i++) {
                    tmp.append(res);
                }

                // 弹出上一层暂存的字符串，把展开后的子串拼回去
                // 比如上一层是 "a"，tmp 是 "bcbc"，结果变成 "abcbc"
                res = new StringBuilder(stackRes.pop()).append(tmp);
            }

            // ── 情况3：遇到数字字符 '0' ~ '9' ────────────
            else if (c >= '0' && c <= '9') {
                // 多位数字逐步累积：multi * 10 + 当前位
                // 比如字符流依次读到 '1','0','0' → 1 → 10 → 100
                // (c - '0') 是利用 ASCII 码差值把 char 转成 int，比 Integer.parseInt() 更高效
                multi = multi * 10 + (c - '0');
            }

            // ── 情况4：普通字母 ──────────────────────────
            else {
                // 直接追加到当前层的字符串里
                res.append(c);
            }
        }

        // 遍历结束，res 就是最终解码完的字符串
        return res.toString();
    }
}
```

```java
// 拓展：一个栈
class Solution {
    public String decodeString(String s) {
        Deque<Object> stack = new LinkedList<>();
        int num = 0;
        StringBuilder cur = new StringBuilder();

        for (char ch : s.toCharArray()) {
            if (Character.isDigit(ch)) {
                // 累计数字
                num = num * 10 + (ch - '0');
            } else if (ch == '[') {
                // 遇到'['将当前字符串和数字压栈
                stack.push(num);
                stack.push(cur.toString());
                // 重置
                num = 0;
                cur = new StringBuilder();
            } else if(ch == ']'){
                // 遇到']'弹出数字和字符串前缀
                String prefix = (String) stack.pop();
                int repeat = (int) stack.pop();
                // 重新构建字符串
                StringBuilder tmp = new StringBuilder();
                for (int i = 0; i < repeat; i++){
                    tmp.append(cur);
                }
                // 拼接字符串
                cur = new  StringBuilder(prefix).append(tmp);
            }else {
                // 普通字母直接添加
                cur.append(ch);
            }
        }
        return cur.toString();
    }
}
```

## 复杂度

- 时间：O(n)，每个字符遍历一次，展开操作的总量级也不超过 n
- 空间：O(n)，两个栈
