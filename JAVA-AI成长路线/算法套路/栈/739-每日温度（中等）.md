# 739. 每日温度（中等）

---

## 题目

给定一个温度数组 `temperatures`，返回一个数组，每个位置表示**需要等几天**才能等到更高的温度。如果之后没有更高的温度，填 0。

```
输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]
```

---

## 你的关键思路

> 1. 栈里存的是**下标**，不是温度值——因为需要计算天数差
> 2. 维护一个**递减栈**：栈顶到栈底温度递减
> 3. 当前温度 > 栈顶温度 → 出栈，计算天数差 → 重复直到栈空或温度不高于栈顶
> 4. 当前温度 ≤ 栈顶温度 → 入栈等待

---

## 你的代码

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int[] res = new int[temperatures.length];
        Deque<Integer> stack = new LinkedList<>();
        for(int i = 0; i < temperatures.length; i++){
            while(!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]){
                int cur = stack.pop();
                res[cur] = i - cur;
            }
            stack.push(i);
        }
        return res;
    }
}
```
---

## 复杂度

- 时间：O(n)，每个元素入栈出栈各一次
- 空间：O(n)，栈
