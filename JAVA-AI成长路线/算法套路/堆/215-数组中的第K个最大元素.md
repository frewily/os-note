# 215. 数组中的第 K 个最大元素

---

## 题目

给定一个整数数组 `nums` 和一个整数 `k`，返回数组中第 k 个最大的元素。

```
输入：nums = [3,2,1,5,6,4], k = 2
输出：5
```

---

## 你的关键思路

**解法一：计数桶**
> 值域已知且不大时最优——统计每个数字出现次数，从高往低数够 k 个就停。空间换时间，O(n) 搞定。

**解法二：快速选择**
> 快速排序的 partition 每次能确定一个元素的最终位置。如果这个位置恰好是第 k 大，直接返回；否则只递归一半。随机选 pivot 避免最坏情况 O(n²)。

---

## 你的代码

```java
// 解法一
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 创建一个长度为 20001​ 的数组 bucket，用来统计每个数字出现的次数
        int[] bucket = new int[20001];
        for(int i = 0; i < nums.length; i++){
            bucket[nums[i] + 10000]++; // 因为数组下标不能为负数，所以用 +10000 做偏移量
        }
        // buckets[x] 的含义是：值为 x - 10000 的数字在数组中出现了几次
        //  从大到小"倒着数"
        for(int i = 20000; i >= 0; i--){
            k = k - bucket[i];
            if(k <= 0){
                return i - 10000;
            } 
        }
        return 0;
    }
}
```

```java
// 解法二
class Solution {
    public int findKthLargest(int[] nums, int k) {
        return quickSelect(nums, 0, nums.length - 1, nums.length - k);
    }
    private int quickSelect(int[] nums, int left, int right, int target){
        if(left == right) return nums[left];
        int pos = position(nums, left, right);
        if(pos == target) return nums[pos];
        // 判断已经归位的 pos 和 target 的关系，看看接下来是往哪一边继续
        if(pos < target) return quickSelect(nums, pos + 1, right, target);
        if(pos > target) return quickSelect(nums, left, pos - 1, target);
        return 0;
    }
    // 将一个元素放到数组中正确的位置，并返回对应的下标，与target对比
    private int position(int[] nums, int left ,int right){

        // ★ 加这两行：随机选一个位置，和最右交换
        int rand = ThreadLocalRandom.current().nextInt(left, right + 1);
        swap(nums, rand, right);

        int pivot = right;  // 要归位的点,由于上面代码，保证了是随机的
        int i = left; // 标记比pivot小的元素下标
        for(int j = left; j < right; j++){  // 从left -> right，不是nums.length
            if(nums[j] < nums[pivot]){
                swap(nums, i, j);
                i++;
            }
        }
        // pivot归位
        swap(nums, i, pivot); // 循环结束后，i 恰好指向"小于 pivot 区域"的末尾。pivot 应该放在 i 的位置
        return i;
    }
    private void swap(int[] nums, int left, int right){
        int temp = nums[right];
        nums[right] = nums[left];
        nums[left] = temp;
    }
}
```
---

## 复杂度

- 解法一：时间 O(n)，空间 O(20001)（值域固定）
- 解法二：时间 O(n) 平均 / O(n²) 最坏，空间 O(log n)（递归栈）
