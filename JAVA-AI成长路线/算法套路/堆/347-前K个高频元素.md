# 347. 前 K 个高频元素

---

## 题目

给你一个整数数组 `nums` 和一个整数 `k`，返回其中出现频率前 k 高的元素。

```
输入：nums = [1,1,1,2,2,3], k = 2
输出：[1,2]
```

---

## 你的关键思路

> 1. HashMap 统计每个数字出现频率
> 2. 维护一个**大小为 k 的小根堆**（PriorityQueue），堆顶是频率最小的
> 3. 堆大小超过 k 时弹出堆顶——保证堆里始终是频率前 k 大的
> 4. 小根堆不用大根堆，因为只需要淘汰"最弱的"，堆顶出队成本 O(log k)

---

## 你的代码

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> freqMap = new HashMap<>();
        // 将数字和出现的频率映射到哈希表中
        for(int i = 0 ; i < nums.length; i++){
            freqMap.put(nums[i], freqMap.getOrDefault(nums[i], 0) + 1);
        }
        // 构建小根堆
        // Comparator.comparingInt(freqMap::get）  比较两个元素时，去 freqMap 里查它们各自的频率，按频率从小到大排
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(Comparator.comparingInt(freqMap::get));
        // 维护堆的大小为k
        for(int key : freqMap.keySet()){   // keySet:把 HashMap 里所有的"键"取出来，放到一个 Set 集合里返回
            minHeap.offer(key);
            if(minHeap.size() > k) minHeap.poll();  // 小根堆，堆顶为频率最小的，数量达到k时删除频率最小的即可
        }
        List<Integer> res = new ArrayList<>();
        while(!minHeap.isEmpty()){
            res.add(minHeap.poll());
        }
        return res.stream().mapToInt(Integer::intValue).toArray();
    }
```

---

## 复杂度

- 时间：O(n log k)，堆操作每次 O(log k)
- 空间：O(n)，HashMap + 堆
