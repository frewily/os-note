# 151. 反转字符串中的单词（中等）

---

## 题目

给你一个字符串 `s`，请你反转字符串中**单词**的顺序。单词是由非空格字符组成的字符串。`s` 中使用至少一个空格将字符串中的**单词**分隔开。返回单词顺序颠倒且单词之间用单个空格连接的结果字符串。**注意**：输入字符串可能在单词前后有多余空格，单词间也可能有多余空格。

```
输入：s = "the sky is blue"
输出："blue is sky the"

输入：s = "  hello world  "
输出："world hello"

输入：s = "a good   example"
输出："example good a"
```

---

## 你的关键思路

> 1. 先 `strip()` 去掉首尾空格
> 2. **倒序双指针**：start/end 从末尾开始，左移找空格确定单词边界
> 3. 内层循环分两段：先跳过非空格（找单词起点），再跳过空格（找下一个单词终点）
> 4. 每个单词 append 进 StringBuilder，最后 strip 掉末尾多余空格
> 5. ⚠️ 空串判断要用 `isEmpty()`，不能用 `==`（比较引用不比较内容）

---

## 你的代码

```java
class Solution {
    public String reverseWords(String s) {
        s = s.strip();
        if(s == "") return s;
        int len = s.length();
        StringBuilder res = new StringBuilder();
        int start = len - 1, end = len - 1;
        while(start >= 0){
            while(start >= 0 && s.charAt(start) != ' ') start--;  // 搜索首个空格
            res.append(s.substring(start + 1, end + 1) + " ");
            while(start >= 0 && s.charAt(start) == ' ') start--;
            end = start;  // 跳过中间的多个空格
        }
        return res.toString().strip();
    }
}
```

---

## 复杂度

- 时间：O(n)，单遍扫描
- 空间：O(n)，StringBuilder 存结果
