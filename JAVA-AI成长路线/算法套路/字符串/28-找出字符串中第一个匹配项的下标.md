# 28. 找出字符串中第一个匹配项的下标

---

## 题目

给你两个字符串 `haystack` 和 `needle`，请你在 `haystack` 字符串中找出 `needle` 字符串的第一个匹配项的下标（下标从 0 开始）。如果 `needle` 不是 `haystack` 的一部分，则返回 `-1`。

```
输入：haystack = "sadbutsad", needle = "sad"
输出：0
（"sad" 在下标 0 和 6 处匹配，第一个匹配项是下标 0）

输入：haystack = "leetcode", needle = "leeto"
输出：-1
```

---

## 你的关键思路

> 1. **暴力匹配**：外层循环枚举 haystack 的每个"发起点" i
> 2. 起点范围 `i <= n - m`——超过 n-m 剩余长度不够匹配 needle
> 3. 内层双指针 a/b 逐字符比对，b 走完 m 个字符说明完全匹配
> 4. 匹配成功返回发起点 i，全部失败返回 -1
> 5. 进阶：KMP 算法（O(n+m)）利用"已匹配前缀"跳过重复比较，面试被追问时再展开

---

## 你的代码

```java
class Solution {
    public int strStr(String ss, String pp) {
        int n = ss.length(), m = pp.length();
        char[] s = ss.toCharArray(), p = pp.toCharArray();
        // ss能匹配的范围，只有(0, n - m),超过n - m 后面的长度不够匹配
        for (int i = 0; i <= n - m; i++) {
            // 从原串的「发起点」和匹配串的「首位」开始，尝试匹配
            int a = i, b = 0;
            while (b < m && s[a] == p[b]) {
                a++;
                b++;
            }
            // 如果能够完全匹配，返回原串的「发起点」下标
            if (b == m) return i;
        }
        return -1;
    }
}
```

---

## 复杂度

- 时间：O(n × m)，最坏情况每个起点都匹配到接近末尾
- 空间：O(1)（用 charAt 代替 toCharArray 可省去复制）
