# 6. Z 字形变换（中等）

---

## 题目

将一个给定字符串 `s` 根据给定的行数 `numRows`，以从上往下、从左到右进行 Z 字形排列。

```
输入：s = "PAYPALISHIRING", numRows = 3
输出："PAHNAPLSIIGYIR"
（排列后：
P   A   H   N
A P L S I I G
Y   I   R
按行读取 → "PAHNAPLSIIGYIR"）

输入：s = "PAYPALISHIRING", numRows = 4
输出："PINALSIGYAHRPI"
```

---

## 你的关键思路

> 1. **按行分配**：numRows 个 StringBuilder，每个字符按"当前行号"放入对应行
> 2. **方向翻转**：flag 表示移动方向（1 向下 / -1 向上），`i % (numRows-1) == 0` 时在首尾行翻转——首行 0 和末行 numRows-1 都是 (numRows-1) 的倍数
> 3. 最后把所有行拼接起来
> 4. 边界：numRows < 2 直接返回原串（也避免 numRows=1 时除以 0）

---

## 你的代码

```java
class Solution {
    public String convert(String s, int numRows) {
        if(numRows < 2) return s;
        List<StringBuilder> res = new ArrayList<>();
        for(int i = 0; i < numRows; i++) res.add(new StringBuilder());
        int i = 0, flag = -1;
        for(char c : s.toCharArray()){
            res.get(i).append(c);
            if(i % (numRows - 1) == 0) flag = -flag;
            i += flag;
        }
        StringBuilder ans = new StringBuilder();
        for(StringBuilder sb : res) ans.append(sb);
        return ans.toString();
    }
}
```

---

## 复杂度

- 时间：O(n)，每个字符处理一次
- 空间：O(n)，存所有行
