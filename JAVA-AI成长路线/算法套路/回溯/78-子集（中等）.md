# 78. 子集（中等）

---

## 题目

给定一个不含重复元素的整数数组 `nums`，返回该数组所有可能的子集。

```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

---

## 关键思路

- 用 `start` 控制不走回头路
- **每次进入 dfs 都把当前路径加入结果集**（不是等到叶子节点）
- 子集问题不要求选满，每个节点都是答案

---

## 你的代码

```java
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        dfs(0, nums, res, new ArrayList<Integer>());
        return res;
    }

    private void dfs(int start, int[] nums, List<List<Integer>> res, List<Integer> path){
        res.add(new ArrayList<>(path));
        for(int i = start; i < nums.length; i++){
            path.add(nums[i]);
            dfs(i + 1, nums,res, path);
            path.remove(path.size() - 1);
        }
    }
}
```

---

## 复杂度

- 时间：O(n × 2ⁿ)
- 空间：O(n)
