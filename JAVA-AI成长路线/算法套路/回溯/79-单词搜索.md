# 79. 单词搜索

---

## 题目

给定一个 `m x n` 的网格 `board` 和一个字符串 `word`，如果 `word` 存在于网格中返回 `true`。每个单元格的字母只能用一次（不能重复使用）。
![499](assets/79-单词搜索/file-20260726211843375.png)
```
输入：board = [["A","B","C","E"],
              ["S","F","C","S"],
              ["A","D","E","E"]]
      word = "ABCCED"
输出：true
```

---

## 你的关键思路

> 1. 遍历网格的每个格子作为起点，从起点开始四方向 DFS
> 2. 用 `board[r][c] = '\0'` 标记已访问（避免重复使用），递归完后恢复（回溯还原）
> 3. 匹配完最后一个字符时返回 true，中途字符不匹配直接剪枝返 false
> 4. 核心逻辑：`board[r][c] != word.charAt(count)` 就返回 false，等于走不下去就回溯

---

## 你的代码

```java
class Solution {
    public boolean exist(char[][] board, String word) {
        for(int r = 0; r < board.length; r++){
            for(int c = 0; c < board[0].length; c++){
                if(dfs(board, word, r, c, 0)) return true;
            }
        }
        return false;
    }
    private boolean dfs(char[][] board, String word, int r, int c, int count){
        if(r >= board.length || r < 0 || c >= board[0].length || c < 0 || board[r][c] != word.charAt(count)){
            return false;
        }
        if(count == word.length() - 1) return true;
        board[r][c] = '\0';
        boolean res = dfs(board, word, r + 1, c, count + 1) || dfs(board, word, r - 1, c, count + 1) ||
                      dfs(board, word, r, c + 1, count + 1) || dfs(board, word, r, c - 1, count + 1);
        board[r][c] = word.charAt(count);
        return res;
    }
}
```

---

## 复杂度

- 时间：O(m × n × 3ᴸ)，L = word 长度（四方向，但走过的格子不能回，所以实际是 3 方向）
- 空间：O(L)，递归栈深度
