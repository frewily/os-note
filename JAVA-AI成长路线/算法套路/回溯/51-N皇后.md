# 51. N 皇后

---

## 题目

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。`n` 皇后问题研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],
      ["..Q.","Q...","...Q",".Q.."]]
```

---

## 你的关键思路

> 经典回溯模版，只是多了一些理解。首先皇后的分布只能是每一行每一列各一个（反证法），然后住对角线（r + c）和副对角线(r - c)都有规律，需要中找出来，表现出来就是三个布尔类型的数组visisted,主对角线和副对角线，都满足才能放皇后。每一次dfs都是向后推进一列，dfs中的for循环则是在当前列中遍历每一行，visisted判断当前行是否可能。queens[r] = c 是直接覆盖，不需要回溯是因为 queens[r] 只会在 dfs(r, ...) 这一层递归中被读取和使用，进入下一层递归后没人会再读它，所以覆盖写没问题，不需要恢复。回溯时只需要恢复"会被后续递归读取的共享状态"。queens[r] 是每行独立写的，且只在 r`==`n 时一次性读取，所以不需要恢复。

> **小总结**：
> - **行 → 递归，列 → for 循环**：dfs 推进行，for 遍历列，和全排列"位置 → 递归，元素 → for"是同一个骨架
> - **三个冲突数组** = 全排列里的 used[] 升级成三个维度（列 + 两条对角线），满足全部才放
> - **对角线规律**：主对角线 r+c 恒定、副对角线 r-c 恒定，副对角线加偏移 n-1 转成非负下标
> - **backtrack 时机**：只恢复"共享状态"（col/diag 数组），行独立的 queens[r] 覆盖写即可——你已经抓住了本质

## 你的代码

```java
class Solution {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> ans = new ArrayList<>();
        int[] queens = new int[n];  // 皇后放在(r, queens[r])
        boolean[] col = new boolean[n];  // 类似于visited[]数组，判断当前列是否放了皇后
        boolean[] diag1 = new boolean[2 * n - 1];  // 同一主对角线，r + c 为定值,区间为[0, 2n]
        boolean[] diag2 = new boolean[2 * n - 1];  // 同一副对角线，r - c 为定值,区间为[-n, n]
        dfs(0, queens, col, diag1, diag2, n, ans);
        return ans;
    }

    private void dfs(int r, int[] queens, boolean[] col, boolean[] diag1, boolean[] diag2, int n, List<List<String>> ans){
        // 回溯模版，先处理回溯停止的情况
        if(r == n){
            List<String> board = new ArrayList<>();
            for(int c : queens){
                char[] row = new char[n];
                Arrays.fill(row, '.');
                row[c] = 'Q';
                board.add(new String(row));  // 这里注意要把row从int[]类型转成string类型
            }
            ans.add(board);
            return;
        }
        // 当前在第queens[r]列，从第c行开始，判断是否可以放皇后
        for(int c = 0; c < n; c++){
            int rc = r - c + n - 1; // 副对角线r - c可能是负数，这里加 n - 1 确保diag2索引为正
            if(!col[c] && !diag1[r + c] && !diag2[rc]){
                queens[r] = c;  // 直接覆盖，不需要回溯
                col[c] = diag1[r + c] = diag2[rc] = true;
                dfs(r + 1, queens, col, diag1, diag2, n, ans);
                col[c] = diag1[r + c] = diag2[rc] = false;
            }
        }
    }
}
```

---

## 复杂度

- 时间：O(n!)，每层选择数递减（第一层 n 种，第二层至多 n-1 种…）
- 空间：O(n)，三个数组 + 递归栈
