# 22. 括号生成（中等）

---

## 题目

数字 `n` 代表生成括号的对数，请你设计一个函数生成所有可能的**有效**括号组合。

```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

---

## 你的关键思路

> 1. 不再用 for 循环做选择——因为选"("还是")"不是由数组决定的，而是由当前状态决定的
> 2. 左括号可以加的条件：`left < n`
> 3. 右括号可以加的条件：`right < left`（右括号不能超过左括号，否则一定无效）
> 4. 结束条件：`container.length() == n * 2`

---

## 你的代码

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new ArrayList<>();
        backtrack(res, n, new StringBuilder(), 0, 0);
        return res;
    }

    private void backtrack(List<String> res, int n, StringBuilder container, int left, int right){
        if(container.length() == n * 2){
            res.add(container.toString());
            return;
        }
        if(left < n){
            container.append("(");
            backtrack(res, n, container, left + 1, right);
            container.deleteCharAt(container.length() - 1);
        }
        if(right < left){
            container.append(")");
            backtrack(res, n, container, left, right + 1);
            container.deleteCharAt(container.length() - 1);
        }
    }
}
```

---

## 复杂度

- 时间：O(4ⁿ / √n)，第 n 个卡特兰数
- 空间：O(n)，递归栈 + StringBuilder
