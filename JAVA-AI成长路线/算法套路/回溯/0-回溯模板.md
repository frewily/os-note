# 回溯模板

---

## 核心

回溯本质是**穷举 + 剪枝**——做选择 → 递归 → 撤销选择。适合排列、子集、组合类问题。

---

## 通用模板

```java
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        加入结果集;
        return;
    }
    
    for (选择 : 选择列表) {
        做选择（路径.add）;
        backtrack(路径, 选择列表);
        撤销选择（路径.remove）;
    }
}
```

---

## 全排列 vs 子集

**全排列**：`[1,2,3]` → `[1,2,3], [1,3,2], [2,1,3]...`（顺序重要，需要 used 数组标记已选）

**子集**：`[1,2,3]` → `[], [1], [2], [3], [1,2]...`（顺序不重要，用 startIndex 控制不走回头路）

| | 全排列 | 子集 |
|--|--------|------|
| 重复选择 | ❌ 不能重复选 | ❌ 不能重复选 |
| 顺序是否重要 | ✅ 重要 `[1,2]` ≠ `[2,1]` | ❌ 不重要 |
| 去重用 | `used[]` 标记已用的元素 | `startIndex` 控制从哪开始选 |
| 结束条件 | path.size() == nums.length | 每次进入都加入结果集 |
| 结果数 | n! | 2ⁿ |
