# 回溯模板

---

## 核心

回溯本质是**穷举 + 剪枝**——做选择 → 递归 → 撤销选择。适合排列、子集、组合、分割类问题。

---

## 通用模板

```java
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        加入结果集;
        return;
    }
    for (选择 : 选择列表) {
        做选择;
        backtrack(路径, 更新后的选择列表);
        撤销选择;
    }
}
```

## 七题速查表

| 题 | 选择来源 | 关键去重 | 结果收集 | 变体要点 |
|---|---------|---------|---------|---------|
| **46-全排列** | for 遍历数组 | `used[]` 标记已选 | 路径满才加 | 标准模板 |
| **78-子集** | for 从 start 开始 | `startIndex` 不走回头路 | 每个节点都加 | 组合基础 |
| **39-组合总和** | for 从 start 开始 | 传 `i` 不传 `i+1` | 路径满才加 | 元素可重复用 |
| **17-电话号码** | for 遍历映射串 | `index` 指向 digits | 路径满才加 | 多叉树每层分支数不同 |
| **22-括号生成** | if 判断状态 | `left`/`right` 控制 | 路径满才加 | 无输入数组 |
| **131-分割回文串** | if 判断切不切 | `cur`/`start` 双指针 | 路径满才加 | 切割模型 |
| **79-单词搜索** | 四方向移动 | board 原地标记 | 找到即返（boolean） | 树形→图形 |

## 三种变体内核

### 变体一：选择来源于状态（无输入数组）

**典型题**：[[22-括号生成]]

```java
// 标准：for (int num : nums)
// 括号：根据 left/right 状态决定选什么
if (left < n)  { add('('); backtrack(left+1, right); remove(); }
if (right < left) { add(')'); backtrack(left, right+1); remove(); }
```

### 变体二：选择来源于切割位置

**典型题**：[[131-分割回文串]]

```java
// 不切：只移动指针
dfs(cur + 1, start, ...);
// 切：检查回文，加子串，重置 start
if (isHuiWen(s, start, cur)) {
    container.add(s.substring(start, cur + 1));
    dfs(cur + 1, cur + 1, ...);  // start 跳到切点之后
    container.removeLast();
}
```

### 变体三：选择来源于棋盘/图

**典型题**：[[79-单词搜索]]

```java
// 不是 for 循环，是四方向移动
boolean res = dfs(board, r+1, c) || dfs(board, r-1, c)
            || dfs(board, r, c+1) || dfs(board, r, c-1);
// board[r][c] = '\0' 标记已走，相当于 used[]
// 回溯后复原：board[r][c] = word.charAt(count)
```

## 举一反三

识别回溯不看 for 循环，看 **三角结构**：

```
做选择 → 递归 → 撤销选择
```

不管选择来自数组、状态还是棋盘，只要满足这个三角结构，就能套回溯的思路。
