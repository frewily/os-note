# 131. 分割回文串

---

## 题目

给你一个字符串 `s`，将 `s` 分割成若干子串，使每个子串都是回文串。返回所有可能的分割方案。

```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

---

## 你的关键思路

> 把字符串想象成一根香肠，你手里有一把刀。每走到一个位置，你决定：切还是不切。切了之后那段必须是回文，然后继续处理剩下的香肠。

---

## 你的代码

```java
class Solution {
    public List<List<String>> partition(String s) {
        List<List<String>> res = new ArrayList<>();
        List<String> container = new ArrayList<>();
        dfs(0, 0, s, container, res);
        return res;
    }
    
    // 现在 s 未被分割的部分为 [start, n-1]
    // 当前位于下标 cur，讨论是否在 cur 和 cur+1 之间切一刀
    private void dfs(int cur, int start, String s, List<String> container, List<List<String>> res){
        if(cur == s.length()){
            res.add(new ArrayList<>(container));
            return;
        }
        // 分支一：不分割
        if(cur < s.length() - 1){
            dfs(cur + 1, start, s, container, res);
        }
        // 分支二：分割，但需要满足回文条件
        if(isHuiWen(s, start, cur)){
            container.add(s.substring(start, cur + 1));
            dfs(cur + 1, cur + 1, s, container, res);
            container.removeLast();
        }
    }
    private boolean isHuiWen(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left++) != s.charAt(right--)) {
                return false;
            }
        }
        return true;
    }
}
```
---

## 复杂度

- 时间：O(n × 2ⁿ)，每个切点可以切或不切，最坏 2ⁿ 种分割方案
- 空间：O(n)，递归栈 + container

---

## 你的写法 vs 常见写法

你的思路是"每步决定切不切"，常见解法是"枚举从 start 开始的第一个子串多长"：

```java
// 常见写法：一次 for 循环枚举所有可能的切割长度
private void backtrack(String s, int start, List<String> path, List<List<String>> res) {
    if (start == s.length()) {
        res.add(new ArrayList<>(path));
        return;
    }
    for (int end = start; end < s.length(); end++) {
        if (isHuiWen(s, start, end)) {
            path.add(s.substring(start, end + 1));
            backtrack(s, end + 1, path, res);
            path.removeLast();
        }
    }
}
```

两者等价，但你的"不切/切"二叉树思路更能体现回溯的"做选择/撤销"本质。
