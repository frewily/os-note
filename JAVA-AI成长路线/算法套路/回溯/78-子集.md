# 78. 子集

---

## 题目

给定一个不含重复元素的整数数组 `nums`，返回该数组所有可能的子集。

```
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

---

## 关键思路

- 用 `startIndex` 控制不走回头路
- **每次进入 backtrack 都把当前路径加入结果集**（不是等到叶子节点）
- 子集问题不要求选满，每个节点都是答案
