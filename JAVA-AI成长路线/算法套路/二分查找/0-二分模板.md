# 二分查找模板

---

## 核心

二分查找本质是**每次排除一半**——在有序（或局部有序）的数据中，通过比较中间值缩小搜索范围。

---

## 标准二分（查一个值）

```java
int binarySearch(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;  // 防溢出
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

**while (left <= right)**：`<=` 保证区间非空时循环，结束时 `left = right + 1`。

---

## 三个变体的核心区别

| 变体 | while 条件 | 收缩方向 | 返回值 |
|------|-----------|---------|--------|
| **标准**（查一个值） | `left <= right` | `left = mid + 1` / `right = mid - 1` | 找到即返 |
| **第一个位置**（左边界） | `left < right` | `right = mid`（左移） | `nums[left] == target` |
| **最后一个位置**（右边界） | `left < right` | `left = mid`（右移，mid 取右中位数） | `nums[left] == target` |

### 左边界（第一个等于 target 的位置）

```java
int leftBound(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left) / 2;  // 左中位数
        if (nums[mid] < target) left = mid + 1;
        else right = mid;  // 收缩右边界，锁定第一个
    }
    return nums[left] == target ? left : -1;
}
```

### 右边界（最后一个等于 target 的位置）

```java
int rightBound(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    while (left < right) {
        int mid = left + (right - left + 1) / 2;  // 右中位数
        if (nums[mid] > target) right = mid - 1;
        else left = mid;  // 收缩左边界，锁定最后一个
    }
    return nums[left] == target ? left : -1;
}
```

**关键区别**：
- 找左边界：`right = mid`，mid 取**左**中位数
- 找右边界：`left = mid`，mid 取**右**中位数（+1，防死循环）

## 旋转数组的二分

```java
// 判断 mid 落在左半还是右半
if (nums[mid] >= nums[left]) {         // mid 在左半
    // ...
} else {                               // mid 在右半
    // ...
}
```

旋转数组的特征：左半段全部 > 右半段。这个比较用来确定 mid 落在哪半。
