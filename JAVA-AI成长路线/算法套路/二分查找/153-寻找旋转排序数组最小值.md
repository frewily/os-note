# 153. 寻找旋转排序数组中的最小值（中等）

---

## 题目

一个升序数组在某个位置旋转了，找出最小元素。

```
输入：nums = [3,4,5,1,2]
输出：1
```

---

## 你的关键思路

> 1. 通过 `nums[0] <= nums[mid]` 判断 mid 落在左半还是右半
> 2. 左半：最小值在右半（或就是 nums[0]），left = mid + 1
> 3. 右半：最小值在左半（或就是 nums[mid]），right = mid - 1
> 4. 过程中用 min 变量记录当前遇到的最小值

---

## 你的代码

```java
class Solution {
    public int findMin(int[] nums) {
        int min = 5000;
        int left = 0, right = nums.length - 1;
        while(left <= right){
            int mid = (left + right) / 2;
            if(nums[0] <= nums[mid]){
                min = Math.min(nums[0], min);
                left = mid + 1;
            }else{
                min = Math.min(nums[mid], min);
                right = mid - 1;
            }
        }
        return min;
    }
}
```

---

## 复杂度

- 时间：O(log n)
- 空间：O(1)
