# 33. 搜索旋转排序数组（中等）

---

## 题目

一个升序数组在某个位置旋转了（如 `[4,5,6,7,0,1,2]`），搜索一个 target，存在返回索引，不存在返回 -1。

```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

---

## 你的关键思路

> 1. 每次二分后，左半段 `[0, mid]` 或右半段 `(mid, n-1]` 必然有一端是**完全有序**的
> 2. 检查 target 是否落在有序的那半：在则缩小到该区间，不在则去另一半
> 3. 判断左右半的依据：`nums[0] <= nums[mid]`（左半有序） vs `nums[0] > nums[mid]`（右半有序）

---

## 你的代码

```java
class Solution {
    public int search(int[] nums, int target) {
        int n = nums.length;
        if(n == 0){
            return -1;
        }
        if(n == 1){
            return nums[0] == target ? 0 : -1;
        }
        int l = 0, r = nums.length - 1;
        while(l <= r){
            int mid = (l + r) / 2;
            if(nums[mid] == target){
                return mid;
            }
            // 左半部分（0 -> mid）有序
            if(nums[0] <= nums[mid]){
                // 如果 target 落在这个区间内（nums[0] ≤ target < nums[mid]），说明目标在左边 → r = mid - 1
                if(nums[0] <= target && target < nums[mid]){
                    r = mid - 1;
                }else{
                    // 否则，目标一定在右半段 → l = mid + 1
                    l = mid + 1;
                }
            }
            // 右半部分（mid -> n - 1）有序
            if(nums[0] > nums[mid]){
                if(nums[mid] < target && target <= nums[n - 1]){
                    l = mid + 1;
                }else{
                    r = mid - 1;
                }
            }
        }
        return -1;
    }
}
```

---

## 复杂度

- 时间：O(log n)
- 空间：O(1)
