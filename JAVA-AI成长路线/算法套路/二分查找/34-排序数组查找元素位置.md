# 34. 在排序数组中查找元素的第一个和最后一个位置

---

## 题目

给你一个升序数组 `nums` 和一个 `target`，找出 `target` 在数组中的开始和结束位置。不存在返回 `[-1, -1]`。

```
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

---

## 你的关键思路

> 1. 找左边界：`nums[mid] >= target` 时收缩右边界，最终 left 指向第一个 target
> 2. 找右边界：`nums[mid] <= target` 时收缩左边界，最终 right 指向最后一个 target
> 3. 最后检查 left / right 是否越界且值等于 target

---

## 你的代码

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        if (nums == null || nums.length == 0) {
            return new int[]{-1, -1};
        }
        int left = 0, right = nums.length - 1;
        int start = findL(nums, target, left, right);
        int end = findR(nums, target, left, right);
        return new int[]{start, end};
    }
    private int findL(int[] nums, int target, int left, int right){
        while(left <= right){
            int mid = (left + right) / 2;
            if(nums[mid] < target){
                left = mid + 1;
            }else if(nums[mid] >= target){
                right  = mid - 1;
            }
        }
        if (left < nums.length && nums[left] == target) {
            return left;
        }
        return -1;
    }
    private int findR(int[] nums, int target, int left, int right){
        while(left <= right){
            int mid = (left + right) / 2;
            if(nums[mid] <= target){
                left = mid + 1;
            }else if(nums[mid] > target){
                right  = mid - 1;
            }
        }
        if (right >= 0 && nums[right] == target) {
            return right;
        }
        return -1;
    }
}
```

---

## 复杂度

- 时间：O(log n)
- 空间：O(1)
