# 4. 寻找两个正序数组的中位数

---

## 题目

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的中位数。算法的时间复杂度应该为 **O(log(m+n))**。

```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
（合并后 = [1,2,3]，中位数是 2）

输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
（合并后 = [1,2,3,4]，中位数是 (2+3)/2）
```

---

## 你的关键思路

> 参考视频：[灵茶山艾府 - 寻找两个正序数组的中位数（B站）](https://www.bilibili.com/video/BV162PVzPECg/)

> 1. **保证在短数组上二分**：先交换使 m ≤ n，二分只在 a 上做，复杂度 O(log min(m,n))
> 2. **切割思想**：把两个数组各切一刀，左半总共 (m+n+1)/2 个元素。**注意这里的 i、j 是下标不是个数**：a[0..i] 和 b[0..j] 是左半，所以 (i+1)+(j+1) = (m+n+1)/2，即 j = (m+n+1)/2 - i - 2
> 3. **合法切割条件**：max(左) ≤ min(右)，即 a[i] ≤ b[j+1] 且 b[j] ≤ a[i+1]
> 4. **巧妙的简化**：只二分"a[i] ≤ b[j+1]"这个条件，找**最大的合法 i**。因为 i+1 不合法 ⇒ a[i+1] > b[j+1']（j' = f(i+1) = j-1）⇒ a[i+1] > b[j]，另一个条件自动满足——所以只需一个判断
> 5. **开区间二分**：left=-1（一定合法），right=m（一定不合法），`while(left+1 < right)`，最后 left 就是答案
> 6. 边界用 Integer.MIN_VALUE/MAX_VALUE 处理：i 或 j 为 -1（该数组左半为空）、i+1 或 j+1 越界（该数组右半为空）
> 7. 奇数返回 max(左半最大值)，偶数返回 (max(左) + min(右)) / 2

## 你的代码

```java
// 暴力解法（目前就只用暴力解法了，二分解法等有大厂梦再回来实现吧）
class Solution {
    public double findMedianSortedArrays(int[] a, int[] b) {
        int m = a.length;
        int n = b.length;
        int[] merged = new int[m + n];
        System.arraycopy(a, 0, merged, 0, m);
        System.arraycopy(b, 0, merged, m, n);
        Arrays.sort(merged);

        int s = m + n;
        int k = (s - 1) / 2;
        return s % 2 > 0 ? merged[k] : (merged[k] + merged[k + 1]) / 2.0;
    }
}
```

```java
// 二分查找
class Solution {
    public double findMedianSortedArrays(int[] a, int[] b) {
        // Java 里可以随意交换引用变量（包括数组引用）
        if (a.length > b.length) {
            // 交换 a 和 b, 确保 a 始终是较小的那个
            int[] tmp = a;
            a = b;
            b = tmp;
        }

        int m = a.length;
        int n = b.length;
        // 循环不变量：a[left] <= b[j+1]
        // 循环不变量：a[right] > b[j+1]
        int left = -1;
        int right = m;
        while (left + 1 < right) { // 开区间 (left, right) 不为空
            int i = left + (right - left) / 2;
            int j = (m + n + 1) / 2 - i - 2;
            if (a[i] <= b[j + 1]) {
                left = i; // 缩小二分区间为 (i, right)
            } else {
                right = i; // 缩小二分区间为 (left, i)
            }
        }

        // 此时 left 等于 right-1
        // a[left] <= b[j+1] 且 a[right] > b[(j-1)+1] = b[j]，所以答案是 i=left
        int i = left;
        int j = (m + n + 1) / 2 - i - 2;
        int ai = i >= 0 ? a[i] : Integer.MIN_VALUE;
        int bj = j >= 0 ? b[j] : Integer.MIN_VALUE;
        int ai1 = i + 1 < m ? a[i + 1] : Integer.MAX_VALUE;
        int bj1 = j + 1 < n ? b[j + 1] : Integer.MAX_VALUE;
        int max1 = Math.max(ai, bj);
        int min2 = Math.min(ai1, bj1);
        return (m + n) % 2 > 0 ? max1 : (max1 + min2) / 2.0;
    }
}
```

## 复杂度

- 时间：O(log min(m,n))，在短数组上二分
- 空间：O(1)
