# 算法练习流程

---

## 目标

LeetCode Hot100 按题型分类刷，重点在**识别模式 → 套模板 → 调细节**。

---

## 协作方式

```
① 我建题目模板（题目描述 + 复杂度空位）
② 你写关键思路，贴你的代码
③ 我来评估，给出反馈
④ 确认无误后，我再完善补充
```

## 笔记规范

- 每个题型建一个文件夹，内含 `0-模板.md` + 具体题目
- 模板笔记总结该类题型的通用解法
- 题目笔记用编号命名，如 `46-全排列.md`
- **是否发布由自己决定**：想发布某篇时，手动在文件顶部加 YAML frontmatter：

```yaml
---
publish: true
---
```

（我创建的模板**默认不带** frontmatter，发布标记由自己控制）

## 算法标签

- **每道题收尾时，按实际用到的技术打标签**（不套固定模板）
- 标签放在 frontmatter 的 `tags` 字段：

```yaml
---
tags:
  - 前缀积
  - 数组
---
```

- 标签要反映**解法特征**而非题型名称：比如 238 用了前缀积思想，就标 `前缀积`，只标 `数组` 会漏掉关键信息
- 一道题可以多个标签（解法 + 数据结构 + 关键技巧）
- 标签统一用**名词短语**，便于 Obsidian 搜索聚合
