# 142. 环形链表 II（中等）（二刷）

---

## 题目

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

```
输入：head = [3,2,0,-4]，pos = 1（尾节点连接到索引 1 的位置）
输出：返回索引为 1 的链表节点

输入：head = [1,2]，pos = -1（无环）
输出：返回 null
```

---

## 你的关键思路

> 你跑的慢没关系，我们终究会相遇，相遇之后我会从起点开始重新追你。

> 题解：[环形链表 II（双指针，清晰图解）](https://leetcode.cn/problems/linked-list-cycle-ii/solutions/12616/linked-list-cycle-ii-kuai-man-zhi-zhen-shuang-zhi-)

> **补充（Floyd 判圈的数学原理）**：
> 1. **阶段一（判圈）**：slow 走 1 步、fast 走 2 步，有环必相遇
> 2. **阶段二（找入口）**：相遇后，一个指针回起点、slow 留原地，都走 1 步 → 相遇点就是环入口
> 3. **为什么成立**：设 起点→入口 距离 a，入口→相遇点 距离 b，环长 L。相遇时 slow 走了 a+b，fast 走了 a+b+nL。fast = 2×slow → a+b+nL = 2(a+b) → **a = nL - b**——从起点走 a 步 = 从相遇点绕环走是同一个位置。这就是"我从起点开始追你，正好在入口等到你"的数学证明
> 4. 和 287-寻找重复数同款算法：数组下标当节点、数组值当 next 指针，环入口即重复数

## 你的代码

```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        if(head == null || head.next == null){
            return null;
        }
        ListNode slow = head, fast = head;
        while(true){
            fast = fast.next.next;
            slow = slow.next;
            if(fast == null || fast.next == null){
                return null;
            }else if(fast == slow){
                break;
            }
        }
        fast = head;
        while(fast != slow){
            fast = fast.next;
            slow = slow.next;
        }
        return fast;
    }
}
```

## 复杂度

- 时间：O(n)，两阶段各 O(n)
- 空间：O(1)
