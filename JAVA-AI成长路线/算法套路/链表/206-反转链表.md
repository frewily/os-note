# 206. 反转链表

---

## 题目

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]

输入：head = []
输出：[]
```

---

## 你的关键思路

> 反转链表，用双指针，实际操作中要用三个变量，两个指针改变链表指向，一个临时变量存储后边节点的位置

> **补充**：
> 1. **迭代版三件套**：pre（已反转部分的头）/ cur（当前节点）/ nxt（暂存后继）——记住"先存后改再移动"的顺序
> 2. `pre` 必须从 `null` 开始——这就是 25 题里踩过的坑（从 head 开始会让尾节点指向自己形成环）
> 3. **递归版**（另一种写法）：`head.next.next = head; head.next = null`，递归到最后一个节点返回作为新头
> 4. 这题是 25-K个一组翻转的"单体版"——25 题就是把这题按 k 个一组调用

---

## 你的代码

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode pre = null;
        ListNode cur = head;
        while(cur != null){
            ListNode nxt = cur.next;
            cur.next = pre;
            pre = cur;
            cur = nxt;
        }
        return pre;
    }
}
```

---

## 复杂度

- 时间：O(n)
- 空间：O(1)（迭代版；递归版为 O(n) 栈空间）
