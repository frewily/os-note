# 25. K 个一组翻转链表

---

## 题目

给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]

输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

---

## 你的关键思路

> 关键是处理好如果分组以及分完组之后如何拼回去

---

## 你的代码

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        // 哨兵节点（dummy），目的是让头节点也像中间节点一样统一处理，避免特殊判断
        ListNode dummy = new ListNode(0, head);
        // 创建一前一后两个指针,用来截取每一个k长度的链表进行分次反转
        // pre:当前待翻转组的前驱节点（翻转后，新头会接在 pre.next）
        // end:当前待翻转组的尾节点（走 k 步到达）
        ListNode pre = dummy, end = dummy;
        while(end.next != null){
            // 分组，k为一组，且要满足剩余节点有 k 个
            for(int i = 0; i < k && end != null; i++){
                end = end.next;
            }
            if(end == null) break;
            // 翻转链表的头节点
            ListNode start = pre.next;
            // 翻转前先保存后继节点，然后断开end后面的节点开始翻转
            ListNode next = end.next;
            end.next = null;
            pre.next = reverse(start);
            // 翻转完成后重新拼接链表，注意此时链表尾部为start
            start.next = next;
            // 记录下一组开始的前驱节点
            pre = start;
            // 翻转完后，end指针指向了链表头部，也要更新
            end = start;
        }
        return dummy.next;
    }
    private ListNode reverse(ListNode head){
        // ⚠️ pre 必须从 null 开始！从 head 开始会让尾节点指向自己形成环
        // 主函数里 start.next = next 恰好修复了这个环，但 reverse 单独用会死循环
        ListNode pre = null;
        ListNode curr = head;
        while(curr != null){
            ListNode next = curr.next;
            curr.next = pre;
            pre = curr;
            curr = next;
        }
        return pre;
    }
}
```
---

## 复杂度

- 时间：O(n)，每个节点被访问常数次
- 空间：O(1)，迭代翻转无递归
