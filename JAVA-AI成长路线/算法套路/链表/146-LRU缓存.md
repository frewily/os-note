# 146. LRU 缓存

---

## 题目

请你设计并实现一个满足 **LRU（最近最少使用）缓存**约束的数据结构。实现 `LRUCache` 类：
- `LRUCache(int capacity)`：以正整数作为容量初始化
- `int get(int key)`：如果存在则返回，否则返回 -1
- `void put(int key, int value)`：如果 key 存在则变更其值；如果不存在则插入。如果插入导致超出容量，则**逐出最久未使用**的关键字

要求 `get` 和 `put` 都以 O(1) 平均时间复杂度运行。

```
输入：
["LRUCache","put","put","get","put","get","put","get","get","get"]
[[2],[1,1],[2,2],[1],[3,3],[2],[4,4],[1],[3],[4]]

输出：[null,null,null,1,null,-1,null,-1,3,4]
```

---

## 你的关键思路

> ① HashMap + 双向链表：一个负责查找，一个负责排序
> ② 每次访问某节点：remove + pushFront → 变成最近使用
> ③ 容量满删除: dummy.prev → 淘汰最久未使用节点

---

## 你的代码

```java
// 库函数
class LRUCache {

    private final int capacity;
    private final Map<Integer, Integer> cache = new LinkedHashMap<>();

    public LRUCache(int capacity) {
        this.capacity = capacity;
    }
    
    public int get(int key) {
        Integer value = cache.remove(key);
        if(value != null){
            cache.put(key, value);
            return value;
        }
        return -1;
    }
    
    public void put(int key, int value) {
        if(cache.remove(key) != null){
            cache.put(key, value);
            return;
        }
        if(cache.size() == capacity){
            Integer k = cache.keySet().iterator().next();
            cache.remove(k);
        }
        cache.put(key, value);
        return;
    }
}
```

```java
// 手搓双向链表
class LRUCache {

    class Node{
        int key, value;  // 为什么 node 中还要记录 key？hashmap 根据 key 删除元素
        Node prev, next;

        Node(int k, int v){
            key = k;
            value = v;
        }
    }

    private final int capacity;
    private final Node dummy = new Node(0, 0);  // 别忘了哨兵节点
    private final Map<Integer, Node> map = new HashMap<>();

    public LRUCache(int capacity) {
        this.capacity = capacity;
        dummy.prev = dummy;  // 哨兵节点的 prev 和 next要初始化
        dummy.next = dummy;
    }
    
    public int get(int key) {
        Node node = getNode(key);
        if(node != null){
            return node.value;
        }
        return -1;
    }
    
    public void put(int key, int value) {
        Node node = getNode(key);
        if(node != null){
            node.value = value;
            return;
        }
        node = new Node(key, value);
        if(map.size() == capacity){
            map.remove(dummy.prev.key);
            remove(dummy.prev);
        }
        map.put(key, node);
        pushFront(node);
    }

    // 获取 key 对应的节点，同时把该节点移动到链表头部
    private Node getNode(int key){
        if(map.containsKey(key)){
            Node node = map.get(key);
            remove(node);
            pushFront(node);
            return node;
        }
        return null;
    }

    // 删除一个节点，注意只删除链表元素本身，hashmap 中的删除自主处理，不要混在一起了
    private void remove(Node x){
        x.prev.next = x.next;
        x.next.prev = x.prev;
    }

    // 在链表头部添加一个节点
    private void pushFront(Node x){
        x.next = dummy.next;
        x.prev = dummy;
        dummy.next.prev = x;
        dummy.next = x;
    }
}
```
