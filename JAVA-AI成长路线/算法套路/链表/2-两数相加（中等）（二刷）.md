# 2. 两数相加（中等）（二刷）

---

## 题目

给你两个**非空**的链表，表示两个非负的整数。它们每位数字都是按照**逆序**的方式存储的，并且每个节点只能存储**一位**数字。请你将两个数相加，并以相同形式返回一个表示和的链表。可以假设除了数字 0 之外，这两个数都不会以 0 开头。

```
输入：l1 = [2,4,3], l2 = [5,6,4]
输出：[7,0,8]
（342 + 465 = 807，逆序存储：2→4→3 和 5→6→4）

输入：l1 = [9,9,9,9,9,9,9], l2 = [9,9,9,9]
输出：[8,9,9,9,0,0,0,1]
```

---

## 你的关键思路

> **核心**：模拟竖式加法——双指针逐位相加，carry 进位传递
> 1. 循环条件要带上 `carry != 0`（处理最高位进位的"多一位"，如 999+1）
> 2. 链表不等长时短的"视作 0"（用 if 判空跳过即可，不需要真的补 0）
> 3. dummy 头 + `cur = cur.next = new ListNode(...)` 一行连接并移动

> **两种解法对比**：
>
> | | 迭代法 | 递归法 |
> |--|--------|--------|
> | carry 角色 | 循环内局部变量（自底向上传递） | 方法参数（自顶向下传递） |
> | 结构 | dummy + while | 终止条件 + 递归调用 |
> | 空间 | O(1)（除结果链表） | O(max(m,n)) 递归栈 |
> | 可读性 | 直观贴近"竖式"心智 | 代码更短，但要看懂参数传递 |
> | 面试推荐 | ✅ 稳（无栈溢出风险） | 加分项（展示递归思维） |
>
> - 和 21-合并两个有序链表的选择一致：**面试优先迭代**，递归作为思路补充
> - 递推关系：`当前位 = (l1 + l2 + carry) % 10`，`下一位的 carry = 总和 / 10`

## 你的代码

```java
// 迭代法
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode();
        ListNode cur = dummy;
        int carry = 0;
        while(l1 != null || l2 != null || carry != 0){
            int sum = carry;
            if(l1 != null){
                sum += l1.val;
                l1 = l1.next;
            }
            if(l2 != null){
                sum += l2.val;
                l2 = l2.next;
            }
            cur = cur.next = new ListNode(sum % 10);
            carry = sum / 10;
        }
        return dummy.next;
    }
}
```

```java
class Solution {
// 递归写法
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        return addTwo(l1, l2, 0);
    }
    private ListNode addTwo(ListNode l1, ListNode l2, int carry){
        if(l1 == null && l2 == null && carry == 0){
            return null;
        }
        if(l1 != null){
            carry += l1.val;
            l1 = l1.next;
        }
        if(l2 != null){
            carry += l2.val;
            l2 = l2.next;
        }
        return new ListNode(carry % 10, addTwo(l1, l2, carry / 10));
    }
}
```

## 复杂度

- 时间：O(max(m, n))，两条链表各走一遍
- 空间：O(1)（迭代，除结果）/ O(max(m,n))（递归栈）
