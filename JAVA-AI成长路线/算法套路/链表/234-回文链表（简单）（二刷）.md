# 234. 回文链表（简单）（二刷）

---

## 题目

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

```
输入：head = [1,2,2,1]
输出：true

输入：head = [1,2]
输出：false
```

---

## 你的关键思路

> 1.找到链表中间节点；（快慢指针，一个一次走一步，一个一次走两步）
> 2.将中间节点后边的反转；（反转链表，双指针，pre 和 cur;
> 3.两个链表同时遍历，有不同的值直接返回 false；

---

## 你的代码

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        if(head == null || head.next == null) return true;
        ListNode mid = findMid(head);
        ListNode rvs= reverse(mid);
        while(rvs != null){
            if(head.val != rvs.val){
                return false;
            }
            head = head.next;
            rvs = rvs.next;
        }
        return true;
    }
    private ListNode findMid(ListNode head){
        ListNode slow = head, fast = head;
        while(fast != null && fast.next != null){
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
    private ListNode reverse(ListNode head){
        ListNode pre = null, cur = head;
        while(cur != null){
            ListNode nxt = cur.next;
            cur.next = pre;
            pre = cur;
            cur = nxt;
        }
        return pre;
    }
}
```

---

## 复杂度

- 时间：O(n)，找中点 + 反转 + 比较各一遍
- 空间：O(1)，原地操作
