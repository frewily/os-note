# 19. 删除链表的倒数第 N 个节点

---

## 题目

给你一个链表，删除链表的倒数第 `n` 个节点，并且返回链表的头节点。

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]

输入：head = [1], n = 1
输出：[]
```

---

## 你的关键思路

> 解法一：最容易想到的思路，直接找到目标节点所在的位置，然后改变前置节点和后置节点的指向就可以；但需要注意的是如果是删除的是头节点，会出现问题，比如最后的返回值就是头节点，结果头节点删了，或者链表中只有头节点一个元素，删了直接变成 null。所以在链表中常用到虚拟头节点dummy，dummy 指向头节点，能避免很多边界问题

> 解法二：快慢指针+一次遍历循环，关键就是让 fast 先比 slow 多走 n 步，这样它们之间始终保持固定距离。等 fast 走到链表末尾时，slow 就刚好停在“待删除节点的前一个节点”。

---

## 你的代码

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        int count = 1;
        ListNode pre = new ListNode();
        pre.next = head;
        ListNode cur = pre;
        while(cur.next != null){
            cur = cur.next;
            count++;
        }
        int target = count - n + 1;
        cur = pre;
        count = 1;
        while(cur != null){
            if(count < target - 1){
                cur = cur.next;
                count++;
            }else{
                cur.next = cur.next.next;
                return pre.next;
            }
        }
        return pre.next;
    }
}
```

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);
        ListNode fast = dummy, slow = dummy;
        for(int i = 0; i < n; i++){
            fast = fast.next;
        }
        // fast 走到最后一个节点时
        // slow 正好位于待删除节点的前一个节点
        while(fast.next != null){
            fast = fast.next;
            slow = slow.next;
        }
        slow.next = slow.next.next;
        return dummy.next;
    }
}
```

---

## 复杂度

- 解法一（数长度）：时间 O(n) 两遍遍历，空间 O(1)
- 解法二（快慢指针）：时间 O(n) 一遍遍历，空间 O(1)
