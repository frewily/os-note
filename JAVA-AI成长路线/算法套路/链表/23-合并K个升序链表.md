# 23. 合并 K 个升序链表

---

## 题目

给你一个链表数组，每个链表都已经按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。

```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]

输入：lists = []
输出：[]
```

---

## 你的关键思路

> 1. **最小堆维护 k 个候选头**：堆里永远存着每条链表当前最小（未取）的节点
> 2. 每次 poll 出全局最小节点，把它 next 补进堆——保证了"堆顶永远是下一个最小"
> 3. dummy 哨兵：不用单独处理"新链表还是空的"这个特殊情况
> 4. 为什么不用逐个两两合并：两两合并 O(N×k)，堆优化后 O(N log k)
> 5. 思考路径：k 个有序序列找全局最小 → "取 k 个里最小"重复 N 次 → 最小堆天然适合

---

## 你的代码

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        // 构建最小堆
        PriorityQueue<ListNode> pq = new PriorityQueue<>((a, b) -> a.val - b.val);
        for(ListNode head : lists){
            if(head != null) pq.offer(head);
        }
        ListNode dummy = new ListNode();  // 新链表的哨兵节点
        ListNode cur = dummy;  // 指针
        while(!pq.isEmpty()){
            ListNode node = pq.poll();  // 取出当前最小值的节点
            if(node.next != null) pq.offer(node.next);  // 要往堆中补充后续节点
            // 拼接节点
            cur.next = node;
            cur = node;
        }
        return dummy.next;
    }
}
```

---

## 复杂度

- 时间：O(N log k)，N = 总节点数，k = 链表条数，每次堆操作 O(log k)
- 空间：O(k)，堆最多存 k 个节点
