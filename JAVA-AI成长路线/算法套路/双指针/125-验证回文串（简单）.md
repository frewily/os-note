# 125. 验证回文串（简单）

---

## 题目

如果在将所有大写字符转换为小写字符、并移除所有非字母数字字符之后，短语正着读和反着读都一样，则可以认为该短语是一个回文串。给你一个字符串 `s`，如果是回文串返回 `true`，否则返回 `false`。

```
输入：s = "A man, a plan, a canal: Panama"
输出：true
（"amanaplanacanalpanama" 是回文串）

输入：s = "race a car"
输出：false
```

---

## 你的关键思路

> 1. **双指针从两端向中间收缩**：left/right 指向待比较的字符
> 2. 跳过非字母数字：`Character.isLetterOrDigit()`，跳过时指针继续移动
> 3. 统一转小写后比较，不等直接返回 false
> 4. 三种解法对比：
>    - 双指针原地：O(1) 空间，最优
>    - StringBuilder 预处理：先过滤再比较，代码更直观但多 O(n) 空间
>    - 正则：写法最简洁但性能差，仅了解
> 5. 双指针的回文模板：`while (left < right) { 比较; left++; right--; }`

---

## 你的代码

```java
// 最优解
class Solution {
    public boolean isPalindrome(String s) {
        int left = 0, right = s.length() - 1;
        
        while (left < right) {
            // 跳过非字母数字字符
            while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
                left++;
            }
            while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
                right--;
            }
            // 比较（统一转小写）
            if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

```java
// StringBuilder预处理
class Solution {
    public boolean isPalindrome(String s) {
        StringBuilder sb = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isLetterOrDigit(c)) {
                sb.append(Character.toLowerCase(c));
            }
        }
        String res = sb.toString();
        int left = 0, right = res.length() - 1;
        while (left < right) {
            if (res.charAt(left++) != res.charAt(right--)) {
                return false;
            }
        }
        return true;
    }
}
```

```java
// 正则表达式处理，性能较差，仅作了解
class Solution {
    public boolean isPalindrome(String s) {
        String res = s
            .replaceAll("[\\p{Punct}\\s]", "")  // 正则表达式，去除所有的标点符号和空格
            .toLowerCase();  // 转换成小写
        int left = 0, right = res.length() - 1;
        while(left < right){
            if(res.charAt(left) != res.charAt(right)){
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
}
```

---

## 复杂度

- 双指针原地：时间 O(n)，空间 O(1)
- StringBuilder 预处理：时间 O(n)，空间 O(n)
- 正则：时间 O(n)，空间 O(n)（且正则本身开销大）
