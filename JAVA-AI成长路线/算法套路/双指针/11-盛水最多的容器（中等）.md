# 11. 盛水最多的容器（中等）

---

## 题目

给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。找出其中的两条线，使得它们与 `x` 轴共同构成的容器可以容纳最多的水。返回容器可以储存的最大水量。

```
输入：[1,8,6,2,5,4,8,3,7]
输出：49
（垂线 1 和垂线 8 之间的容器：min(8,7) × 7 = 49）
```

---

## 你的关键思路

> 1. **双指针从两端向中间收缩**：left/right 指向两根线
> 2. **容量公式**：`(right - left) × min(height[left], height[right])`——短板决定高度
> 3. **贪心移动**：每次移动较短的那一边——因为短边是瓶颈，移动长边宽度变小容量不可能变大，只有移动短边才有机会遇到更高的线
> 4. 为什么正确：移动短边不会漏掉更优解（反证：若最优解在中间某对，短边被移动前一定能到达它）
> 5. 和 42-接雨水的区别：接雨水是"每个位置存多少水"（需要前后缀最值），这题是"选两根线"（双指针贪心）

---

## 你的代码

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0, right = height.length - 1;
        int max = (right - left) * Math.min(height[left], height[right]);
        while(left != right){
            if(height[left] < height[right]){
                left++;
            }else{
                right--;
            }
            max = Math.max((right - left) * Math.min(height[left], height[right]), max);
        }
        return max;
    }
}
```

---

## 复杂度

- 时间：O(n)，单遍扫描
- 空间：O(1)
