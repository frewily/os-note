# 15. 三数之和（中等）

---

## 题目

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且**不重复**的三元组。答案中不可以包含重复的三元组。

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]

输入：nums = [0,1,1]
输出：[]

输入：nums = [0,0,0]
输出：[[0,0,0]]
```

---

## 你的关键思路

> 关键是先拿出一个数，剩下两个数就采用两数之和同样的思路进行求解。采用双指针。要注意如何去重以及进行剪枝来优化运行效率。

>二刷：注意去重判断二的写法以及写的位置，再者就是两个剪枝优化，二刷的时候忘记写了

---

## 你的代码

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> ans = new ArrayList<>();
        int n = nums.length;
        for(int i = 0; i < n - 2; i++){
            int head = nums[i];
            if(i > 0 && head == nums[i - 1]) continue; // 去重判断1
            if(head + nums[i + 1] + nums[i + 2] > 0) break;  // 剪枝1
            if(head + nums[n - 2] + nums[n - 1] < 0) continue;  // 剪枝2
            int left = i + 1, right = n - 1;
            while(left < right){
                int sum = head + nums[left] + nums[right];
                if(sum > 0) right--;
                else if(sum < 0) left++;
                else{
                    if(left == i + 1 || nums[left] != nums[left - 1]){  
                        // 去重判断2：left==i+1说明还没有移动指针
                        // 而找到ans后left和right指针都会动
                        // 因此这里只需要判断nums[left]!=nums[left - 1]即可
                        ans.add(List.of(head, nums[left], nums[right]));
                    }
                    left++;
                    right--;
                }
            }
        }
        return ans;
    }
}
```

---

## 复杂度

- 时间：O(n²)，外层遍历 + 内层双指针
- 空间：O(1)（不含排序空间，排序 O(log n)）
