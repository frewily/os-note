# MySQL 知识点 — 编写规则

> 定位：AI 辅助开发（vibe coding）视角下的 MySQL 核心知识梳理。
> 不是面试八股，不是 DBA 手册，是后端开发中必须理解的数据库原理。

---

## 面向读者

已具备 MySQL 基础 CRUD 能力，需要深入理解索引、事务、锁等核心机制。

---

## 筛选标准

### ✅ 收录

- 写 SQL / 看 AI 生成的 SQL 时需要知道的知识
- 判断查询性能问题时需要理解的概念
- 项目中 @Transactional / 锁 / 索引优化涉及的核心原理

### ❌ 不收录

- MySQL 安装配置、主从搭建等运维操作
- 特定版本的行为差异细节
- 纯 DBA 导向的调优参数
