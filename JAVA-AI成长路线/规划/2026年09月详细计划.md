## 1. 本月核心成果

9 月剩余时间只追求以下五项成果：

1. JVM、OS、计网和 Java 八股正式运行 D+1、D+3、D+7、D+14 复习机制，并完成月底第一次检查。
2. MySQL 完成事务、隔离级别、MVCC、快照读/当前读和锁的第一轮串联；随后完成 Redis 数据结构、持久化、过期删除和内存淘汰的第一轮学习。
3. JVM 不急于增加大量新名词，重点修复运行时数据区、对象创建、类加载、GC 和 OOM 排查的遗忘问题。
4. OS 完成第三讲的真实学习与验收，并根据实际理解情况进入下一逻辑单元；计网补齐 TCP 可靠传输、TIME_WAIT 和拥塞控制第一轮框架。
5. 算法保持连续性，记录陌生中等题独立完成表现；完成一次 40 分钟限时训练。项目只完成一次 AI 优化阶段立项，不要求本月开始大规模重构。

## 2. 本月必做、选做与暂不做

### 必做

- 每天先处理当天到期复习，再学习新内容。
- 完成 MySQL D11、Redis D12～D13 和一次 MySQL + Redis 综合复习。
- 完成 JVM D5～D6 的重点补强，至少两次不看笔记复述。
- 完成 OS 第三讲学习、自测和复述；至少再安排一次 OS 新内容或逻辑单元。
- 完成 TCP 可靠传输、TIME_WAIT、拥塞控制，并各完成一次延迟复习。
- 算法完成 8～10 道新题、6～8 道复习题和 1 次限时训练；以实际数量记录，不为凑数看题解。
- 9 月 30 日完成月末验收和 10 月计划输入清单。

### 选做

- 用 Wireshark 或现有抓包记录验证一次 TCP 标志位、序列号和确认号。
- 完成 OS 第四讲或下一完整逻辑单元；如果第三讲仍不稳，则改为复习第三讲。
- 项目 AI 优化阶段在范围评审后提前进入实现，但不作为本月验收条件。

### 暂不做

- 不继续执行旧版 D11～D28 项目冲刺。
- 不同时优化 Agent 项目和黑马点评。
- 不制作正式简历，不集中投递。
- 不提前深挖 JVM 调优参数、复杂 GC 收集器细节、Redis Cluster、Kafka 或微服务全家桶。
- 不把现有 OS 第三讲笔记直接算作已掌握，必须经过课程学习、复述和自测。

## 3. 日常执行模板

### 课程密集日，约 2 至 3 小时

1. 到期复习：20～30 分钟。
2. 当日主线：60～90 分钟，只学一个新主题。
3. 算法：45～60 分钟，1 道新题或 1 道复习题。
4. 记录：10 分钟，标注掌握状态和下次复习日期。

### 空闲日，约 4 至 6 小时

1. 到期复习：30～40 分钟。
2. 主线新内容：60～90 分钟。
3. 第二学习块：60～90 分钟，用于 JVM/OS/计网补强或综合练习。
4. 算法：90～120 分钟，原则上 2 道新题加 1 道复习题。
5. 项目或周复盘：60～90 分钟，仅在计划日安排。

当天时间不足时，优先保留到期复习和算法复做；减少新题和选做，不把未完成的新内容全部堆到第二天。
