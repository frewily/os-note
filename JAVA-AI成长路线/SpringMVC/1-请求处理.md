# 请求处理

---

## 核心

SpringMVC 把 HTTP 请求中的各种信息（路径参数、查询参数、请求体、请求头）绑定到 Java 方法的参数上。

---

## @PathVariable——路径参数

````java
// URL: GET /users/123
@GetMapping("/users/{id}")
public Result<User> getUser(@PathVariable Long id) {
    // id = 123
}

// URL: GET /users/123/orders/456
@GetMapping("/users/{userId}/orders/{orderId}")
public Result<Order> getOrder(
        @PathVariable Long userId,
        @PathVariable Long orderId) {
    // userId = 123, orderId = 456
}
````

**vibe coding 视角**：AI 经常在 RESTful 路径中使用 `@PathVariable`，需要把路径变量名和方法参数名保持一致，不一致时需要显式指定 `@PathVariable("name")`。

---

## @RequestParam——查询参数

```java
// URL: GET /users?page=1&size=20
@GetMapping("/users")
public Result<Page<User>> listUsers(
        @RequestParam(defaultValue = "1") int page,
        @RequestParam(defaultValue = "20") int size) {
    // page = 1, size = 20
}

// required = false：参数可选
@GetMapping("/users")
public Result<Page<User>> listUsers(
        @RequestParam(required = false) String keyword,
        @RequestParam(defaultValue = "1") int page) {
    // keyword 可能为 null
}
```

**vibe coding 视角**：AI 在 `@GetMapping` 中经常忘记设 `defaultValue` 或 `required`。分页参数一定要给默认值，否则请求不带参数就报 400。

---

## @RequestBody——请求体 JSON

```java
// POST /orders
// Body: {"userId": 1, "amount": 99.9}
@PostMapping("/orders")
public Result<Order> createOrder(@RequestBody @Valid OrderDTO dto) {
    // Spring 自动把 JSON 转为 OrderDTO 对象
}
```

### 参数校验

```java
public class OrderDTO {
    
    @NotNull(message = "用户ID不能为空")
    private Long userId;
    
    @NotNull(message = "金额不能为空")
    @DecimalMin(value = "0.01", message = "金额必须大于0")
    private BigDecimal amount;
    
    @NotBlank(message = "商品名称不能为空")
    private String productName;
    // getter/setter
}
```

配合 `@Valid` 注解，校验不通过时会抛出 `MethodArgumentNotValidException`，由全局异常处理器返回统一错误提示。

**vibe coding 视角**：`@Valid` 是参数校验的关键，AI 生成的 DTO 类经常缺少校验注解。生产环境必须加，否则不合法的数据会直接穿透到 Service 层。

---

## 常见参数绑定场景

| 注解 | 绑定来源 | 例子 |
|------|---------|------|
| `@PathVariable` | URL 路径 | `/users/{id}` |
| `@RequestParam` | 查询参数 | `?page=1&size=20` |
| `@RequestBody` | 请求体 JSON | POST 提交的数据 |
| `@RequestHeader` | 请求头 | `Authorization: Bearer xxx` |
| `@ModelAttribute` | 表单数据 | 表单提交（较少用了） |

**vibe coding 视角**：AI 在参数绑定上经常用错注解——比如 `@PathVariable` 和 `@RequestParam` 混淆。看到代码里路径中有 `{}` 就应该用 `@PathVariable`，`?` 后面的参数用 `@RequestParam`。
