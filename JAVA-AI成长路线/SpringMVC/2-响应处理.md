# 响应处理

---

## 核心

SpringMVC 把 Controller 方法的返回值转为 HTTP 响应——通常是 JSON，同时携带状态码和响应头。

---

## @ResponseBody 与 @RestController

```java
// @RestController = @Controller + @ResponseBody
// 所有方法的返回值自动转为 JSON 写入响应体

@RestController
public class UserController {
    
    @GetMapping("/users/{id}")
    public User getUser(@PathVariable Long id) {
        // 返回 User 对象 → Spring 自动转 JSON → 写入响应体
        return userService.findById(id);
    }
}
```

如果不加 `@ResponseBody`，SpringMVC 会认为你想返回一个视图页面（JSP/模板）——这在你前后端分离的项目中不适用。

---

## ResponseEntity——完全控制响应

需要手动控制**状态码**、**响应头**、**响应体**时用 `ResponseEntity`：

```java
@GetMapping("/users/{id}")
public ResponseEntity<User> getUser(@PathVariable Long id) {
    User user = userService.findById(id);
    if (user == null) {
        return ResponseEntity.notFound().build();          // 404
    }
    return ResponseEntity.ok(user);                        // 200
}

@PostMapping("/orders")
public ResponseEntity<Order> createOrder(@RequestBody OrderDTO dto) {
    Order order = orderService.create(dto);
    return ResponseEntity
            .status(HttpStatus.CREATED)                    // 201
            .header("Location", "/orders/" + order.getId())
            .body(order);
}
```

**常用快捷方法**：

```java
ResponseEntity.ok(body)              // 200
ResponseEntity.notFound().build()     // 404
ResponseEntity.noContent().build()    // 204
ResponseEntity.status(400).body(msg)  // 自定义状态码
ResponseEntity.badRequest().body(msg) // 400
```

## 统一返回格式

```java
// 通用的返回包装类
public class Result<T> {
    private int code;
    private String message;
    private T data;
    
    public static <T> Result<T> success(T data) {
        Result<T> r = new Result<>();
        r.code = 200;
        r.message = "success";
        r.data = data;
        return r;
    }
    
    public static <T> Result<T> error(int code, String message) {
        Result<T> r = new Result<>();
        r.code = code;
        r.message = message;
        return r;
    }
}

// Controller 中统一使用
@GetMapping("/users")
public Result<List<User>> listUsers() {
    return Result.success(userService.list());
}
```

**前后端约定的标准响应格式**：

```json
{
    "code": 200,
    "message": "success",
    "data": { ... }
}
```

**vibe coding 视角**：AI 生成的 Controller 经常直接返回实体对象，而不是包装在 `Result` 中。如果项目约定使用统一返回格式，需要在 prompt 或代码示例中明确告诉 AI。

## HTTP 状态码速查

| 状态码 | 含义 | 使用场景 |
|--------|------|---------|
| 200 | OK | 查询成功 |
| 201 | Created | 创建成功 |
| 204 | No Content | 删除成功（无返回体） |
| 400 | Bad Request | 参数错误、校验失败 |
| 401 | Unauthorized | 未登录 |
| 403 | Forbidden | 没权限 |
| 404 | Not Found | 资源不存在 |
| 429 | Too Many Requests | 限流 |
| 500 | Internal Server Error | 服务器内部错误 |
